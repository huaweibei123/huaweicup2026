## 2. A：理想集为何足以保证 Task-order 合法性

先用官方同口径得到非 COPY 计算依赖 DAG：桥接 Op–Tensor 路径，再跳过 COPY 节点，保留最近计算操作的依赖。记其为 D。父 Task 的计算成员为 V，内部图是 D 在 V 上的诱导子图。

拆分条件是：

\[
\varnothing\ne P\subsetneq V,\quad Q=V\setminus P,
\quad (u\to v\in D[V],\ v\in P)\Rightarrow u\in P.
\tag{I1}
\]

【证明 A1】在以下前提下，式 I1 与新完整 Task 依赖加核序 DAG 无环等价：

1. 父计划已经通过完整“商图数据边 + 每核相邻 Task 顺序边”的无环检查，而不只是直接同核数据顺序检查。
2. 两个新 Task 使用非空成员集，同一核心、原位置相邻执行前半再后半；原前项改接前半，后半改接原后项。
3. 新外部依赖按原计算边端点重新分配，没有新计算数据依赖、任意换核、其他 Task 重新排序或节点删除。
4. 使用真实 COPY 收缩后的 D，不漏内部 COPY 桥接关系；新子图 ID 无冲突，所有原非 COPY 操作恰好覆盖。

必要性：非理想集必存在后半到前半的内部跨界边。与新增的前半到后半核链组成环。

充分性：假设新 Task 图有环。若环触及其他 Task，把前半和后半都映回父 Task，删去由前半到后半压成的自步，就得到父完整 Task 图的非空闭合有向走法，矛盾。若环仅在两个新节点中，就需要后半到前半边，与理想集矛盾。

**无需额外要求所有外部输入只连前半，或所有外部输出只连后半。**两半可以各有任意外部接口；合法父增广图已经排除了经外部绕回父 Task 的路径。

条件缺失的反例：若忽略 `q → tensor → COPY → tensor → p`，可能把后端 p 单独放前半；真收缩关系仍是 q 到 p，产生逆序环。若父计划本来只有商图无环、核链联合成环，也不能使用本命题。单成员 Task 没有非空二分。

本命题只解决 Task-order 结构，不保证新局部 Step1/2/3、内存、Pipe 执行成功或 Makespan 改善。

## 3. B：冻结输入释放标签，不累加计算时长

设父计划中 Task T 的旧实际启动为 s_T，本核前项为 H（可能不存在）。定义本核入口底线：

\[
b_T=\begin{cases}f_H+100,&H\text{存在},\\0,&\text{否则}.\end{cases}
\qquad
r_v=\max\left(\{b_T\}\cup
\{f_U+1000: U\text{为 }v\text{的外部异核计算前驱 Task}\}\right).
\tag{I2}
\]

这里等待数值必须从配置读取。父计划合法时，较早同核前驱已被本核前项结束底线覆盖。原 DDR 图输入没有计算前驱，其外部门控为底线；并不意味着数据已在 L1/UB，COPY 服务仍未计算。

在内部拓扑序上传播：

\[
\ell_v=\max\left(\{r_v\}\cup\{\ell_u:u\in\operatorname{pred}_{D[V]}(v)\}\right).
\tag{I3}
\]

**不要加计算周期。**这是必需外部完成条件的传播，不是算子的最早实际开始时间。父时间线、图、计划、配置身份必须一致；若所有标签的最大值不能解释旧 Task 的启动，先报告残差，不能硬凑。

对任意非空理想集：

\[
g_{\rm frozen}(P)=\max_{v\in P}r_v=\max_{v\in P}\ell_v,
\qquad I_\tau=\{v:\ell_v\le\tau\}.
\tag{I4}
\]

【证明 B1】I_tau 是该阈值下唯一的最大理想集。因为标签沿依赖不下降，所以子水平集向下闭合；任何冻结门控不高于阈值的理想集，包含其成员全部祖先，因此其标签均不高于阈值，必被 I_tau 包含。

若标签有 d 个不同值，最多 d−1 个不同的非空真最大理想集。若外部异核前驱结束加等待只有 k 个不同值，则 d 不超过 n 与 k+1 中较小者。标签只取输入标签中的最大值，不凭空产生新值。

**近线性限于描述和统计。**内部图 n 个节点、m 条边、p 个张量 pins，标签/统计可在 O(n+m+p+d log d) 内生成。把每个阈值都输出为完整计划仍可能产生二次量级开销；只保存阈值和增量分组，选中后物化。

### 同阈值不能只保留最大集合

多搬一个共享大输入可能让一个短的早就绪分支代价很高；把它留给后半与晚输入消费者共同读取可能更好。最大集合只最大化“门控允许的成员”，不最大化有用的重叠。后面的新 E0 例子直接证明了这一点。

若所有标签都等于旧启动，则该父 Task 不存在冻结模型下有正入口提前量的理想集；这可以停用**入口提前机制**，但不能删除其出口释放、spill 或局部流水机制的所有拆分。

### 输出边界的最小理想集

对一个异核消费者 Task X，令 A_X 为父 Task 中所有向 X 发出真实计算依赖的源端点。定义：

\[
D_X=\downarrow A_X.
\tag{I5}
\]

【证明 B2】把 D_X 全放前半，是消除后半到 X 的**直接数据依赖**的最小理想集。不能只选其中一个输出生产者而留下其他生产者在后半。若 D_X 是全体 V，则这种二分无法将该直接出口完整提前。

这不保证 X 真能早开工：它还可能等其他前驱、自己的核链，或经其他 Task 间接依赖后半。出口条件不是收益定理。

## 4. C：精确 spill 前字节增量的集合函数

不要从旧 Task 的重命名 tensor/backing 做继承。以下直接从原图重新使用 Q1 builder 的边界条件。

对原张量 t，记 s_t 为大小，p_t 为唯一原生产者（若有），C_t 为全部非 COPY 消费者，h_t 表示原 COPY_OUT 消费者存在。J_t 是 C_t 中属于父 Task 的成员。参与模型的是 builder 实际触达的原 tensor：原 COPY_IN 的片上输出通常才是重复读取的那一个 net，不能擅自合并为原 DDR ID 或 logical ID。

对成员集 S，直接边界计费为：

\[
B(S)=\sum_t s_t\Big[
\mathbf1[J_t\cap S\ne\varnothing,\ p_t\notin S]
+\mathbf1[p_t\in S]\,
\mathbf1[h_t\lor C_t=\varnothing\lor(C_t\setminus S\ne\varnothing)]\Big].
\tag{I6}
\]

该式用于 S 是父 Task 的子集；若生产者是原 COPY 或在外部，同样不属于 S。原多生产者输入不在本原型承诺范围；检测到即停用本图割表示，不偷偷取一个生产者。

在父 Task 内生产的张量，定义它原本就需要输出的标志：

\[
b_t=\mathbf1[h_t\lor C_t=\varnothing\lor(C_t\setminus V\ne\varnothing)],
\qquad
\operatorname{cut}_e(P)=\mathbf1[e\cap P\ne\varnothing,\ e\setminus P\ne\varnothing].
\tag{I7}
\]

【证明 C1】精确增量为：

\[
\begin{aligned}
\Delta B(P)&=B(P)+B(Q)-B(V)\\
&=\sum_{p_t\notin V}s_t\operatorname{cut}_{J_t}(P)
+\sum_{p_t\in V}(2-b_t)s_t\operatorname{cut}_{\{p_t\}\cup J_t}(P).
\end{aligned}
\tag{I8}
\]

| 类型 | 跨两半时增量 | 原因 |
|---|---:|---|
| 输入生产者不在父 Task 的计算成员中 | s_t | 父 Task 读一次，新两半各读一次；读一次还是多个消费者共用均按 Task 去重 |
| 内部产生，父 Task 原本不必写出 | 2s_t | 生产半新写一次，另一半新读一次 |
| 内部产生，已有外部计算消费者或原 COPY_OUT | s_t | 生产半本来就写出；只增加另一半的读 |
| 没跨两半，包括纯最终输出 | 0 | 没有新增另一半读取 |

证明逐张量相减即可。每个其他 Task 的成员没变，其边界布尔条件和字节数不变，所以式 I8 也是全计划 `partition_added_copy_bytes` 的增量。**这不意味着其他 Task 的生成 ID、编译顺序、spill 或执行时间不变。**Q1 源 Task 对同一张量写一次，不因目标 Task 数量线性复制源端 COPY_OUT。

该结论准确到 spill 前字节；不是总搬运、不是动态 DDR 时间、不是 Makespan 下界。零字节 tensor 也可能对应至少一周期的 COPY 参考工作，因此零字节增量不等于零时间代价。

### 为什么可以最小割

式 I8 是非负加权 all-or-nothing 超边割之和，因而为次模函数。一个超边只需要两个辅助点：每个 pin 到 a 为无穷容量，b 到每个 pin 为无穷容量，a 到 b 为该 net 权重。若 pins 分处两侧，则辅助点必须分离并支付一次权重；否则可以零付费。

本轮只为这个装置核对一手文献，不重做综述：Nate Veldt, Austin R. Benson, Jon Kleinberg, **Hypergraph Cuts with General Splitting Functions**, SIAM Review 64(3), 650–685 (2022), DOI `10.1137/20M1321048`，arXiv `2001.02817`。实际读取开放稿 §4.1 的 Lawler expansion 及 Figure 4。文献给出的是装置；式 I8 是按本题 Q1 源码独立推导。

选定理想上界 U 和强制理想子集 D，满足 D 包含于 U 且 U 是真子集，取正的可加计算权重：

\[
\min_{P\text{为理想集},\ D\subseteq P\subseteq U}
\left\{\Delta B(P)-\lambda\sum_{v\in P}w_v\right\},\qquad\lambda\ge0.
\tag{I9}
\]

依赖 u 到 v 对应反向无穷边 v 到 u。源到操作的容量为 lambda*w。强制选择用源到点无穷边，禁止选择用点到汇无穷边。再接上超边装置，一次最小割就精确求解这个**标量代理**。

采用有理价格时统一乘分母，容量用整数。无穷取所有有限容量之和再加一，且锚点一致时有有限可行割。若 D 为空，解可能为空，应丢弃；U 为真子集保证非空结果留下非空后半。

入口模式：U 取非空真 I_tau，D 可为空。出口模式：D 取 D_X；选一个不在 D 中的后半锚点 q，令 U 为 V 去掉 q 的上闭包。这样 D 仍包含于 U；本原型的纯最小闭包 D_X 也应直接保留，不强迫所有出口候选经过价格筛选。

### 参数压缩的边界

【证明 C2】固定 U、D 和正权重，随 lambda 严格增加，任意最优主节点集合嵌套增长。用两组最优性分别与交集、并集比较，结合次模不等式可得：

\[
0\le\Delta B(P_1)+\Delta B(P_2)-\Delta B(P_1\cap P_2)-\Delta B(P_1\cup P_2)
\le(\lambda_1-\lambda_2)\sum_{v\in P_1\setminus P_2}w_v.
\tag{I10}
\]

因此差集为空。在每个价格取固定的包含极小最小割后，整条参数路径最多 n+1 个不同集合。这不是有限价格网格必然找全断点，也不是跨不同阈值/锚点只剩 n+1 个候选。

**参数割不能找全离散 Pareto 前沿。**链 a→b→c→晚节点，三个理想前缀的工作/增量字节分别为 (1,2)、(2,6)、(3,8)，可由跨界内部 tensor 大小 1、3、4 实现。中间点不被另外两点支配，却没有任何价格使其成为标量最优。不能声称“未被价格选中就不值得 E1”。

同阈值、同工作、同字节也不表示编译/执行等价。安全去重仅使用相同成员集合与相同新 ID/计划规则；纯代理支配最多是预算排序，不能硬删整个原问题候选类。

## 5. 建议接入的唯一生成流程

```text
RELEASE_BOUNDARY_SPLITS(graph, parent, measured_parent, budget):
    校验父计划完整 Task DAG；校验测得时间线与父计划身份
    使用真实 COPY 收缩关系；按原 tensor 构建 Q1 精确增量 nets
    从所有 Task 的入口/出口边界索引选择本轮对象，不只沿旧 spill 排名前缀池

    对每个选定 Task:
        拓扑传播外部门控标签，不加计算时长
        一次扫描得到所有不同最大理想集的门控、工作与精确字节描述
        选择少量不同阈值，保留其最大理想集
        在所选阈值内，用少量价格最小割生成部分理想集
        针对少量重要远端消费者，保留完整出口源集合的向下闭包
        预算允许才在出口锚点与后半锚点之间补一个最小割扩展

    保留少量已有基线前缀候选；按成员精确去重
    不按 Makespan 猜测、相同三元分数或所谓 Pareto 支配做安全硬剪枝
    将选中成员集写成 P/Q 同核相邻的标准计划；再次调用官方 Task-order 检查
    经固定 E1 批接口重新编译/评价，最终 E0 确认；父计划始终为保留方案
    采用新父计划后重新计算标签，不复用旧生产者完成时刻
```

一组初始人为预算可设为八个 split 槽：两个已有前缀、两个不同阈值的最大理想、两个部分理想、两个出口闭包。某类为空再回填。该分配只是启动实验方案，不是理论上限；应根据实测 E1 批耗时、剩余 E0 确认时间调整，不假定只能评八个或可以无限评。

不宣称每个 Task 都值得流求解。若最大理想扫描没有覆盖新增结构、或父前项完全控制门控，入口价格路径可以不启用；但出口和原压力机制仍保留。对输出闭包，关键路径、远端剩余工作等只决定尝试顺序，不是必有收益的定理。

### 成本

已有真实收缩图后，标签和阈值描述为 O(n+m+p+d log d)。全体阈值字节可利用每条 net 的最小/最大标签：它只在这两个标签之间被切开，因此对标签桶做区间加减即可。

最小割网络有 n+2h+2 个点，O(m+2p+h+n) 条弧。L 次求解为 L 倍相应最大流时间。本附件参考实现使用 Edmonds–Karp，最坏 O(L*V_f*E_f^2)，仅用于小 Task 和等价验证，不冒称生产性能；残量网络与图索引空间 O(V_f+E_f)。更快实现可替换这个子程序，整数目标与验证口径不变。

COPY 收缩可能扩张依赖，m 指真实生成后的边数，不能将此成本隐藏为原 JSON 长度的线性。选中 B 个子集的物化还需 O(B*n)；标准完整计划输出另外是 O(B*全图计算操作数)。全部构造、流、编译、E1、E0、失败回退都计入预算。

### 6.2 非前缀部分理想：存在性见证

固定合成图有 Task T 的计算成员 b、c、a，真实父 Step1 顺序恰为 b,c,a。a 是 3000-cycle 独立早工作；b 是短早工作；c 等一个异核生产者。b 与 c 共用 262144-byte 图输入。标签为 b=0、a=0、c=4002。计算/依赖/原 ID 在该对照内不改。

| 构造 | 前半成员 | Makespan | spill 前 COPY 增量 | spill 字节 |
|---|---|---:|---:|---:|
| 父计划 | 不拆 | 11376 | 0 | 0 |
| Step1 第一个前缀 | b | 11847 | 262144 | 0 |
| Step1 第二个前缀 | b,c | 11477 | 0 | 0 |
| 最大早理想集 | a,b | 11847 | 262144 | 0 |
| 价格 1 的部分理想 | a | **8377** | **0** | 0 |

这覆盖了该 Task 的所有非空真 Step1 前缀；不只是赢过恰好漏了切点的前缀采样器。收益是本合成例的存在性证据，不是正式开发图的新成绩。

动态耦合仍可见：父计划远端源结束为 3002，拆分后为 3004；标签预测的门控 4002，实际后半启动 4004。两新 Task 实际持续时间合计 7377，原 Task 为 7374。不能把冻结标签当真实新时刻，也不能将收益解释成总执行持续时间下降。

**保留失败/中性控制：**最先手工构造的另一张输入布局，父 Step1 为 a,b,c，父计划与部分理想都为 8377；最大早理想为 8849。随后才构造上述非前缀变体。两者均归档；没有在同一输入上允许重编号来优化，也不声称盲测或首次尝试就成功。

### 6.3 零入口提前量、仍可提前出口

父 Task 两个独立工作 a（100 cycles）和 b（5000 cycles），远端长消费者只需 a 的输出。所有父成员入口标签都是 0。把完整出口闭包 a 放前半，b 放后半：

- 父计划 11005，拆分 6104 cycles；五项搬运统计相同，spill 为 0。
- 父 Task 0→5003，远端消费者 6003→11005。
- 前半 0→102，后半 202→5204，远端消费者 1102→6104。

该例否定“输入提前量为零就禁用全部 split”，但不证明零入口图上拆分通常有效。

### 6.4 字节公式的官方四个对照

一个 96-byte 内部张量，两个本地消费者；消费者还共享 120-byte 输入：

| 原内部张量是否已有外部消费者 | 只把生产者放前半 | 再把一个本地消费者放前半 |
|---|---:|---:|
| 否 | 192 | 312 |
| 是 | 96 | 216 |

均是 E0 的 `partition_added_copy_bytes` 相对父计划增量，与式 I8 一致。该表检查写出是否本来存在以及重复输入是否按新 Task 去重，不用它预测 Makespan。

完整调用账本：18 次 E0 函数运行，3 次未插桩官方 CLI 复核（对应全部函数结果字段一致），2 次独立 Task 构图读取父 Step1。不同标签的候选中有重复成员集，调用数不当作独立样本数。全部结果、输入、计划保留；无全 100 图运行。

## 7. 首个集成实验应如何证伪

1. **结构和字节口径**：含 COPY 桥接、外部前驱/消费者、共享输入与已有 COPY_OUT 的极小图，枚举全部理想；新 Task-order 必须通过，字节增量必须匹配。任一不符先停用实现，不能调整定义掩盖差异。
2. **覆盖而非事后重排**：固定父计划，比较现有同数量前缀与本生成器，评价前保存成员集合、阈值、净新增字节和价格；观察新增非前缀覆盖以及相同 E1 次数/墙钟下最终 E0 最好值。若只是重复已有前缀或增加构造费而无发现收益，暂缓默认接入。
3. **零入口与大重复输入负对照**：保留零入口出口例及“最大理想更坏”的例子；真实图不要仅以正入口提前量过滤全部 split，也不要只保留最大理想。若标量筛选持续排除 E0 好方案，降低价格路线权重而不是宣称未支持点不可能好。

Q1 独有性：每个新子图都是新 Task，必须全量重建边界 COPY、backing、Step1/2/3，并有新增同核切换等待。Q2/Q3 的每核合并 Task 没有相同入口/出口屏障；不能把这些二分结果当作其 singleton 阶段编排定理。
