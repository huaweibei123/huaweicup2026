# P1 s6607 / r2：同步Task的共享DDR商响应与三状态构造

本包不含新E0/E1/E2结果，不是正式成绩台提交。没有运行统一v4或全100矩阵。

## 本轮结论

1. 聚合计算量/DDR服务量代理不能识别由请求释放、固定FIFO、Task完整退休产生的DDR断供。
2. 一项“每个容量包保留一条完整链”的固定新构造也被本轮模型否决：084/k5模型417172，比全切模型399121慢。不要部署这个单独构造。
3. 首选研究对象改为 **经实际FIFO签名核验的同步商响应**。在各核Task同型且共同释放时，将K份相同DDR请求合并为一个代表请求，其独占服务工作乘K，计算周期与100-cycle门控不变。使用完整事件响应，而非一个负载标量。
4. 在固定容量包Q上，三个待返程状态0、Q-1、Q组成条件DP。它是在一个明确受限类内求解，不是全局最优算法；不扫描Q，不在线提交每条DP路径评分。
5. 对084原图完成静态结构核验，得到保链阻塞/拆链搬运析取界335819。它的适用条件与证明见下；它不是全切计划的390951服务界，也不认证399121最优。

## 适用条件与证明

### 1. 无spill不意味着无内存边

普通峰值不超过容量，仍可能反复使用已释放额度而生成MEMORY_REUSE边。
本包使用更强的充分条件：Task每个物理片上tensor恰有一个producer，所有不同片上tensor大小的总和不超过对应容量。于是每个tensor最多分配一次，所有首次分配均可从VIRGIN额度满足，不需要SPILL或有来源的复用额度。仅在该条件下跳过Step2/Step3的容量模拟；实际Step1/FIFO仍完整保留。

### 2. 四个完成前缀足够判定ready

每条Pipe只能顺序退休。把某op的每条Pipe前驱集合换成“该Pipe上最大的前驱序号”，与原前驱检查等价。Task静态签名保存每个op的四个阈值、Pipe、时长、是否DDR；实际原op IDs在输出计划中不变。

这只是计算表示的压缩，不会把多个DDR COPY合并成一个真实COPY；每个COPY仍分别取整、分别加入共享池。不能把K倍服务工作换成一次对K倍字节的取整。

### 3. 同步商响应

假设同一轮K个Task的上述完整签名相同，且共同释放，无其他在途工作和未表达的跨核依赖。每组对应操作保持同状态、同完成时刻。若代表Task有r个活跃DDR请求，全图有Kr个，对应每个真实请求的服务速率为1/(Kr)。将代表请求工作改成K倍，在代表池中以1/r共享，完成时间完全相同。

对事件序列归纳即可证明。计算时长不缩放，门控不缩放。两条搬运Pipe可以同时在飞；公式不假设DDR请求串行。Task完整结束时所有COPY也已退休，下轮再从空池出发。因此可以缓存一个响应并复用许多轮，而不保留跨轮残余DDR状态。

该结论在本包的“有理数公平服务+整数cycle退休”模型中精确。官方实现使用binary64/EPS；本包没有给任意整数范围的程序等价证明，单点匹配也不替代独立差分验收。

### 4. 非同步尾部

宽度不整除KQ时，只折叠已核验同签名的共同轮次。第一个签名不一致处起，显式模拟剩余各核端口状态。不得人为等所有核结束再开下一轮，因为计划接口没有那个屏障。新构造的余数仅放末尾，故显式尾部规模受KQ控制；任意计划若早早失去对称性，尾部可能是整个图。

### 5. 三状态DP

Q由每条prefix加return的保守容量确定，只取一个值。每核每轮消耗Q条新链；状态r表示上一轮留下的返程条数。状态集为{0,Q-1,Q}。

动作r→s创建同一个Task：Q-s条新完整链、s条新前缀、r条旧返程。每个动作都重新验证容量以及各核完整编译签名相同。可附加r→0的纯排空Task，消耗0条新链。每个动作成本是代表Task共享DDR响应加100门控；第一个Task减去那次不存在的门控。

状态(j,r)唯一确定未完成的旧返程集合：它们是固定第j-1组的最后r条链。任何旧返程都在当前Task中结束，不跨越两轮保存。故这是充分状态。每层至多3个状态、9条进展边、2条排空边；排空边只有正成本且只指向0，一次闭包即足够。

普通最短路动态规划给出该**签名认证同步包类、该数值模型**中的精确最优路径。不是原P1优化问题下界。候选所有跨Task边只向本核后续Task，联合数据DAG与核顺序DAG无环。跨核无数据依赖，不支付1000；100门控由真实Task退休计算。

`renewal_dp.py`含原图到两键plan的完整小原型，但本轮仅在一个12链合成图上执行该DP。没有在084或官方100图上运行它。

### 6. 084静态析取证书

脚本检查：独立同质真实M-V+-M spine，无COPY桥，单计算producer、无共享tensor，所有对外计算输出都在终点。完整spine被Step1连续遍历，所以入口M与返程M在本核M FIFO中相邻。中间V的1152 cycles是本核任何其他M无法填补的空转。即使其他Task/组件引起SPILL，新节点也只是COPY，不会在这对M之间插入其他M。

N=1077，链计算量2328。每条链有四个必要3072B搬运和一个必要2B搬运，服务209，总必要服务225093。七个内部切口的额外服务分别为154,154,158,154,154,158,154，因此任意拆链至少支付154服务；不是仅检查返程切口。

若拆s条，三个对所有合法计划成立的界分别是：

- ceil((1077×2328−1152s)/5)：普通M工作加未拆链强制M空转；
- 2328×ceil((1077−s)/5)：未拆链的整数装核界；
- 225093+154s：必要与拆链DDR服务。

取三个最大值，再对所有s取最小。前两项不增，第三项不减，二分交叉处为719：

| s | M阻塞界 | 整链计数界 | DDR界 | 最大值 |
|---|---:|---:|---:|---:|
|718|336024|167616|335665|336024|
|719|335794|167616|335819|335819|

故下界335819。更小s由M阻塞项排除，更大s由DDR项排除。这是给定结构域内覆盖全部计划的静态证书，而不是某一候选FIFO图的最长路。

将所报合法上界399121与之结合，条件性相对最优差距至多18.8500%；当前时长最多再降低15.8604%。不等于该幅度可实现，不是最优认证。沿用现有静态下界文档的正常整数资源语义/数值域限定，未形式化证明任意binary64极端输入行为。

只有2个084原图自有模型CLI进程，均在预先固定的40秒窗口内成功，无重试；没有改变Q、完整lane数或切口。完整进程墙钟分别1.39169秒、1.41478秒。这不是M5主机的统一solver基准。固定候选落盘后的模型诊断也计入此进程墙钟。

|方案|自有模型时长|固定计划DDR服务|scheduled bytes|extra bytes|
|---|---:|---:|---:|---:|
|全切，Q=5|399121|390951|23161962|9925632|
|每包1完整+4回流|417172|357533|21162090|7925760|

全切的同型中间Task响应9075，DDR服务也为9075；完整lane混合Task响应9469，DDR服务8305。后者每轮少770服务，却引入1164的服务空窗，净慢394。同步并没有消除FIFO造成的请求断供。

全切折叠43轮、2种响应，尾部7个Task。新候选折叠44轮、3种响应，尾部2个Task。模型编译约0.47秒；两种响应阶段约0.00477/0.00332秒。响应阶段不是求解端到端墙钟。

另有1个微测试进程，5项测试通过（见microtests_run1.json）：K=1..5商模型/展开模型一致；对称破坏时显式尾部；真实原ID深度tie导致返程M先行；三状态最短路手算实例；12链原图DP输出计划与独立展开端口模拟一致、字节一致。全部只调用本包模型，没有导入官方evaluator。

## 泛化与停止规则

所有100个原图均视为研发数据。不要重新划分后称完全未见。算法不读case名字、历史计划或图哈希来选构造；哈希仅用于来源验证。N只决定分组数、余数、容量裁剪，不应出现N==1077等路由。

冻结后预注册少量新生成实例：改变宽度与KQ余数、V深度（特别是depth tie）、独立改变M/V周期、改变完整跨界tensor与旁路tensor大小，并覆盖60B取整和容量floor阈值。保持官方配置不变；相对门控占比通过操作持续时间变化测试。再由未参与实现者保留一个域内新generator-family和一个域外共享输入/fork族。后者的正确行为可以是明确回退，不要求每族改善。

合法重编号不保证官方成绩不变，因为官方Step1依赖ID；应检查合法性以及模型对变化后真实FIFO的正确响应。不能在生产输入上改ID。

建议只分三项后续证伪检查：编译/数值微契约；已冻结的少量参数扰动；整generator族留出。固定种子范围与总预算后执行，失败即记录，不补扫Q/s、不增加第四状态或无限候选。当前研究包不授权或启动任何官方批次。
