**范围。** 本稿仅针对情况 A、固定官方源码与 config、原始100图、K=1,…,5。所有新增定理、证书及静态程序均为本轮作者报告，待本地独立审计。本文不报告新 solver/E0/E1/E2 成绩。原始输入身份与逐文件 Git/SHA-256 见 `read_inventory.json`；数据表见 `paired_500_audited.csv`。引用 [S1] 等均为本次实际读取的附件源码或文档，不引用未读取的外部文献。

## 1. 优化域及“理论上界”的方向

令 G_i 为原图，Θ 为硬件与官方程序身份。一个提交 P 只能含 `node_to_subgraph` 与 `core_schedules`。定义

\[
\mathcal F_{iK}^{E0}=\{P:\text{通过固定格式/覆盖/联合依赖校验，且固定官方编译与 E0 成功结束}\}.
\]

这里成功执行包含实际 Step1/2/3 生成的 COPY、spill、逐 Pipe FIFO 和内存依赖。合法商图只是必要条件，不能代替完整成功执行。不得把所有满足数据依赖的任意 op 时间表当成这个可提交域。程序的固定运行环境、迭代限制及异常处理也属于需要固定的执行身份；外部测试墙钟超时不等同于题面的600秒淘汰规则。

\[
OPT_{iK}^{E0}=\min_{P\in\mathcal F_{iK}^{E0}}M_{E0}(P),\qquad
L_{iK}\le OPT_{iK}^{E0}\le U_{iK}.
\]

U 是已有成功方案的 makespan，是最小化问题的**可行上界**。L 是对全域所有方案成立的下界。只要有一个成功方案，最小值存在：成功结果是非负整数，不必假设任意 Task 编号本身构成有限集合。本文把有身份的成功归档记录作为 U；本包不含500份完整计划和 trace，本轮不重新证明这些方案的执行合法性。

B_i 是固定官方单核入口的成绩。该入口把全部非 COPY op 放入一个 Task [S3]，不是遍历单核所有分区的最优值。因此

\[
\frac{B_i}{U_{iK}}\le\frac{B_i}{OPT_{iK}^{E0}}\le\frac{B_i}{L_{iK}},
\]

但不能无条件再令 B_i/L 或真实加速比小于 K。分区会改变 spill、COPY 和 FIFO，且 B_i 本身不保证最优。正式曲线的 K=1 点固定为1；重分区单核的平均1.0020968223600535属于另一项实验，不能替换分母或曲线基点。

必须分别定义零额外DDR子域、固定分区子域、固定分区与核序子域、冻结编译签名子域、完整链/无spill/FIFO谓词子域，以及同型同步响应状态图。对子域 S 的下界只能推出 L_S≤OPT_S；因 OPT_full≤OPT_S，不能反推 L_S≤OPT_full。精确服务/Fraction模型也有自己的目标函数和可行执行语义；没有桥接定理就不能用该模型的上下界与 E0 的 U 组成差距。

## 2. 能跨越官方浮点细节的整数不变量

固定源码具有下列不变量 [S1,S2]：

1. 每个非 COPY op 被保留并只执行一次；d_v=max(1,cycles_v)，完成时刻由整数 `now+d_v` 给出。每核各 Pipe 一槽，同核只有一个 active Task。
2. Task 激活必须等待全部前驱 Task 完成。仅当本核已有 previous Task 时才加入 previous.end+100；首 Task 没有自动的100。每个异核前驱约束 predecessor.end+1000，多个约束取最大值。
3. 原图直接 compute→compute 边与 compute→tensor→compute 边所表达的计算因果被保留：同 Task 由重建图保留，跨 Task 由官方 Task 依赖及完整 Task 屏障保留；spill 只将某些数据路径细化为搬运路径，不允许消费先于相应生产计算。
4. 删除原 COPY 桥后，穿过该桥的原计算路径不一定保留于同一个 Task。该类收缩仅能用于官方 Task 依赖，不能加入通用计算关键路径。

令 D_i^0 是仅按第3项建立的保留计算 DAG。以下正式全域界只依赖这些整数不变量；不假设浮点 DDR 严格守恒，不使用 COPY 驻留长度下界或局部 `local_makespan`。额外内存依赖、spill 与 FIFO 可以限制执行，但不会破坏这些必要条件。

## 3. 现有静态界的逐项审计

### 3.1 不可省的边界服务

对原张量 t，令 P(t)、C(t) 为直接相邻的非 COPY 生产者、消费者；令 O_original(t) 表示存在原 COPY_OUT 消费者。代码采用

\[
I=\{t:P(t)=\varnothing,C(t)\ne\varnothing\},
\quad O=\{t:P(t)\ne\varnothing,\ C(t)=\varnothing\ \text{或}\ O_{original}(t)\}.
\]

任意分区中，I 的每个张量至少有一个消费 Task；该 Task 没有本地计算生产者，因此重建至少一次 COPY_IN。O 中每个张量的每个生产者所在 Task 都满足输出边界条件，至少有一次 COPY_OUT。同核 Task 边界不豁免此规则 [S1,110–171]。

按张量选择必要实例，而不是累加原图所有 COPY，也不是断言每轮都必须加载一次。对输入选择实际服务“必要尾最长的消费者”的那次读；若该消费者被 spill 重载重写，选择相应实际读而非机械地选择首条 COPY_IN。对输出选择位于“必要释放最晚的生产者”之后的那次写。不同原张量产生不同搬运实例，I 与 O 不相交，故可一致计数。多生产者/消费者不要求在不同下界中强行选择同一个具体任务，但每个资源求和中的代表必须是彼此不同的实际服务实例。

本100图中不存在多计算生产者张量，也没有零字节张量；通用谓词仍应按上述逻辑证明。零字节在模型中仍有
\(w_t=\max(1,\lceil |t|/60\rceil)=1\)，不能计0。必须逐 COPY 取整后求和，不能以 ceil(总字节/60) 冒充更强的逐服务量界。

### 3.2 理想服务域中成立的原实现

在归一化服务率总和≤1的精确共享模型中，每个必要 COPY 的持续时间至少 w_t。因此可以加入 MTE2/MTE3 的 K 槽资源，同时把全部读写放入容量1的 DDR 资源。非 COPY 按各自 Pipe 累加。不同资源可能同时工作，必须取最大值，不可直接把计算界与DDR界相加。

原 `lower_bounds.py` [S4,100–140] 先给计算节点传播含必要输入/输出服务的释放 r 和尾长 q，随后对**每个完整资源集合**取

\[
r_{\min}+\lceil W/c\rceil+q_{\min}.
\]

它没有实现完整的双阈值窗口最大化。源代码虽然输出 `proof_scope.target=all successful plans`，该标签目前必须补上 `numeric_model=ideal unit-capacity service` 或已完成的 E0 数值桥接证明；标签本身不是桥接证明。

本轮从100张原图独立重建上述谓词、DAG、资源记录及全部500个标量，与归档扫描完全一致；derived JSON和CSV也逐格一致。这证明复算与实现一致，不证明理想服务语义自动等于官方程序。

### 3.3 为什么不能直接认证官方 binary64/EPS

E0 的 `advance_ddr_work` 使用浮点减法、`work>1e-9`、钳位及容差比较；`reschedule_ddr` 使用剩余 work 分组、浮点 cursor 和 ceil(cursor−1e−9)，retire 时删除对应剩余工作 [S1,238–279,346–419]。不能把它视为逐条 COPY 独占的 FIFO 服务器。

例如在抽象内部状态 w_1=1、w_2=1+2^−52 时，二者差小于EPS，会被同组投影到时刻2；总剩余服务却严格大于2。这个例子否定“该实现每一步都严格守恒”的证明不变量，**不证明此状态由本100图某合法分区可达，也不证明某个归档整数界已经被违反**。最终整数界可能仍被小误差余量保护，但需要另证。

本轮没有完成覆盖全部合法分区、所有编译 spill/FIFO 和成功执行轨迹的浮点误差包络。因此不无条件认证原扫描的500个整数；不采用未经证明的统一减1、按样本最大偏差扣减或几例Fraction一致性替代证明。

可复核的补证路线如下：只需分析假设 M<L 的反证轨迹，从而用候选下界 L 限制时钟幅值；固定每核两个DDR槽给出 N≤2K；用迭代上限、编译边界/重载规模界限制数值更新次数；逐行用区间算术控制减法、分组、钳位和 retire 的剩余服务欠账。若能证明某资源窗口的总欠账≤δ，则把 W 换成 max(0,W−δ)。若必要 release/tail 也含 COPY，则需分别给出其安全下修，不能只扣DDR总量。只有当逐COPY早完成误差<1且时刻为整数时，才可恢复每条驻留时间≥整数 w 的论证。这是一组待完成的形式化义务，不是本轮已取得的数值结果。

当前正式表改用下述完全整数的计算/Task gate证书。在56格中，新整数界已经大于等于旧扫描标量，故这56个旧数值可由支配关系得到认证；这不等于其DDR证明已被修好。

## 4. 定理一：全域计算双阈值资源窗口

在 D_i^0 上定义
\(r_v=\max_{u\to v}(r_u+d_u)\)、\(q_v=\max_{v\to u}(d_u+q_u)\)，空最大值为0。r,q均不包含v自身时长。

固定 Pipe p、阈值a,b，令
\[
S_p(a,b)=\{v:p(v)=p,r_v\ge a,q_v\ge b\}.
\]
若 S 非空，则每个成功官方方案满足
\[
M\ge a+b+\left\lceil\frac{\sum_{v\in S}d_v}{K}\right\rceil.\tag{T1}
\]

**证明。** 保留计算因果使每个所选操作开始不早于a、完成不晚于M−b。其全部执行区间在[a,M−b]中。同一Pipe总共K槽，每个op占槽d_v，因此总占用不超过K(M−a−b)。整数时间给出取整式。证明不需要操作起始时间可自由提交，也不需要 COPY 服务守恒。证毕。

空集必须排除，否则任意大的阈值会产生伪界。公共尾只加一次b，不能把各节点q相加。多个Pipe分别计算后取max；完整关键路径亦取max。

**算法。** 压缩q升序坐标b_j，r降序分组激活；维护
\(V_j=Kb_j+\sum_{\mathrm{active},q_v\ge b_j}d_v\)。加入节点对q坐标前缀加d_v，区间最大值为当前阈值a的候选值a+ceil(max V/K)。仅查询b_j≤最大已激活q，保证选集非空。同一r必须先全部激活再查询。每Pipe O(n_p log n_p)，额外空间O(n_p)；构造DAG成本按显式展开后的边数计。

**证书。** 记录图/config身份、K、Pipe、a,b、所选个数/总d/ID集合哈希及结论整数。独立验证器重建r,q并线性筛选，不必重复证明原窗口搜索取得了最大值。任意一个有效见证已足以给下界。

## 5. 定理二：全域屏障的不可隐藏双向Task gate

本定理不固定Task边界，也不假定归约全部在独立尾。它使用的是保留计算DAG中的操作屏障，而不是当前算法的stage。

称计算节点a为通用分隔节点，如果对每个其他计算节点v，均有v可达a或a可达v。全部此类节点依拓扑序排列a_1,…,a_s，将其余节点分成首段、相邻分隔节点间的段、末段。对段j及Pipe p记工作W_{jp}。每个分隔节点的自身时长单独计算一次。

设跨核Task等待τ=1000。对K≥1、h∈{0,1,2}定义
\[
\phi_{K,0}(W)=\lceil W/K\rceil,
\quad
\phi_{K,h}(W)=\min\{W,\lceil[W+h\tau(K-1)]/K\rceil\}\ (h=1,2).
\]

首末段只有一个分隔端点时h=1，内部段h=2；没有分隔节点的全图h=0。所有成功官方方案满足
\[
M\ge L_{sep}:=\sum_{\ell=1}^s d_{a_\ell}+\sum_j\max_p\phi_{K,h_j}(W_{jp}).\tag{T2}
\]

**证明。** 考虑相邻分隔a,b，中间段长度取x=start(b)−finish(a)。假设a,b分别在核s,e。对段内核c上的计算操作，保留路径从a至该操作若异核，至少有一个跨核Task依赖，因此其开始≥finish(a)+τ·[c≠s]；从该操作至b同理，完成≤start(b)−τ·[c≠e]。一条路径有多次跨核也只取必要的一次，不将所有边等待相加。

若s=e，该Pipe全部K核可用时间总和至多
\[
F_{same}(x)=x+(K-1)(x-2\tau)_+.
\]
若s≠e，则至多
\[
F_{diff}(x)=2(x-\tau)_++(K-2)(x-2\tau)_+.
\]
对0≤x≤τ、τ≤x≤2τ、x≥2τ分别检查可得F_diff≤F_same。因此对未知核归属取F_same仍是合法容量上包络。必要条件W≤F_same(x)的最小整数解正是phi_{K,2}(W)：W≤2τ时可以全留一核，解为W；W≥2τ时进入线性段，解为ceil((W+2τ(K−1))/K)。这与上式min写法相同。

单端点段相应容量包络为x+(K−1)(x−τ)_+，给phi_{K,1}；没有端点则是Kx。各Pipe可以重叠，段内取max。所有真实操作屏障前后区间不重叠，连同分隔节点自身的计算时间覆盖从0到最后完成的一个必要时间链，故可将各段与节点时长相加。允许Task跨段融合不会推翻证明：若两端留同核，上包络已经允许；如果路径换核，整Task门控只会增加必要等待。证毕。

不应再无条件为每段加同核100，因为跨段融合可能把两侧放在同一Task。也不能在未知放核时直接给所有节点加2000；phi的单核分支正是防止该错误。

**识别及验证。** 用任意共同拓扑序，正向Kahn扫描记录当前唯一剩余源，反向Kahn扫描记录当前唯一剩余汇；两者交集恰是上述通用分隔节点。唯一源可达剩余全部节点，反向同理。识别与各段计数为O(n+e)，给1–5核的求值为O(Kn+e)。独立验证器不复制该识别逻辑，而是检查每个报告段中每个顶点从左端可达、向右端可达，端点缺失时只检查另一侧；按段前/后向布尔传播总计O(n+e)。证书包含端点ID、段成员数量、各Pipe工作、phi值及节点工作总和。

**实际加强。** 100图中自动识别出可加强多核界的6图：002、016、024、051、062、063，共24格。051有24个13周期根，每轮非根V工作25282。五核首段5857，后续23段各6657，加24个根得到159280。该通用界不声称强于所有已有051专用界；它的优点是只依赖已经核查的整数不变量、无需重载或DDR浮点桥接。

最终本轮正式证书取
\[
L_{iK}=\max\{CP(D_i^0),L_{window},L_{sep}\}.
\]
独立程序验证了500格全部见证。016/5从纯计算窗口1543016提高到2033550；051/5从121437提高到159280。仍无一格与v4的U完全相等。

### 5.1 从局部证书升级到全域，量词不能交换

若全域被结构谓词覆盖为 $\mathcal F=\bigcup_\theta\mathcal F_\theta$，且每个 $L_\theta$ 对其对应子域所有方案有效，则可得全域下界 $\inf_\theta L_\theta$，而不是 $\max_\theta L_\theta$。只有多个下界分别已经对全域成立，才可以取max。由某个当前方案的下界跳到全域，必须补上这个覆盖步骤。以目标T反证时，必须排除所有结构分支，而非只排除现有候选。定理T2正是在未知端点核归属上先取容量的上包络，避免这种量词错误；它没有把当前方案的Task分段当作全域必需分段。

## 7. 迭代的数学保证与不能保证的内容

### 7.1 嵌套候选与嵌套证书

**定理。** 固定i,K,Θ，若成功候选集C_t包含于C_{t+1}，始终保留旧成功计划，且按同一精确E0目标选最小值，则U_{t+1}≤U_t。若L_{t+1}=max(L_t,新增已验证全域界)，则L_{t+1}≥L_t，区间[L_t,U_t]嵌套。

证明是有限集合最小值与下界最大值的序关系。若采用(M,extraDDR)字典序，makespan不会增加；但makespan改善时额外DDR可以上升，不能声称两个指标分别单调。区间收缩也不保证收敛全局最优：只有一个代价2的候选被永久保留，即使存在代价1的另一方案，也可永远停在2。需要覆盖/完备搜索等额外条件才能谈全局收敛，本文不建议以暴力搜索换取该条件。

**对v4的限制。** 已读入口最多6个不同候选、按E1选择；附包没有其导入的 `src.eval_exact`，不能验证E1与E0等价。最小排名反例为旧方案E0=10、新方案E0=11，而E1分别报告10和9；候选集扩大仍会让真实结果退化。若已证明评分误差≤ε，只在新估计+ε≤旧估计−ε时更换可以恢复单调；但本包没有这样的误差证书。

`choose` 首次失败时保留已有成功评分者；如果第一项即失败，则返回未获在线验证的基本候选，单候选快路径也不作在线评估。候选在理论上保留而评分前被预算截断，不等于成功候选集嵌套；必须保留旧已认证输出，并保证其不会因新增构造/编译/超时耗尽预算而丢失。可使用同身份计划字节缓存或等价性证书，但不能依赖图编号/历史成绩表选择规则。

### 7.2 追加空闲核的全域单调性

**定理。** 将任意成功K核计划的 `core_schedules` 尾部追加空数组，保持节点映射、Task ID、原核序、原核编号和所有既有对象的相对遍历顺序不变。官方允许空核序 [S2]；Task编译按原Task ID排序，不依赖尾部空核；新核从不发射操作。归纳每个事件可得原执行的激活、发射、退休及DDR字典更新完全不变，连同binary64操作次序不变。因此M和搬运字节相同，得到
\[
OPT_{i,K+1}^{E0}\le OPT_{iK}^{E0}.
\]

这不要求所有核被使用，不适用于重新编号、迁移Task或重新分区。当前v4对每个K独立构造，未实现该可行解继承，所以4→5核13图退化不反驳定理。

修复方式是在当前输入上在线构造较低核预算的父候选，追加空核纳入相同准确度的选择，不读取历史格号。若对K=1,…,5都重做基础构造，最坏候选评分尝试规模可能从至多6扩大到1+4×6=25；共享编译缓存或递归只保留父胜者可降低重复工作，但收益必须实际计入启动、读图、所有构造/评分/回退、输出与退出的完整墙钟。历史包络K5=4.036858344737648是对已存结果做的算术，不是新统一入口成绩或新墙钟。

### 7.3 各条研究线的逻辑地位

- H/J的分层完整链packet与拓扑闭包：结构条件满足时覆盖/联合无环可证；有同映射K3配对支持机制，不能据此证明所有图或K都改善。
- 084变宽packet：有条件无spill的容量并集守卫、受限状态图Bellman最优性可以分别证明；整体E0改善仍依赖评分域及签名保持，不存在“更宽必快/DDR必少”的普遍定理。
- 保留MEM的响应器：在固定真实FIFO与完整前驱图下，跨Pipe前驱集可压成各Pipe最大完成前缀，前提是Pipe内严格FIFO；这是状态表示等价，不是Fraction与E0等价。遗漏MEM会改变模型。
- 丢约束后的贪心共享响应不能自动当乐观下界：两个独占工作1的DDR请求A/B，A后接100计算；B原先在时刻1才可发射，则A于1完成，总长101。去掉B的释放约束使二者都在0发射，A于2完成，总长102。可行域放松的最优值单调，不等于固定贪心公平共享程序的响应单调。
- 懒DP仅当OPEN保留全部未解析合法转移、下界对这些转移有效、状态包含完整剩余问题身份时，才有认证前沿。超时是未知不是不可行。只记(n,r)必须证明同状态剩余任务/FIFO/张量身份相同；跨ID签名等价不能靠同型直觉代替。缺失实现意味着本轮不能逐行认证全部控制器。
- 008：本轮仅从保存ports静态重建了28个Task的DAG与新窗口见证，得到whole=101836、同步period7≥106071。它排除这一固定同步签名优于该保存模型可行值，不排除全部切链，也不比较E0的100603。若另具备“每条完整链两条M在冻结M FIFO相邻、其间V依赖保留”的谓词，99264的计算阻塞证明本身不含DDR浮点，可用于满足该谓词的E0子域；但仍不是P1全域界，更不证明v4当前计划属于该子域。

## 8. 论文应采用的结论措辞

本方法通过有限结构候选及执行反馈改进可行解，并通过独立、全域有效的下界给出未闭合的最优差距区间。结构优化改善了部分已核验实例；本研究不证明每次构造修改都会改进官方目标。只有在候选继承、同一准确目标选优及成功回退条件下，才可证明当前可行上界不增。新整数窗口与屏障界不依赖共享DDR浮点等价性，已给出可独立检查的500格证书；涉及必要DDR服务和冻结响应签名的结论保留其数值域与结构子域。当前数据不支持宣称全100图已达到或正在以已证速度收敛到全局最优。
