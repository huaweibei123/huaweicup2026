# A. 从冻结语义得到的下界体系

## A1. 先固定量词

设 \(D\) 为原图，\(\Theta\) 为官方源码与配置身份，\(\mathcal F_3(D,k;\Theta)\) 为能够通过该身份下合法性检查并成功完成官方执行的两字段方案集合。定义

\[
M_3^*=\min_{P\in\mathcal F_3}M_3(P),\qquad
U=M_3(P_{\mathrm{current}}).
\]

这里须区分四类量：

| 类型 | 正确陈述 |
|---|---|
| 全局下界 | \(L\le M_3(P)\quad\forall P\in\mathcal F_3\)，因此 \(L\le M_3^*\)。 |
| 受限族下界 | \(L_{\mathcal H}\le M_3(P)\quad\forall P\in\mathcal H\subseteq\mathcal F_3\)。不能直接用于整个 \(\mathcal F_3\)。 |
| 固定方案下界 | \(\ell(P)\le M_3(P)\)，其中归核、FIFO或编译图已经固定。 |
| 模型值 | \(\widehat M(P)\) 是某个简化执行模型的结果；未证明映射关系前，它不自动是官方上界或下界。 |

对真正的全局界，

\[
L\le M_3^*\le U
\]

给出：

\[
\boxed{U-M_3^*\le U-L},
\qquad
\boxed{1-\frac{M_3^*}{U}\le1-\frac LU},
\qquad
\boxed{\frac{U}{M_3^*}\le\frac UL}.
\]

三者分别表示：最多还能减少的周期、相对当前时间最多还能降低的比例、当前解的最坏乘性证书。**都不是已经证明可达到的收益。**

固定单核基线 \(B>0\) 后，才有

\[
S^*=\frac{B}{M_3^*}\le\frac BL.
\]

## A2. 旧计算松弛界：本轮核验后可以保留

令 \(V\) 为原图非 COPY 计算操作，\(d_v=\max(1,\mathrm{cycles}_v)\)，\(p(v)\) 为 Pipe。定义

\[
W_p=\sum_{v:p(v)=p}d_v,
\]

以及只保留必然计算依赖后的最长计算路径 \(CP\)。则

\[
\boxed{
L_0=
\max\left\{
CP,\;
\max_p\left\lceil\frac{W_p}{k}\right\rceil,\;
\max_v d_v
\right\}
\le M_3^*.
}
\]

**证明。** 原操作不能拆分、复制或删除；每核同一 Pipe 同时最多执行一个操作。因此任一路径必须串行完成，每类 Pipe 在 \(M\) 周期内最多提供 \(kM\) 个服务周期，单操作至少需要自身周期。Task 重建、spill、内存复用和跨核 COPY 只会保留或增加这些必要因果约束，不会减少原计算工作。最大单操作项通常已经被 \(CP\) 包含，保留它便于独立检查。

不能改成 \((W_M+W_V)/k\)：M、V 可以并行。两个无依赖、各1周期的 M/V 操作，在一核上就可同时完成；把两类工作相加会给出错误的2周期“下界”。

本轮独立处理了 **634,506 个原计算操作**。全部为正整数周期 M/V 操作；100张图中，排除原 COPY 后没有发现额外的 COPY 收缩计算边。原证书的 CP、工作量、路径见证和全部500个 \(L_0\) 均复算一致。上述依据对应冻结 E3 的计算保留、S2 的原操作序保留、S3 的单 Pipe 执行槽，见:chatgpt-content-reference{index="1"}[官方语义摘录](sandbox:/mnt/data/p3_r3_audit/output/SOURCE_EXCERPTS.md)。

因此，旧界的**全局有效性可以保留**；旧报告中引用的历史“当前成绩”则不能保留，必须与新 feed 连接。本轮已完成该500格连接核对。

## A3. 本轮新增：原计算 DAG 的“共同时间窗口工作量界”

这是本轮实际强化并逐格计算的全局证书，不使用候选归核、COPY队列或旧 trace 历时。

定义操作 \(v\) 的必需前缀和后缀：

\[
h_v=\max_{u\to v}(h_u+d_u),\qquad
t_v=\max_{v\to w}(d_w+t_w),
\]

空集合取0。任何合法执行都满足

\[
\operatorname{start}(v)\ge h_v,\qquad
\operatorname{end}(v)\le M_3(P)-t_v.
\]

对 Pipe \(p\) 和两个阈值 \(a,b\)，取非空集合

\[
S_{p,a,b}
=\{v:p(v)=p,\ h_v\ge a,\ t_v\ge b\}.
\]

这些操作必须全部在共同窗口 \([a,M_3(P)-b]\) 内执行。因此

\[
\sum_{v\in S_{p,a,b}}d_v
\le k\bigl(M_3(P)-a-b\bigr),
\]

从而得到：

\[
\boxed{
L_{\mathrm{win}}
=
\max_{\substack{p,a,b\\S_{p,a,b}\ne\varnothing}}
\left[
a+b+
\left\lceil
\frac{\sum_{v\in S_{p,a,b}}d_v}{k}
\right\rceil
\right]
\le M_3^*.
}
\]

这是完整的全局量词：集合只由**原图**决定，而非由当前方案决定。

另有一个原子操作计数界。将某 Pipe 的操作周期降序排列为 \(d_{(1)},d_{(2)},\ldots\)，则

\[
\boxed{
L_{\mathrm{atom}}
=\max_{p,j}
\left\lceil\frac jk\right\rceil d_{(j)}
\le M_3^*.
}
\]

因为前 \(j\) 个操作中，至少一核执行不少于 \(\lceil j/k\rceil\) 个，每个周期不小于 \(d_{(j)}\)。

本轮新表采用

\[
\boxed{L_+=\max\{L_0,L_{\mathrm{win}},L_{\mathrm{atom}}\}.}
\]

### 可复现算法与复杂度

只需让 \(a,b\) 分别取该 Pipe 实际出现的 \(h_v,t_v\)。对 \(a\) 递减扫描，按 \(t_v\) 排序建立线段树，叶值维护

\[
kb+\sum_{\substack{h_v\ge a\\t_v\ge b}}d_v.
\]

加入一个操作 \(v\)，就是对所有 \(b\le t_v\) 的前缀加 \(d_v\)。一次前缀最大查询便能选出当前 \(a\) 下最强的 \(b\)。

```text
GLOBAL_INTEGER_CERTIFICATE(original_graph, k):
    建原计算依赖图；核对操作类型、周期、端点与依赖投影
    拓扑遍历求 h[v]、CP；反向遍历求 t[v]
    计算每 Pipe 工作量 W[p]，得到 L0

    Lwin = 0
    for each Pipe p:
        tails = 本 Pipe 出现的 t[v]，递增去重
        线段树叶值初始化为 k * tails[j]
        按 h[v] 分组，h 从大到小处理
        largest_active_tail = -1

        for a in descending distinct h:
            for v with h[v] == a:
                对 tails[j] <= t[v] 的前缀加 d[v]
                更新 largest_active_tail

            只在非空集合对应的尾阈值范围查询最大叶值 Q
            Lwin = max(Lwin, a + ceil(Q / k))
            保存 pipe、a、b、工作量及成员身份见证

    各 Pipe 周期降序扫描，求 Latom
    return max(L0, Lwin, Latom), witnesses
```

原图处理为 \(O(N+E)\)，每个核数的窗口计算为 \(O(N\log N)\)，空间 \(O(N+E)\)；这里 \(E\) 指投影后的计算依赖边数。核数固定为1–5，只是常数倍。所有核心算术为整数，不依赖共享池浮点模型。

\]

故

\[
L_+\ge393+1106+\lceil7669/5\rceil
=\boxed{3033},
\]

强于旧界2507。

**069/k5：** 同类见证为

\]

得到

\]

## A4. 如何加入 COPY、容量、通信和共享带宽，才不犯量词错误

### 首末 COPY：可以加强，但必须先证明它对所有方案不可避免

原图强制的输入读取、最终输出，可以提供全局必要工作或头尾等待。然而必须区分：

- 每个逻辑键**至少一次**首次 miss；
- 固定归核导致的多核重复读取；
- 当前顺序造成的重载或 spill。

只有第一类天然具有跨方案的全局意义。后两类要么对所有方案取最小值，要么只作为固定方案证书。

例如067中，计算尾部的2144周期可直接纳入本轮整数窗口界：

\[
L_+=\left\lceil58\,915\,232/5\right\rceil+2144
=\boxed{11\,785\,191}.
\]

此前的11,785,739还额外使用了首末各274周期 COPY。要把它作为冻结实现的机器证书，须再补上“所有方案均需该首末传输，以及官方共享服务/浮点推进下该单笔最低历时成立”的完整论证。本轮没有补完这个数值层证明，故**未把额外548计入全量严格表**；这不等于已经找到反例推翻它。

### 容量：不能由“所有权重总和超容量”直接推出统一重复 IO 下界

“共同权重超过总 L1 或 Cache”排除的是某些**全部常驻**模型。合法方案仍可逐段装入、连续消费后丢弃；超容量本身不能证明所有方案都必须重复读相同数量的字节。

对于固定官方重建 Task 和固定 Step2 输入序列，可以用完整生命周期证明零 spill；但若要得到**全局 IO 下界**，必须证明每一种合法归核、顺序和驻留选择都至少产生相应搬运，不能把当前顺序下的生命周期峰值当成全局必需峰值。

### 通信：固定切割量不能直接加入全局界

若不附加负载或完成时间条件，把全部计算放到一核可能令跨核割为0。即使已证明必须切开一个作业，也不能直接写

\[
L_{\mathrm{work}}+500
\]

作为全局下界：这500周期可能被其他核的独立工作覆盖。必须证明等待占据了哪个不可重叠窗口。

一个可组合的目标 \(T\) 松弛接口如下。令 \(x_{vc}\in[0,1]\) 表示放置，\(s_v\) 表示计算开始，\(y_{uv}\in[0,1]\) 表示跨核指示的松弛：

\[
\sum_c x_{vc}=1,\qquad
\sum_{v:p(v)=p}d_vx_{vc}\le T,
\]

\[
s_v+d_v\le T,\quad s_v\ge h_v,\quad
s_v+d_v+t_v\le T,
\]

\[
y_{uv}\ge x_{uc}-x_{vc}\quad\forall c,
\]

\[
s_v\ge s_u+d_u+500y_{uv}\quad\forall u\to v.
\]

任何真实合法方案，以其0/1归核和真实开始时刻代入，都满足这些必要约束。因此，**该松弛不可行可以排除 \(M_3\le T\)**；可行则不能证明存在官方方案。

写为 \(Az\le b\) 后，一个可机械核对的不可行证书是

\[
\lambda\ge0,\qquad
\lambda^\top A=0,\qquad
\lambda^\top b<0.
\]

加权求和便得到 \(0\le\lambda^\top b<0\) 的矛盾。模型规模为 \(O(k(N+E))\)，给定证书用稀疏有理数乘加验证即可。**本轮没有求解这个 LP。**

这个基础松弛也可能很弱：对称分数归核 \(x_{vc}=1/k\) 可以让所有 \(y_{uv}=0\)。要加强它，需要新的有效不等式，而不是把某一个平衡切图指定成唯一合法选择。

### 共享服务：本轮保留弱而严格的证书

官方先将单笔 COPY 工作量取整，再用浮点剩余工作、公平共享、事件退休取整推进。不能直接把连续流公式升级为官方证书。

# C. 各条迭代路线的数学进步审计

## C1. 结构识别与连续划分 DP：精确的是受限目标

结构识别的可证明作用，是把原图划分成满足明确守卫的子类，并减少需要考虑的构造自由度；它不能改变原计算、原 max/sum 树或 K/V producer 的执行次数。

例如原输入 \(t\) 在各核的基础读取量，可以按

\[
I(P)=\sum_t |t|\,
\#\{\text{消费 }t\text{ 的核心}\}
\]

计算。在唯一输入及对应重建条件下，它是基础 COPY 数量的结构量，**不是包括 spill 和 Cache 后的实际 DDR 总量，更不是 Makespan**。

连续流水模型中，若 \(J\) 个同序作业经过 \(s\) 个不同核的串行阶段，段服务为 \(p_j\)，无 COPY、无容量约束，则

\[
M_{\mathrm{model}}
=\sum_jp_j+(J-1)\max_jp_j.
\]

前缀和为 \(W_i\) 时，

\[
D[j,i]=\min_{h<i}
\max\{D[j-1,h],W_i-W_h\}
\]

精确求解该最小最大连续段和问题，复杂度 \(O(sL^2)\)。

加入不能提前重叠的首次 setup \(\eta_j\)，由

\[
F_{j,1}=F_{j-1,1}+\eta_j+p_j,
\]

\[
F_{j,n}=\max(F_{j-1,n},F_{j,n-1})+p_j
\]

可推出

\[
M_{\mathrm{model}}
=\sum_jp_j+
\max_j\left((J-1)p_j+\sum_{a\le j}\eta_a\right).
\]

**这些是模型内精确结论。** 把 M/V 串成单服务台会丢失真实重叠，忽略 COPY 又会删除真实成本，两种误差方向相反，因此整个模型未必是 E0 的上界，也未必是下界。冻结 `shared_pipeline.py` 本身已明确这一边界。

044/k4的40,927→37,581支持该实例的合法切分改进；它不能反向证明静态容量代理或冷 setup 模型普遍正确。

## C2. 容量与生命周期：需要从“原 tensor”升级到“重建后的物理 ID”

固定重建 Task、固定 Step2 输入序列时，令物理 tensor \(t\) 首次和末次使用位置为 \(f_t,l_t\)。若每池满足

\[
\forall i,\qquad
\sum_{t:f_t\le i\le l_t}|t|\le C,
\]

且集合覆盖官方生命周期处理的全部对象，则可证明 Step2 不需要 spill。闭区间必须保留“新输出已分配、末次输入尚未释放”的瞬态。

更强、更容易验证的充分条件是

\[
\sum_{\text{该Task全部相关物理ID}}|t|\le C.
\]

但必须计入原 DDR 的本地 UB 视图、自动 COPY 端点、跨核直接边新增 UB 桥，以及每核副本；不能按 logical ID 跨 Task 去重。

若再满足每个物理 ID 至多分配一次、无 spill incarnation，而且总支持覆盖 Step3 的全部分配对象，则初始 VIRGIN 信用足够完成全部首次分配，故不会消费回收信用，也就没有 `MEMORY_REUSE` 边。

**反方向不成立：零 spill不等于零内存复用约束。** 本轮044两份计划都为 spill 0，但结果各自报告核2有 **167条内存依赖**。更不能从零 spill推出更小 Makespan。:chatgpt-content-reference{index="9"}[保存结果核验](sandbox:/mnt/data/p3_r3_audit/output/mechanism_audit.json)

所以原 `shared + max(single-op nonshared)` 仍只是代理：跨越当前操作而活着的残差不在该操作 incident footprint中，代理可能漏计。

## C3. 森林峰值排序：交换论证成立，但最优性范围必须写完整

固定原树、固定归核，要求每个子树完整执行、子树间不交错，内部结果没有额外消费者。设孩子 \(i\) 的内部峰值为 \(h_i\)，完成后保留量为 \(r_i\)，且 \(h_i\ge r_i\ge0\)。

若

\[
h_i-r_i\ge h_j-r_j,
\]

则

\[
\max(h_i,r_i+h_j)
\le
\max(h_j,r_j+h_i).
\]

右侧的 \(r_j+h_i\) 同时不小于左侧两项，因此相邻交换不会恶化峰值。连续消除逆序，得到按 \(h_i-r_i\) 递减的最优孩子顺序。

父节点峰值递推为

\[
h_v=
\max\left\{
\max_j\left(\sum_{i<j}r_i+h_j\right),
\sum_i r_i+\operatorname{outsize}(v)
\right\}.
\]

排序部分复杂度为

\[
O\!\left(N+E+\sum_v\deg(v)\log\deg(v)\right).
\]

这是**内部输出 frontier、非交错子树模型中的最优性**；不覆盖外部输入、双存储池、共享权重、所有合法交错或官方时间。当前两个冻结完整版本24格周期改善、476格持平，只是版本级证据，不是森林模块单因素消融，更不是未来输入上的不退化定理。

## C5. max-plus释放包络：可以组合固定服务，不可以隐藏状态变化

固定局部 DAG、固定服务时长，外部释放向量为独立的 \(\mathbf r\ge0\)。从

\[
F_v=d_v+\max_{u\to v}F_u
\]

递推，出口必可写成

\[
F(\mathbf r)
=\max\left\{\theta,\max_j(r_j+\lambda_j)\right\},
\]

其中 \(\theta\) 规范化为 \(F(\mathbf0)\)。

对相同变量域的两个规范化包络，

\[
F_A(\mathbf r)\le F_B(\mathbf r)\quad\forall\mathbf r\ge0
\]

当且仅当

\[
\theta_A\le\theta_B,\qquad
\lambda_{A,j}\le\lambda_{B,j}\quad\forall j.
\]

充分性逐项比较；必要性分别令全部释放为0，以及某一变量单独趋于无穷。

这使完整函数比较替代少数释放时刻采样。单释放时，可压缩成四系数响应；多释放一般要保留向量，通用计算成本为 \(O(r(N+E))\)，特定串行 FIFO 模型可用前缀和、后缀最大值线性求系数。

**状态合并的充分条件不能省略：** 后缀必须只依赖当前状态；相同后缀对更早释放单调；切点不能另行改变后续容量、Cache状态或服务历时。真实残差包含多个跨核端口时，单个“上一段完成时刻”通常不够。

同理，h=2/15/17的模型非支配包络只说明在固定服务、独立非负释放域中不能互相淘汰，不代表h=15在真实 E0 中全局最优。

## C6. 部分预加载：闭式正确，新增实测也成立，但因果归因要收紧

在单激活 \(R\)、固定冷读服务 \(w_r\)、串行计算总量 \(C\)、激活传输 \(d_a\) 的模型内，设 \(U_r=\sum_{i\le r}w_i\)，首次消费前计算量为 \(\pi_r\)，则

\[
\boxed{
T(q)=\max(R,U_q)+d_a+C+
\max\left\{0,\max_{r>q}(U_r-U_q-\pi_r)\right\}.
}
\]

最后一项是逐消费的最大累计加载欠账；串行链仅在缺输入时等待，恰能实现它。用前缀和与后缀最大值可在 \(O(m+|\mathcal Q|)\) 内选出**已证明合法断点集合**中的模型最优断点。

反例同样清楚：

\[
w=(1,8),\quad\pi=(0,2),\quad d_a=1,\quad C=3.
\]

\(R=1\) 时，部分/全预读为11/13；\(R=10\) 时为20/14。早启动计算并不总是早结束。

若考虑预读反向拖慢上游，只能在更严格的封闭两流模型中，用供给曲线 \(Y(x)\) 写

\[
T(x)=d_a+C+Y(x)+\max(R_0,x)+(\Delta-x)_+.
\]

其中 \(Y\) 在上游DDR段斜率为1、非DDR段为0；相应模型可只比较拐点两侧最近的合法断点。**044具有多核流、中途残差和其他读写，不能未经守卫直接套入这个两流公式。**

## C8. query-flow：两次跨核定理需使用“全原边阶段单调”

令阶段为 \(S<P<A<O\)。在同一固定 owner 和增强计算 DAG 上，要求：

\boxed{L_\delta\le L_{\mathrm{zero}}+2\delta.}

## D1. 可以严格证明认证间隙单调

固定输入、核数、官方身份和有效全局界 \(L\)。令

\[
U_t=\min\{M_3(P):P\text{截至 }t\text{ 已合法、成功官方验证}\}.
\]

只接受更小E0值，则

\[
U_{t+1}\le U_t.
\]

因此下面各量均不增：

\[
U_t-L,\qquad
\frac{U_t}{L},\qquad
1-\frac{L}{U_t},\qquad
\frac BL-\frac B{U_t}.
\]

而已取得加速比 \(B/U_t\) 不减。这里比较的是**相同身份下的同一实例**，不是不同输入或不同配置之间。

若不断产生新的有效全局界 \(L_t\)，使用历史最强界与历史最好可行值：

\[
\widehat L_t=\max_{s\le t}L_s,\qquad
\widehat U_t=\min_{s\le t}U_s,
\]

便有嵌套区间

\[
[\widehat L_{t+1},\widehat U_{t+1}]
\subseteq
[\widehat L_t,\widehat U_t].
\]

区间长度不增。若出现 \(\widehat L_t>\widehat U_t\)，应立即检查证明、记录身份或实现，而不是解释成“超过理论最优”。

但这些结论**不包含**CacheGain、spill、搬运或求解墙钟单调。只按M接受，不是多指标Pareto接受。

## D2. 为什么不等于收敛到全局最优

单调有界只说明存在极限

\[
U_t\to U_\infty\ge M_3^*,
\]

不说明等号成立。周期为整数时，严格改善的接受次数有限，数值最终会稳定；算法仍可能不断尝试无改进候选，甚至不保证自身有限墙钟终止。

最小的局部搜索反例是邻域路径

\[
A(11)\;-\;B(12)\;-\;C(10).
\]

从A出发只接受严格改善，就不能经过B到达全局最优C。即使没有坏中间点，候选生成器从未提出C，也一样不能保证找到它。

要声称全局收敛，至少还需证明某种额外机制：所有必要方案被完备覆盖；或每个非最优点都存在且必能找到可接受的改进邻居；或得到有效全局近似比；或取得明确终止证书。最直接的最优性终止证书是

\[
U=L,
\]

若目标为整数，\(0\le U-L<1\) 也足够。**本轮500格都没有这种证书。**

因此，适合论文的表述是：

> 算法以严格官方Makespan接受准则维护可行上界，独立全局松弛维护下界；在身份固定和证书有效的条件下，所得认证区间单调收缩。该性质不保证区间收缩到零，也不保证候选构造收敛至全局最优。

# E. 给第四个综合咨询的P3可组合接口

## E1. 六层接口，而不是把所有东西压成一张固定权重DAG

建议统一为

\[
\boxed{
\text{原DAG}
\to\text{合法两字段计划}
\to\text{官方编译}
\to\text{资源事件系统}
\to\text{松弛证书/可行结果}
\to\text{官方身份验证}
}
\]

使用共享符号 \(P=(\phi,\kappa,\sigma)\)：\(\phi\) 是操作到子图，\(\kappa,\sigma\) 由 `core_schedules` 同时给出。它不是额外提交字段。

| 层 | P3应输出的数学接口 | 必须保留的边界 |
|---|---|---|
| 原图 | 原操作、周期、Pipe、tensor、原依赖、图哈希 | 计算原子性；不得重写树、拆分或复制计算。 |
| 合法提交 | 两字段字节、计划哈希、覆盖/子图/归核/顺序 | 可表达顺序不等于任意Pipe队列或时间戳。 |
| 官方编译 | 每核Task、物理ID、COPY、Step2扩展序列、四Pipe顺序、内存边 | 分桶不是运行时barrier；物理ID不能按逻辑键合并。 |
| 资源事件系统 | 固定因果/FIFO，加DDR池、Cache池、查询/插入状态与500释放 | 一般不是固定权重DAG；历时受全局事件状态影响。 |
| 证书与构造 | 全局松弛见证，或固定方案界；另保存合法可行结果 | 必须标明全局/受限/固定/模型量词；下界不是方案。 |
| 官方验证 | graph/config/code/plan身份、M、搬运、spill、hit/miss、墙钟及调用账 | 记录绑定、原件解析、重新E0是不同验证层级。 |

固定计划若保留**重建图、全部操作/物理ID、完整Step2输入序列和配置**，后续确定性编译及模拟结果保持一致。这是可复用的安全编译不变量。只保留M/V顺序或只减少子图数不够；044两轮粗合并与部分预加载恰好说明COPY顺序的重要性。
