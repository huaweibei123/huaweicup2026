## 如何选工具

先用 Python 和冻结官方评估器复现最小现象，再按需要用 MATLAB 的实际可用求解器做小规模优化，或用 Wolfram 做符号化简、有限枚举和猜想检查。工具计算结果必须回到官方事件、FIFO、资源约束和浮点语义中验证，不能用理想化数学模型的结论替代 E0 等价性。

有足够批量、适合并行的负载或明确训练收益后再选 Colab/CUDA；对当前短 CPU 搜索不强行增加上传、排队和环境成本。Pro 专项以明确状态、目标、已知失败、待证性质和可运行小实验为输入，不因高级术语或资源丰富而另开无边界研究。
