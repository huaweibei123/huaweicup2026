# Pro 反馈第一阶段：结构守卫与物理容量证书

目标是修复 gap 路线忽略容量而放大 DDR spill 的退化，同时保留其在其他图的收益。这是容量层 F1，不是 Pro 建议的完整容量/DDR队列联合 FQ。独立公开问答和原件位于 `AI chats/P2-capacity-ddr-6ab57979/`，静态语义复核位于 `docs/a/q2/PRO_CAPACITY_AUDIT_20260925.md`。公开回答的自报成绩与本机新实验分开；L/U 浮点严格性尚未补完，不作为本轮验收证书。

## 确定的构造规则

1. 保留 TensorIndex 的唯一原始 producer 守卫；logical_tid alias 沿用原 gap 构造，不给容量证明。
2. 优先检查既有同构 M→V*→M、首尾 M 时长相等且 V 总时长≤2M 的 `word_descriptor`。它允许已由链覆盖的捷径边，因此图上出现分叉和汇合不一定代表应该走通用 gap。构造既有 `resource_word`，仅在物理桶包络通过时直接返回。该规则用结构和配置，不查图号或保存成绩；复用原方法而非宣称重新发明。
3. 其余情况构造唯一原 gap 计划。将每核 eligible 输入/输出触碰的 tensor 规范成物理 token；原 DDR 本地副本记 UB，异核 direct 边另外建两个本地 UB token；一 tensor 多目的核仅源空间计一次，基础 COPY 服务仍按源/目的核对计账。
4. 对实际单操作子图优先序统计每个 token 的首/末桶闭区间；每桶先同时占用输入和输出，再释放末次触碰。输出每核每池峰值、峰值桶和可核对的 live token 证据。该包络包含桶内 COPY，因此通过是 Step2 无 spill 的充分条件；不宣称它等于最后全局并行峰值。
5. 已通过的核完全保留。仅对未通过且完整弱分量同核的核生成一次保守重排：先用已有 S+W·P 窗口；若永久共享预留不能容纳一个分量，按真实共享输入签名分组，各组计算窗口。拼接后的**完整核序**必须再通过 footprint。三角交叠等结构不能在组边界假释放共享 tensor。
6. 分量跨核、单组无法准入、完整序仍超额时保留该核原序并记录 unresolved。采用的重排再次通过完整物理证书和官方结构合法性派生。只输出 node_to_subgraph/core_schedules，不增 IDLE/SPILL/控制边；0 在线 E0，无成绩选优。

## 时间和适用域

物理 token 构造及事件扫描 O(V+E+I)，此外有已有索引、合法性派生及签名排序成本。组内窗口≤8，pipe_window 每个操作只在有界 active 集合中取下一步。普通路线仍付出原 gap 的预处理与日历成本，故不能预称总求解更快；word 结构早退有机会省去通用 gap 日历。所有预处理、证书、回退、校验和落盘仍计入冷进程 solver wall time，外部 E0 另计。

返回 capacity_certified=false 并不证明该计划必定 spill：桶包络是保守充分证书；也不表示全图无解。split-component 的容量重排、真实 MTE FIFO/全局 DDR 公平共享预测、小前沿 DP 和完整 FQ 尚未实现。保守修复可能牺牲并行，必须保留负结果。

## 预注册的最小实测

只运行固定 F1 六格：008/k3、095/k3、025/k3、036/k3、072/k3、014/k5。前五格一个单 worker 批次，尾部效率案例另一个批次；全轮最多6 solver、6外部E0，无自动重试，不重复计算旧 tensor/gap 参考。每次 solver 外部60s、E0外部90s，每批900s、收尾保留15s，RAM门槛沿用既有1.5GiB；通过与队友的边界协调串行启动。这里60s是本地实验watchdog，不是官方题面限制。

主验收关注：008/095 消除声称已认证域内的 spill 且 M≤旧tensor的1.01倍；025/036 M≤固定gap参考的1.01倍；072 未认证时给拒绝原因，不冒充解决；014 一次失败如实记 null、保留成本。非法输出、证书通过而实际出现 spill、源码身份变化或监督故障即停止相关路径推广；六格通过仍不代替固定算法的100图/500格回归。禁止将每格新旧较优值拼成可部署算法。

在6格之前，根会话执行25项小测试通过，涵盖跨核token、closed bucket、零字节direct、共享三角、早期word路由、别名守卫及原容量/gap回归；0官方大图/E0。独立审阅与官方小图前缀差分结果另见 FRONTIER_GAP_REVIEW.md。
