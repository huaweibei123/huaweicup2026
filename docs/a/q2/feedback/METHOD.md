## 新构造与可验证范围

先用官方依赖工具收缩 COPY，确定 eligible DAG。每个弱连通分量视作作业，其内部取最小 ID Kahn 拓扑线性扩展；这是为产生优先级而增加的顺序，不断言原分量实际串行。按四类计算 Pipe 工作向量将整个作业分到核，减少跨核 eligible 数据边。所有策略共享这一分核和 mapping。

`pipe_window` 每核只准入 W 个作业，默认

`W = min(J, 8, 1 + ceil(总计算工作 / 最大Pipe总工作))`。

这是计算占用启发式，不是容量证书或 Little 定律对官方系统的精确应用。对008/084/095给出 W=3。每个已准入作业只暴露拓扑链下一操作；其理想可开始坐标是 `max(作业前项结束, 对应Pipe空闲)`。选坐标最早者，同分优先剩余工作较少者、再按原 ID；排完该作业的末项后，将其理想完成坐标作为下一个作业的准入时刻。只将得到的拓扑序编译成 singleton 优先级，时间坐标丢弃。

它与已有全 ready `earliest_start` 的区别是：完整作业分核、滚动准入窗口、作业内拓扑链降低以及完成后开放窗口。它不是全图节点分核的新通用求解器；只有一个巨大分量时可能只用一核，应在后续 portfolio 保留已有通用分核算法。

正确的结构主张：每个分量的内部拓扑次序保持，分量间无 eligible 依赖；singleton 商图仍是原 eligible DAG，因此方案层依赖成立。实际 COPY桶、Step2溢出/化身、Step3内存复用/FIFO依赖及全局模拟仍完整交E0，不用纯计算估算替代。

复杂度：官方 COPY 收缩的成本单列；对已收缩图，Kahn及分量/分配 `O((V+E) log V + J K)`，窗口调度 `O(V W)` 且 `W <= 8`，存储 `O(V+E)`。四个构造是预先指定的科学对照，非在线暴力搜参。算法只读图生成一个方案，不调用 E0/E1/E2；同机外部测量另报。
