# 连通归约树的精确标量切分

这是 P2 官方调度的一个受限子问题，不是完整 Makespan 最优性定理。实现为 `src/q2/feedback/tree.py`，入口 `construct --strategy tree_dp`。事前开发对象仅 002、062、063：三个图均为单弱连通 DAG，每个操作至多一个后继，因此是向唯一汇点归约的 in-tree。

## 子问题和动态规划

设 n 个顶点的正整数权重为 `w(u)=max(1, cycles(u))`。删除 k−1 条树边得到恰 k 个非空连通块；目标是最小化最大块权重之和 C。k 取 requested cores 与 n 的较小值；空余核仍保留其输出条目。

对整数阈值 B，自叶向根处理。`D[u,c]` 是 u 子树已关闭 c 个块、仍连接 u 的开放块的最小权重；所有已关闭块及开放块的权重均不超过 B。不可达记无穷。初始只有 `D[u,0]=w(u)`，若 w(u)>B 则失败。

合并孩子 v 时，给定父侧 `(a,x)` 与孩子侧 `(b,y)`，只有两种可能：

- 保留 v→u：若 x+y≤B，更新 `(a+b,x+y)`。
- 切断 v→u：孩子开放块关闭，更新 `(a+b+1,x)`。

只保留 c≤k−1。根的 `D[root,k−1]` 可达，当且仅当存在合法的 k 连通块切分。

**充分性**：每次转移都对应一个具体切/留边决定，且保证涉及块的容量。归纳合并全部孩子即给出真实可行切分。

**完备性与支配**：树的连通性保证任一切分在每个已处理子树中恰有一个可能连接祖先的开放块，其他块已关闭。每条父子边必为切或留，因此上述两种转移穷尽可能。固定已关闭块数时，较小开放权重支配较大权重：未来仅可能增加非负孩子权重或关闭该块，较小权重永远不会损失容量可行性；过去已关闭块不再参与合并。因此不必保存其余更大开放权重。这里未带边通信成本、pipe 向量或调度时间，支配结论不能直接推广至这些多目标状态。

**最优性**：阈值可行性随 B 单调。下界为 `max(max_u w(u), ceil(sum w/k))`，上界 sum w。在该整数区间二分到首个可行 B，再沿转移回溯 k−1 条切边，得到标量子问题的精确最优 C。单次合并最多 O(k²)，全树 n−1 次；总时间 O(n k² log(sum w))、存储 O(nk)，最后回溯的各层选择总量同为 O(nk)。k≤5。

## 从切分到官方计划

每个连通块放在一核，保留 singleton 子图。树按子树总计算工作降序做深度优先后序，将其限制到各核，得到合法的核内拓扑优先级；所有节点恰出现一次。树边被切不改变依赖，官方会插入跨核 COPY。由冻结 `derive_multicore_plan` 再验证计划结构。

深度优先使每个子树先完成后向父节点交付，但“较大子树先”仅为确定性规则，不宣称张量驻留最小或官方 Makespan 最优。真实目标还包含每 pipe 并行、跨核 COPY 与 500 cycles 延迟、共享 DDR、Step2 spill 和 Step3 重排。标量 C 既不是实际 Makespan，也一般不是允许任意非连通分核时的下界。

## 可证伪验证与首批协议

独立测试枚举小树的全部 k−1 条切边组合，与 DP 比较；随机种子 20260924，n=2～9，每规模 5 棵树，k=1～min(n,5)，权重 1～40，验证最优值、块数及回溯。该枚举仅是小规模测试 oracle，不进入求解程序。另检验官方 002 的 1～5 核结构合法性及 044 结构守卫拒绝。原有 6 项与新 3 项结构测试共 9 项通过（1.314 秒，0 E0）。

首批只跑 002/062/063、requested4、一个 `tree_dp` 策略：最大 3 solver、3 独立未修改 E0、单 worker、每进程 60 秒、批次 600 秒含 15 秒收尾、不重试、首个意外失败即停止。旧方案来自固定已有证据，不重跑作为预算外对照。本机其他会话评分窗口结束后才能启动；普通系统负载和 OS 缓存不受控，不能称独占重复性能实验。

结果无论正负均用于拆分两个假设：DP 是否正确解标量切分（上述证明与小例 oracle），以及这种切分是否改善真实 P2（由保存的官方 E0 原件决定）。不能拿第一项的证明替代第二项实测。
