Source reviewed at `675fdcb4f6527336f35ca3ec870bf59544485324` only. This is a source review; no constructor, solver, evaluator, test, Colab, or Pro run was made. Token usage is unavailable. Read scope: the six assigned files plus the directly called `reverse_gap_candidate.py`.

## Findings and limits

1. **The four-start guard is present for this wrapper.** `adaptive_bidirectional_guarded.py:21-33` counts before invoking the injected oracle, deduplicates equal complete plans, and rejects a fifth distinct start. The forward route constructs at most three distinct candidates (`adaptive_hypergap_guarded.py:26-27,76-89`), so there is room for at most one new reverse score. The reverse is constructed once (`adaptive_bidirectional_guarded.py:67-76`); its score is compared against the forward winner, with a strict lexicographic improvement required (`:79-103`). Ties retain the incumbent. `adaptive_guarded.py:315-318` passes the same four-request limit into the persistent E2 adapter. This is a **per solver invocation** bound; it is not an E0 evaluation budget or a full-run wall-time claim.

2. **Unknown and exception handling is deliberately conservative at the CLI boundary.** A forward construction/score uncertainty returns `score_evidence='unknown'` (`adaptive_hypergap_guarded.py:34-38,50-54,58-61,68-72,88-93`); the wrapper skips reverse construction on that evidence (`adaptive_bidirectional_guarded.py:63-65`). Reverse construction failure or unavailable score retains the incumbent (`:67-72,83-95`). The E2 adapter persists a request before crossing the boundary and leaves an uncertain exception in flight (`adaptive_guarded.py:189-220`); the CLI refuses output on unknown evidence or an in-flight request (`:319-321`). A native `ok` P2 score is required (`:236-241`), and only nonnegative integer score pairs are accepted (`guarded_component.py:21-30`). Thus a reverse score failure can be a failed solver run, rather than a usable incumbent fallback, when E2 request outcome is uncertain. Minimal subsequent check, if this behavior matters operationally: inspect one retained `solver.json` from an actual failed request; do not launch new evaluations merely for this review.

3. **There is no unconditional added-DDR non-regression guarantee.** Scores are ordered `(makespan, added_copy_bytes)` (`guarded_component.py:27-30`); the reverse wins whenever that tuple is smaller (`adaptive_bidirectional_guarded.py:98-101`). A lower Makespan can therefore select higher added DDR; the existing injected-oracle test explicitly exercises `(100,10)` incumbent versus `(90,20)` reverse (`tests/test_q2_bidirectional_guarded.py:19-20,45-52`). DDR only breaks equal-Makespan ties (`:56-64`). The submitted plan receives a structural derivation check, not a final official E0 score certificate (`adaptive_guarded.py:319-327`). Any reported official DDR comparison requires the actual final E0 results for those plans.

4. **The frozen five-cell pilot does not exercise the online wrapper.** `q2_reverse_generalization_pilot.py:89-102` invokes `src.q2_nikolastarx.reverse_gap_candidate` directly, and asserts zero internal E0/E1/E2 calls. It then runs external E0 once on that candidate (`:103-118`). The archived comparator is hash-checked and its saved score read (`:41-54`); it is not passed to `adaptive_bidirectional_guarded.build`. The script itself labels scope as one raw-input candidate versus a frozen seed (`:55-61`). Therefore completed pilot rows can test reverse-candidate generalization on five selected k=5 cells, subject to their retained artifacts, but cannot establish wrapper selection, its four-call behavior on real inputs, online solver time, or a fixed-algorithm full-case result. The minimum next validation for an online-algorithm claim is a separately budgeted run of the wrapper entry point with retained plan, ledger, and final E0 result; the five-cell pilot should retain its narrower label.

No source change is proposed from this review. The only substantive claim to correct, if made elsewhere, is that this wrapper guarantees DDR non-regression or that the five-cell pilot measures the wrapper itself.
