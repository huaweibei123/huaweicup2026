# 固定计算 FIFO 的生命周期优化：研究问题

这是候选研究域，不是已通过官方评价的算法。当前 c665 的全500额外DDR比固定前版增加36.66%；两格只读分解表明072/K5与014/K2的内部跨核tensor COPY分别从0增至65,411,636与52,042,756 B，同时spill增加。固定归属的穿插优化不能消除这些新增跨核字节，目标仅是先降低spill，保留当前计算分配与Pipe顺序。

## 可提交自由度与不变量

P2最终只提交singleton映射和每核子图优先序。冻结每个原计算op的core以及该core上每条Pipe的非COPY投影序列，仅改变不同Pipe操作在优先序中的穿插。预Step2 mandatory COPY计数只依赖归属，因此不变；`fifo_bound.py`的原计算依赖+计算Pipe FIFO图不变，因此其必要下界不变。**COPY FIFO、Step2 spill及MEMORY_REUSE/credit仍可能改变，官方M不受不退化保证。**

先在原DAG加固定计算Pipe链的全局拓扑序中选取下一就绪操作，再投影到各核，可保持新全核总序与原DAG无环。每核独立重排则不能直接假定跨核安全。

容量模型沿用 `zero_spill_intervals.py` 的守卫：无logical alias、唯一物理producer、singleton、所有依赖已表示。各core分别跟踪tensor从第一次到最后一次本地触碰的闭区间；DDR输入映到UB，分配先于本次释放；跨核直接边在端点加瞬时UB容量。模型峰值改善不等于官方spill字节改善，仍需E0验证。

## 两条固定链的精确子问题（待审计）

单核只有固定M/V两条序列，长度m、n；状态(i,j)代表两条序列已经处理的前缀。tensor t的两条链首末触碰位置为a_M,a_V,b_M,b_V，缺失首位置为正无穷、缺失末位置为0。处理完前缀后仍存活的字节可写成：

L_p(i,j) = sum_{t in pool p} s_t * [1 - 1(i<a_M and j<a_V) - 1(i>=b_M and j>=b_V)].

边(i,j)->下一操作u的分配峰值还应加上第一次触碰tensor的字节与直接边瞬时容量，之后才释放本次末用tensor；不能仅以顶点L判断可行性。对无直接边的顶点函数，混合二阶差分似为非正（Monge）；这**尚不推出**两池边峰约束有线性/近线性最优路径算法。

完整网格DP可以求这个模型内是否存在无spill路径、或最小化容量峰值，代价O(mn)。两条链都上万操作时，需要证明有效的状态压缩或明确受限的走廊DP，不能把任意beam/窗口称为精确全域最优。

多核嵌入可考虑一次只优化一核、固定其他核的完整优先序，将经其他核传播的依赖投影成当前M/V前缀下界；是否可在线性图遍历中得到充分约束，以及何时原增广图有环，仍需证明与反例。全局ready的内存贪心是另一个轻量启发式，不宣称最优；它直接保留全局拓扑见证。

## 验收与边界

检查owner与每Pipe投影逐项相同、mandatory字节相同、原依赖+新各核顺序无环、模型峰值与独立闭区间计数一致。使用非编号特判的确定性构造，固定输入seed生成规则；最小实图验证后才考虑冻结新完整算法的全100×1–5核评分。不得拼接已有不同算法的历史赢家，不得把固定计算FIFO解释成完整事件图固定。
