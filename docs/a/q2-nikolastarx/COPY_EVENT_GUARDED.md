# 统一 COPY-event 守门算法

固定规则：先从当前图在线运行 c665 的 baseline / gap / hypergap 构造与精确选择，再对所选计划构造一个固定分核 COPY-event 重排。只对不同的完整计划评分，合计最多四次，按 (官方 Makespan, added DDR bytes) 严格字典序接受；平局保留原解。只有一个未评分原解时，先评分原解再评分重排。输入仅为图、核数、固定配置，不读 case ID、历史赢家、测试成绩或预制种子。

任一评分未知后停止追加请求，CLI 在写出方案前拒绝不确定的结果。正常不支持的结构保留已有构造。该规则是可提交的统一算法，但尚未完成新的 full500，不能将三个机制试验合成全题成绩。闭区间证书此时仅是独立诊断，未进入选择规则。

Linux E2 使用与 macOS 相同的 603b 源文件，显式要求冻结收据 SHA、Linux 二进制 SHA，核对固定清单的 50 个源文件、平台与 ABI。macOS 默认固定二进制与检查路径保留。构建和 ABI 检查只证明身份/可加载，数值一致性须另以固定方案的 E0 对照证明。求解在线预处理与评分均计入端到端时间，独立 E0 另列。
