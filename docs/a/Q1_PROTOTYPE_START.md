# 情况 A：首个可运行原型

本会话开始研发 Q1，以官方评估器选择真实可提交方案。第四路 Pro 的追问答复已收到，但仍主要讨论 Q2/Q3，没有完成要求的勘误影响审计；其证书、增量等价与实验数字不作本地已验证结论。

## 决策与约束

Q1 的决策是非 COPY 算子的 Task 分区、Task 核归属和每核 Task 顺序。Task 内部的 Step1/2/3 由官方程序确定。当前原型不提供任意内部算子重排接口。

取非 COPY 算子 DAG 的一个拓扑序，按连续区间切为 Task，并使每核 Task ID 递增。商图数据边和每核串行边都严格向前，因此它们的并图无环。这是一个明确受限的候选族，不是对完整搜索空间的等价化约。

第一版采用四个候选：官方随机 stub、整图单 Task、固定 64 算子分块加随机核分配，以及同一固定分块加预计最早完成核分配。最后一项用官方编译得到的局部 Task makespan，以及配置中的同核/跨核等待构造代理。共享 DDR 会改变并发执行耗时，所以该代理只提议方案，不能作为精确评估器或拒绝候选的依据。四个候选全部调用未修改的官方 Q1 CLI，保留所有成功和失败记录。

不能以同核驻留替代 Task 边界搬运；不使用被勘误否定的无条件 spill COPY_OUT 规则；不以核数变化加工作量变化推断单调性。后续尝试按真实 Task 边界通信量选择切点，再用 E0 验证粒度和并行收益的取舍。

## 结构化构造与三例开发验证

`--structural` 增加五个候选：非分叉链包、弱连通分量，以及链包经过三个合并策略后的方案。它们与前四个候选组成九候选组合。链/分量先在商图上按剩余计算工作量决定共同拓扑序，再用官方编译的局部 Task 时长决定核归属。代理时长只用于构造，所有候选都跑完整 E0，没有依照错误 spill 公式筛除。

合并只发生在同核相邻 Task A、B 之间。令 H 为全部数据依赖加全部核链的 DAG；如果删去 A→B 后不存在 A 到 B 的路径，收缩这条边不会引入环。每次收缩重新构造拓扑检查，不假设影响只在局部。保护版本还禁止合并 A 有远端后继的情况；这是防止推迟出口释放的启发式，不是收益定理。源码注明其思想来自第一路 R3，代码独立实现。

四项图层回归覆盖替代路径阻止收缩、出口保护的差异、含空核的组合环，以及 64 个四节点前向 DAG × 16 种核归属的合并合法性；用冻结官方校验器核对。它们不代替真实 Task 执行验证。三个 `*-structural-v1/` 目录保留每个方案、E0 full/trace/log、源码及输入哈希和生成命令，汇总在 `structural_summary.json`。

限制：局部编译用于分核时尚无超时隔离；合并器逐次重建图，当前优先可核对性而非大图复杂度。尚未做全 100 图、不同核数、独立留出集或搜索总预算公平比较；下一步不是宣称完成优化，而是使用正式批量接口降低核心分配/顺序邻域的精确评价成本。

完整 E0 输出以各目录的 `execution-evidence.tar.xz` 保存；其 manifest 逐文件记录哈希，展开后可恢复原来的 result/trace/stdout/stderr/log。原始 stdout 保留程序实际打印的路径，不将其混入可移植运行命令。实际运行的代码快照在 `source-structural-v1/`，与三个实验记录中的源码 SHA 一致；早期四候选版本也按原 SHA 复原保存。
