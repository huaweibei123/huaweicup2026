## 数学结论的复核

1. **同核相邻二分的结构合法性。** 假设父计划的数据依赖与全部核内相邻边联合无环，计算依赖按官方 COPY 收缩，两个非空新 Task 原位相邻 P→Q，其余成员、归属及顺序不变。P 是内部偏序理想当且仅当新 Task 增广图无环。必要性来自任何 Q→P 依赖与核链 P→Q 成环。充分性：若新环包含外部 Task，将 P/Q 缩回 T、删除内部自步即得父图非空闭合走法；仅在 P/Q 内的环则必有 Q→P。两者矛盾。此证明不保证内存/FIFO 执行成功。
2. **释放标签是门控，不能加算子工期。** 将本核上一 Task 结束加配置等待，与各操作外部异核前驱的冻结释放取最大，再沿内部依赖取最大传播。标签子水平集是相应门控下唯一最大理想。d 个不同标签至多给 d−1 个非空真最大理想；不代表它们支配同阈值内的其他理想。父计划变化后标签作废。
3. **精确的 pre-spill 增量。** 对父成员 V、前半 P 和原张量 t，J 是它在 V 内的消费者。生产者不在 V 时，共享输入在两半都使用，增加一份 size；生产者在 V 时，把生产者和 J 作为一个 net，跨两半增加 `(2-b)*size`，其中 b 表示父 Task 原来因外部消费者、原 COPY_OUT 或最终输出而已需要写出。故总增量是上述非负超边割之和。已逐项对照冻结 P1 builder 的 `input_boundary/output_boundary` 原始谓词（该文件第122–159行）。必须按原 tensor ID 计费，不能按 logical_tid、旧 backing 或收缩后的依赖边重算/合并。
4. **最小割精确的只是代理子问题。** 每个 net 用两个辅助点和一次有限割边计费；反向无限依赖边保证理想，源边表达可加工作奖励，强制集合/理想上界限制可选成员。最小化 `denominator*新增字节 - numerator*可加工作`。对固定约束、严格正工作权重，不同价格的最优集合嵌套：分别和交/并比较最优性，再用次模性，即迫使低价集合不存在高价集合之外的成员。但有限价格取样不覆盖所有断点，标量化也不覆盖所有离散 Pareto 点。

以上第3项采用单生产者张量条件。多生产者输入显式拒绝；不能静默套公式。理想上界和强制集合必须与同一个内部 DAG 匹配。零 spill、较少 COPY、更多提前工作均不能当 makespan 支配规则。

## 本机已经做了什么

独立模块 [`src/q1/release_ideals.py`](../../src/q1/release_ideals.py) 不导入 evaluator，提供：

- 确定性拓扑检查、依赖闭包、冻结释放标签及增量阈值桶；

- 可选的整数最大流部分理想构造，使用仓库已有锁定 SciPy 的 Dinic 实现，无新依赖；
- 单生产者、完整计算成员、正整数工作、理想约束和容量溢出的显式守卫。

模块尚未接入正式输入适配器、默认 `profile_candidates.py` 或 E2。调用方仍需提供官方收缩图、合法父增广图、身份绑定的测量时间线，以及将成员变为标准 plan 的逻辑。此处没有暗中接受旧 Pro 构造器代码，也没有使用其理想模型代替官方模拟器。

## 复杂度与接入边界

当前确定性拓扑用堆，O(m+n log n)；闭包 O(n+m)；标签分桶 O(n+d log d)，阈值割扫描 O(p+d log d)，其中 p 为 net pin 总数。一次最大流网络节点 O(n+h)、边 O(m+p+n+h)，h 为net数；Dinic一般最坏 O(V²E)。不是整套求解器近线性。当前每次 `split_nets` 都重新构造原图索引，跨 Task 的共享只读索引仍需在适配层复用。物化完整计划、SciPy冷启动、局部编译、评分和最终确认均属于线上成本。

容量守卫保守限制有限总容量小于2³⁰；超域时抛错、跳过该价格，并保留直接阈值/出口候选，不能用浮点近似偷偷代替精确子问题，也不能宣布该 Task 没有好拆分。整数公因子缩放等优化尚未实现。

下一步接入顺序：先校验官方计算图/父结果身份并从所有 Task 扫描释放机会；再按来源保留少量旧前缀、最大理想、部分理想和完整出口闭包；以成员集合及相同计划生成规则去重。候选上限是明确工程预算，不是最优覆盖证明。收益实验需冻结候选集合，比较相同评价次数和包含生成/初始化/编译/复核的总时间；原008共同实验的2次预算已用完，不向本项挪用。

E2 作为可替换评分后端，适合固定划分的成组核序/归属候选；二分改变划分时须重新编译。不能把开发者评分内核的26–30倍测量写成这套求解器端到端收益。正式输出仍用E0确认，域外回退及短名单全字段复核保留。

六字段：目标=突破旧前缀覆盖；输入=官方原始张量规则与Pro数学答复；输出=独立构造核/证明审阅/纯数学测试；限制=未接入默认求解器且无新官方成绩；验收=七项数学检查通过；节点=可供适配与有界实测的模块，不是算法最终验收。
