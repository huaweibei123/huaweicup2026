# P3 迭代10：Pro 单迁移构造的官方证伪

Pro r02 的双迁移在原不可分计算、五核单 V 槽和跨核依赖 500 周期的放松内达到全局下界 `6279S−500`；独立证明和整数 DAG 重建已复核。真实 COPY、容量、Cache 尚未进入该证明，不能宣称官方最优。

本次只测单迁移固定词：051/k5，`tree_solve --tree-method stage-single-cut`。保持原图/原树/原59S计算节点与边；每阶段仅 lane 2 的第二与第三算子之间改变 owner，collector 固定2。原图严格守卫和完整 FIFO 增强图核对通过。计算下界153096，比旧实测 rotate168806低；但每阶段32KB迁移会增加 DDR COPY，收益仍未知。优先单迁移用于辨识该服务开销，而非按更低纯计算分数盲选双迁移。

冻结预算：1 solver、1在线完整未修改E0、单worker，90秒每格、180秒全批；0重试、0新分母/P2/E1/E2/云。与固定033f3c24728284e681212927ba2cdf07f085ffb2归档的051/k5旧rotate原件比较（M168806，added COPY944 B，spill0），旧结果不重跑、不在线择优。预期改善不是通过条件：失败和退化同样保存。

来源代码先固定，复用自己的稀疏执行树；仅在P1及集中评测负责人确认当前窗口后运行。报告原件、实际M/DDR/spill/字节命中率、完整求解进程耗时，独立回读后入台。此一格不自动授权另外两张图、双迁移参数扫描或把迁移方法加入全500生产入口。
