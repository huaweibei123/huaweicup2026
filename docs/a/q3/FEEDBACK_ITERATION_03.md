## 两个构造及因果边界

两者复用与迭代02完全相同的片段集合，阈值固定
`B=max(max_node_work, ceil(total_work/(4*k)))`。不额外扫描粒度。
商图只有前驱片段均已构造才进入ready集，片内保留DFS后序。
ready的首键为外部输入的最大预计release（place时取核心最小值），次键为商图bottom-level；
该排序坐标不表示所有输入必须在片段入口就绪，也没有纳入当前pipe_available来计算最早开工。
每个摆放试算逐原操作使用内部依赖/外部完成时刻、跨核500及各pipe可用时间，禁止把整片段当单槽原子工作。

- `release-order-e0` 保持旧fragment的LPT归属，只改变各核片段/原操作提交顺序。
- `release-place-e0` 逐ready片段选择简化模型预计完成最早的核，平手优先少跨核输入、再核ID。
  归属改变还会改变后继release键与dispatch顺序，因此这是**归属与顺序联合修改**，
  两者的性能差不能全部归因于分核一个因素。

ready首键不是“只要有ready就永不等待”的证书。源片段release为0可能先于上层join，
留下多个片段输出，容量仍由官方核验。不声称无spill、无队首阻塞或总体性能保证。
代码采用整数非负cross_delay，当前500与冻结配置一致；任意配置扩展需显式读取/传入实际值。

计算图+逐pipe FIFO无环：全局片段拓扑dispatch序、片内DFS构成原计算图的一个线性扩张，
每核顺序为其子序列。对固定归属与pipe顺序，逐op试算与该简化增强DAG最长路一致，
两个随机结构单测用独立DAG重算验证。此模型本身不包含COPY、内存补边、容量或Cache。
只有通过`pipe_bound`的官方适用守卫才能称为官方下界。
森林上复杂度`O(n log n + k(n+e) + q log q)`，k≤5、q≤n，近线性对数；
求解阶段仅一次直接构造，不在候选空间暴力搜索。
