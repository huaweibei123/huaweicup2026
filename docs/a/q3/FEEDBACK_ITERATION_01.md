## 直接构造与可证明边界

对 COPY 收缩后的 eligible DAG，只允许一个弱分量、每操作出度不超过 1 且存在 join。
它是一棵面向唯一 sink 的归约树。将最重块沿内部边切开，选择使两侧最大 compute work
最小的边，平局依差值/原 ID；重复到至多 k 块。每块分配一个核，按最小原 ID 稳定编号。
在原树作确定性 DFS 后序，投影到各核形成顺序；singleton 子图 ID 和 mapping 插入序
仍来自旧 Index 的全局拓扑序。输出两字段，所有元数据在 receipt 中。

这个宏联合改变核归属与核内执行顺序，不能把结果全部归因于某一个因素。平衡依据只含
compute work，不是 Makespan 代理正确性证明；切边也可能增添跨核 COPY、竞争和 spill。

每次切边的两侧仍为连通树块，所有操作覆盖一次。后序是原 DAG 的一个线性扩展，
各核顺序是同一扩展的子序列，因此原计算边与诱导计算顺序边的并集无环。
**这不证明官方 Step2/3 内存、插入 COPY 和管线 FIFO 的完整执行可行性**，仍由 E0 判断。
树结构的子树权重可沿拓扑序算；k 次切分约 O(k(V+E))，另有确定性排序/索引成本。
本轮只提出这一棵树分解，不遍历切分组合。
