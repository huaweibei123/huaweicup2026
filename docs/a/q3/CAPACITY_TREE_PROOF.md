# 非负标量归约树的容量阈值分块

本节给出一个**组合目标的精确算法**：将带非负标量节点权的树切成至多 k 个连通块，
最小化最大块权。它不证明官方 Makespan 最优，也不证明插入 COPY、容量分配或 FIFO 后的执行合法。
当前实现的权来自 `Index.duration(u)=max(1, cycles)`；这是构造器计算工作量坐标，
不能未经核查等同于官方完整时延或多个管线的容量向量。

## 命题与状态

设非空有限树朝唯一根定向，节点权 w(u)≥0，删边生成的每一连通块权重为其节点权之和。
给定阈值 B≥0，要求每块权重不超过 B，目标是最少删边。
对以 u 为根的子树 T_u，定义状态 (c_u,r_u) 为下列二元组的字典序最小值：

- c_u：T_u 内部的删边数；
- r_u：在删边数最少的前提下，含 u 的连通块的最小权重。

后序处理节点 u：

1. 若 w(u)>B，则不可行；非负权保证该判断必要。
2. 先取所有孩子的状态，设 c_u=Σ c_v，r_u=w(u)+Σ r_v。
3. 按 r_v 从大到小排列孩子，权重相同按稳定节点 ID 排序。
4. 若 r_u>B，则依次切断最大的尚未切断子残块与 u 之间的边，每次令 c_u+=1、r_u-=r_v；
   一直执行到 r_u≤B。

这个算法返回上述精确状态。根节点的最少组件数为 c_root+1。
因此，阈值 B 能否用至多 k 块实现，等价于 c_root+1≤k。

## 替换论证与证明

叶节点显然满足命题。假设所有孩子都已满足命题，取 T_u 的任意合法分块。
它在孩子子树 T_v 内使用 d_v 条切边，根残块权为 s_v。归纳假设给出 d_v≥c_v。

- 若 d_v=c_v，可将孩子内部方案替换成归纳方案。切数不变且 r_v≤s_v；保留父边原本切或连的状态，
  父根残重与各块的阈值可行性都不恶化。
- 若 d_v>c_v，且父边 (v,u) 原本切断，可替换成归纳方案并保留该父边切断状态；切数减少。
- 若 d_v>c_v，且父边原本连接，则替换成归纳方案并切断父边。新局部切数 c_v+1≤d_v，
  父根残块减少了 s_v≥0 的权重；所有新封闭孩子块都来自合法归纳方案。因此切数不增加，
  父根残重也不增加。

逐孩子替换后，必存在一个同样好或更好的方案，它的每个孩子内部都使用归纳状态，
仅需决定哪些孩子父边切断。若切 q 条父边，切掉 q 个最大的 r_v 能移除最多权重；
所以让剩余总重首次不超过 B 的最小 q，就是必须额外使用的最少切数。
在相同最少切数下，移除最多权重也恰好使根残重最小。归纳成立。

该论证没有枚举切分组合；小规模穷举仅用于检查算法实现是否与推导一致。

## 二分最优阈值、核数与零权

当权重为非负整数且 k≥1 时，令 W=Σw(u)，可以在整数区间

    max(max_u w(u), ceil(W/k)) ≤ B* ≤ W

上二分。可行谓词随 B 单调不减；二分结束后，在 B* 重建一次切边即可。
全部权为零时直接得到 B*=0，不需要 epsilon、正权假设或人为将零改成 1。
若使用 `Index.duration` 的至少 1 变换，需明确所得最优性是对**变换后的权**而言。
输入若含非整数，应另定义精度/容差或精确有理数处理，不能直接声称整数二分精确。

这里允许至多 k 块、至多 k 个活跃核，因此**没有必要为了用满核数而强切到恰好 k 块**。
若结果少于 k 块，保留空核仍符合组合目标和当前提交接口的含义。
数学上，在 k≤节点数且确需恰好 k 块时，可以继续切任意内部边：非负权保证最大块重不增。
但额外切边可能增加官方通信开销，不能据此声称用满核一定更优。

负权不在命题范围内：例如父节点权 -5、孩子权 10、B=5，不切边的整块可行，
但“某个节点权>B 即不可行”会误拒绝；替换证明中父残重只降的论据也失效。

## 复杂度与实现边界

单次阈值遍历的时间为 O(n + Σ deg(u) log deg(u))，额外空间 O(n)。
对整数总权 W，二分需要 O(log(W+1)) 次判断，最后再线性重建/排序一次。
二叉或其他有界度树每次判断为 O(n)。这是一维阈值上的精确多项式构造，
不是以官方 evaluator 扫描组合。k≤5 不要求枚举 k−1 条切边。

标量“最大残块”不能直接扩展为多管线容量向量。反例：零权根的三个孩子向量依次为
(8,0)、(0,8)、(4,4)，容量为 (10,10)。仅切 (4,4) 可保留两个孩子，使用一条切边；
按分量和排序并恰好先切前两个，会用两条切边。向量上不存在此证明需要的统一大小关系。

## 为什么值得替换重复二分

六个单位权节点，边为 0→1→2→5 与 3→4→5，根 5 是 join，满足现有归约树 guard。
当 k=3，先找最平衡二分会切成两个三节点块，再只二分其中一个，最大块重仍为 3。
切 (1,2) 与 (4,5) 却得到 {0,1}、{3,4}、{2,5}，最大块重为 2，达到总重/k 下界。
因此每一步都找到最优二分边，并不能推出最终 k 路平衡最优。

实际 Makespan 与这个标量最优值**没有必然单调关系**。切边会改变跨核依赖、COPY、
管线冲突、缓存和分配；树块之间也可能形成较深的依赖链。即使最大块重更小，官方结果也可能更差。
保留原全局后序在每核的投影，可以证明计算依赖与计算顺序边无环；这仍不证明完整 E0 执行可行。
正式实验必须保存新旧完整官方结果与失败/退化，不用该证明替代合法性或质量验收。

## 扩展讨论／待测：细分后打包，允许每核多个连通碎片

以下是后一阶段的候选机制，不改写前文的连通 k 分块定理，也不是新增正式实验成绩。
当“每个核必须占一个连通树块”限制了负载平衡时，可先生成更多连通碎片，再分配到核。
令总权 W、核数 k≥1，固定粒度参数为 1/4，设

    B = max(max_u w(u), ceil(W/(4k)))。

使用前文已证明的阈值算法，生成阈值 B 下数量最少的连通碎片，此处不再限制碎片数≤k。
将 q 个碎片按总权降序排列（同权按稳定碎片 ID），逐个交给当前累计权最小的核（同权按核 ID）。
这就是针对碎片标量权的 LPT/list scheduling；每核可以含多个彼此不连通的碎片。
最后仍将原树的一份全局 DFS 后序投影到各核，而不是将核内碎片任意整块串起来。

### 可证明的负载界

记碎片权为 p_j，其总和为 W，且 0≤p_j≤B。任意“交给当前最轻核”的 list scheduling，
无论碎片输入顺序如何，都会得到

    最大核负载 L ≤ W/k + (1−1/k) B。

证明：取最终负载最大的核，设它收到的最后一个碎片权为 p。该碎片分配前，此核负载
不超过当时所有核已分配总权的平均值。此时已分配总权 A≤W−p，因此

    L ≤ A/k+p ≤ (W−p)/k+p = W/k+(1−1/k)p
      ≤ W/k+(1−1/k)B。

LPT 的降序只确定这里的直接构造；上述界不依赖更强的 LPT 近似定理。
若权与 B 均为整数，则 L 也是整数，可写成更紧的

    L ≤ floor((W+(k−1)B)/k)。

这里的 ceil 不能悄悄去掉。若最大单节点权不超过 ceil(W/(4k))，设 μ=W/k，则精确的保证是

    L ≤ μ+(1−1/k)ceil(μ/4)。

忽略粒度前先保留加法误差，可给出较松的

    L ≤ (1+(1−1/k)/4)μ + (1−1/k)。

五核时右侧为 1.2μ+0.8（权的单位与原构造相同）；最后的 0.8 来自整数舍入上界，
不能称为真实执行开销。若 B 由更大的单节点权主导，应使用原始 B 公式，
不能继续声称接近平均负载的 1.2 倍。全零权时 B=0、L=0；空核允许保留。

### 任意分核仍保持计算顺序无环

令 τ(u) 为全局后序中的严格序位。每条原计算依赖 u→v 满足 τ(u)<τ(v)。
对任意节点到核的归属，只要每核顺序是同一 τ 的子序列，新增的核内计算顺序边也都严格增大 τ。
因此这些边的并集不可能包含有向环。证明不要求单核节点集连通，也不要求只占一个碎片。
这一事实只涉及计算节点和计算顺序，仍不涵盖官方插入 COPY、内存分配和 FIFO 之后的完整图。

### 碎片数和通信代价不能被固定粒度掩盖

B≈W/(4k) **不保证 q≈4k，也不保证 q=O(k)**。例如 k=5，星形树根权为 1000，
有 19000 个权为 1 的孩子：W=20000、B=1000。根自身已占满容量，任何孩子都不能连到根，
因此最少也要 19001 个碎片。一般可有 q=Θ(n)。这不是阈值算法错误，而是连通碎片的结构约束。

确定性的构造成本为：阈值遍历 O(n+Σdeg log deg)，重建 O(n)，
碎片排序 O(q log q)，以小根堆分配 O(q log k)，全局后序投影 O(n)。q≤n，
所以仍是多项式的单候选构造，无组合扫描。不能把 q 当作固定的 4k 从复杂度或运行记录中省去。

切边有 q−1 条；只有两端碎片最终属于不同核的边，才是该树视图中的跨核计算边。
不同碎片打包到同核时，部分切边会成为核内边。该边数只是结构诊断量，
不能直接等同于官方新增 COPY 次数或搬运字节：收缩的计算边与实际 tensor/COPY 语义并非一一对应。

因此实验应同时保存碎片数、每核碎片数与总权、跨核计算边、官方 COPY/搬运、spill、
按字节 Cache 命中和完整求解时间。更小的标量负载并不意味着更小 Makespan；
更多跨核依赖、带宽竞争、内存峰值、访问交错都可能抵消甚至反转收益。
相较“一核一个连通块”，本机制主动用潜在通信代价换取负载均衡自由度，是否值得必须由完整 E0 对照判断。

即使没有 COPY、没有 Cache、每核只有一条计算管线，也有负载更平衡但执行更慢的小反例：
两个权为 5 的叶子都指向权为 10 的根，k=2，W=20。新阈值 B=10 得到三个单节点碎片；
LPT 先将根放核 0，再把两个叶子都放核 1，核负载为 (10,10)，但根要等两叶顺序完成，
理想执行 Makespan 为 5+5+10=20。将一个叶子与根放核 0、另一个叶子放核 1，
核负载为 (15,5)，两个叶子并行后根执行，理想 Makespan 为 5+10=15。
这只是合成计算模型反例，不是官方 E0 case 分数；它足以否定“标量负载下降必然带来 Makespan 下降”。
