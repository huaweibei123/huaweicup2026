# 一般DAG的空隙插入候选

`src.q3.expanded_solve` 保留统一2d5459fa版本的阶段迁移、阶段和Attention/FFN路径。仅当这些结构守卫均拒绝时，尝试一般fork/join DAG的空隙插入候选；不适用仍交原guarded策略。每次运行自己读取图、构造、评分和写出方案，不读历史赢家。

构造来自Fang的固定 `a37eb931a22fb7df7e0d00d193538ce5289ae045`：`src/q3_yuanzhifang/gap_list.py`、`gap_calendar.py` 与 `dag_list.py::chain_dag`。本地 `gap_dag.py` 适配Index、显式拒绝原fallback，计算排序与tie-break保留；`gap_calendar.py` 保持上游函数字节。不是本会话原创gap算法，也不能把Fang单点成绩改称自己的全量成绩。

算法将只有一个前驱/后继的串行段凝聚为链，按剩余计算关键路维护ready队列。持久AVL保存每核M/V空闲区间，链进入最早可容纳区间；当一条链恰好释放join时，联合选择链与join的核，最多k²个算术放置，保留原操作与依赖。传输模型用固定500延迟加两次整除向上取整的COPY服务估计，未模拟共享DDR竞争、Cache和容量，模型数值不是官方成绩或一般下界。

这不是全图组合暴力搜索：每条链只提交一次、就绪选择固定、无随机或参数扫描。以N个操作/E条边计，构造约O(E+k²N log N)，k≤5；持久日历的临时分支在当前提交后释放。在线最多评价两个实际方案：先评与旧guarded相同的结构anchor，再用已证明FIFO必要界淘汰不可能降低其Makespan的gap候选；未淘汰才调用未修改官方P3。候选不合法时保存失败、保留anchor；编程错误不吞掉。严格较小Makespan才替换anchor，同分保留原方案。求解墙钟包含全部构造、下界、在线E0、失败/回退与输出。

当前检查：119测试通过、1明确E0门控测试跳过；010/044/100五核的适配构造与固定上游函数使用相同Index时产生完全相同plan对象。该检查共6次静态构造、0E0，不是求解器性能评测。正式新增机制批预定仅这3图五核，最多3次完整solver/6次E0、每格30秒、批120秒、1worker、0retry，须在资源窗口实际释放后执行。未在执行前宣称收益，未用它替换旧统一500的任一格。
