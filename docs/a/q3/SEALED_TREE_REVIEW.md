## 2. 必须成立的接口条件

计算边指向归约根。首版接受一棵非空、每节点出度至多 1、入度至多 2 的计算树；一元节点和单节点可以处理。
每个封闭子树包含根的全部计算祖先，子树之间没有共享计算节点，且所有内部节点最终到达根。
因此根完成时，子树内全部计算已完成，团队上的所有计算资源均已释放。

状态 `H_v(q)` 表示至多 q 个同质核心上的模板完成时间，根返回团队指定核心。
可以空置核心，不强迫使用恰好 q 核。跨核计算延迟 δ 为统一非负整数。
每核心的每条计算 Pipe 各有一个串行槽；不同 Pipe 可并行。
输入的原始 `cycles=0` 按冻结实现的 `max(1, cycles)` 计时，不得误作 0。

首版只接受非 COPY 的 M/V 操作，整数原时长非负。
COPY 收缩后的每条边必须与原始共享 tensor 或直接 op→op 边一一吻合；拒绝仅由中间 COPY 桥接产生的无见证边。
多 producer tensor 另行拒绝，避免歧义。原始输入/输出 COPY 可以存在，但其服务时间不进入本模型。
这些限制用于明确数学模型，不意味着已证明完整 E0 可执行。

任意片段有多个内部外部输入，不能只用根完成时间代替全部输入释放信息。
带 fork 的图、共享祖先 DAG 或原始高入度节点不能静默改成该树模型。
051/024/016 的阶段广播图因此属于另一构造，不能直接套用本 DP。

## 3. LOCAL、SEQ、PAR 与返回核

固定每节点孩子的 ID 升序，形成固定 DFS 后序。
`D_v` 是整个子树在一个核心采用该词时的**精确多 Pipe 计算增强 DAG 时间**，不是总工作量。

对二元节点 v、孩子 a/b、计算时长 w_v：

\[
H_v(q)=\min\{D_v, H_v(q-1), H_a(q)+H_b(q)+w_v,
\min_{1\le i<q}[J_\delta(H_a(i),H_b(q-i))+w_v]\},
\]

其中 q=1 不含前一预算项和 PAR，叶为 w_v，一元节点比较 LOCAL、前一预算和 `H_a(q)+w_v`。

\[
J_\delta(A,B)=\min\{\max(A,B+\delta),\max(A+\delta,B)\}
=\max\{\max(A,B),\min(A,B)+\delta\}.
\]

父留在较晚孩子的返回核，较早孩子可以在另一子树计算期间支付通信等待。
例如 A=1000、B=1、δ=500 时，拆分仍可节省 1；单看小孩子时长不能推出不值得迁移。
当 A≥B>0，且本地孩子只同 Pipe 串行，严格收益条件正是 δ<A。

编译必须保持如下不变量：`EMIT(v, team)` 令根 v 留在 `team[0]`。

- LOCAL：全部固定 DFS 词放 `team[0]`。
- LESS：只丢弃团队末尾核心，保持返回核。
- SEQ：两个孩子先后使用同一 team，并且都返回同一 `team[0]`；父也在此核。
- PAR：两个孩子使用不交团队。父返回 A 时 A 团队包含 `team[0]`；父返回 B 时整体重排团队，使 B 团队包含它。不能只改父节点的核而漏改子计划。

核心重命名只利用抽象计算模型中的核心同构性；不声称官方 Cache/FIFO 同时刻仲裁对核心编号置换完全不变。

## 4. 为什么编译后 Lδ≤H

LOCAL 的 D_v 是其固定词的精确计算时间。
SEQ 可把第二子树整个见证平移 H_a，并把父节点放在 H_a+H_b 后；两个孩子结束后团队所有计算都已结束。
PAR 的两个团队不交，孩子可同时开始；父所在核心的 Pipe 至迟在本地孩子根完成时可用，另一个孩子只需计一次跨核延迟。
以上给出所有计算依赖和同核心同 Pipe FIFO 都满足的合法见证时序。

实际提交只有 singleton 归属与每核优先词，没有提交屏障或起止时刻。
每核词是上述递归拓扑词的投影，不会增加逆向依赖环。
去掉证明用的屏障只放宽计算约束，增强 DAG 的最早完成时间因此满足：

\[
L_\delta\le H_r(k).
\]

双 Pipe 的 SEQ 并不要求真实执行整个 A 后才发射 B：串行屏障只是证明见证，不是官方接口。
如果“子树”另有不通向根的尾部任务，上述团队释放论证就不成立；完整归约子树条件不能省略。

当 `pipe_bound` 的依赖/时长/延迟 guard 成立时，另有 `Lδ≤C_official`。
这两个不等式**不推出 H 与官方时间的大小关系**。
因此不能以 `H≥anchor` 硬剪枝，也不能把 H 记作官方预测或上界。
`L≥anchor` 只能排除 Makespan 的严格改善；等号仍可能改善次级指标。

## 5. 精确 LOCAL max-plus 摘要

令输入状态为 `(0, A_M, A_V, …)`，首坐标恒为 0。
每子树保存资源映射矩阵 R_v、根完成行 g_v。有限运算为整数，负无穷单独表示。
按固定顺序组合 a 然后 b：

\[
R=R_b\otimes R_a,\qquad
h_a=g_a,\qquad h_b=g_b\otimes R_a.
\]

父完成行是 R 的父 Pipe 行、常数行、h_a、h_b 逐列取最大后加 w_v；最后用该行替换 R 的父 Pipe 行。
从全零输入计算根完成行即可得到 D_v。

必须保存**第一个孩子的根完成行**，不能只留下最后孩子或某 Pipe 的尾时刻。
反例：孩子 A=V100，B=M1，父=M1，正确 D=101；漏 A 的完成行会错算为 2。
同样不能用所有 Pipe 尾时刻的最大值替代根完成：单个 V1 子树遇到继承的 M100/V0 时，根在 1 完成，而 M 尾时刻仍是 100。
该 M 槽属于之前工作，不应无依据地阻塞 V 子树。

DP 与签名核心时间为 `O(n k² + n P³)`，空间为 `O(n k + n P²)`。
回溯只存决策指针，选中的 LOCAL 子树不重叠，总共只展开 n 个原操作。
整个求解函数还包含原图扫描、排序、官方静态校验与落盘；官方校验内部的排序/列表弹出可能有更高成本，不能把核心 DP 界冒称整个程序的最坏复杂度。
所有在线步骤仍须计入求解墙钟。

## 6. 完全树结论与受限族反例

Pro 原文已正确限定：完美二叉树高度 h、所有节点同权 a>0、**单 Pipe**、q=2^d 且 0≤d≤h。
共有 n=2^(h+1)−1 个节点。深度 d 以下的 q 棵子树分别放核，再在上方 d 层用不交团队归约：

\[
T_q(\delta)=a((n+1)/q-1)+d(a+\delta).
\]

零延迟下，深度至少 d 的 n−(q−1) 个节点都必须在最终完成 T−da 前结束。
单槽工作量约束 `q(T−da)≥a(n−q+1)` 得到同一公式，因此零通信时全局最优。
加延迟后最优值不低于零延迟最优值，故该特定构造至多有 dδ 的加性差距。
这不证明一般二叉树最优，也不能将四核界与五核最优比较。
仅同权但双 Pipe 不够：两叶分别 M/V、根 M、均时长 a，单核可 2a 完成，而单 Pipe 公式为 3a。

11 节点反例边为 `0,1→2; 3,4→5; 2,5→6; 7,8→9; 6,9→10`。
单位时长、单 Pipe、双核、零延迟时，DP H 和编译 L 均为 7。
另一个合法每核词 `[[0,3,2,5,6,10],[1,4,7,8,9]]` 只需 6，达到工作量下界。
漏掉的自由度是某个子树未完全结束时借出已空闲的核心。
因此模板的最优性只相对于该 LOCAL/SEQ/PAR 家族；容量 Pareto、异步借核、森林分配、双 Pipe 任意交错都没有被精确优化。
