## 适用判断

**适用于固定结构下的仿射排序族，但尚不是现在线上算法的一项提速。**
现有 `affine_eighth` 对每核只取一次 `max(1, length // 8)`，不提供可调 lag，
也不遍历参数。资源序列构造及其守卫不使用 lag，因此本结论不改变它们。

当前代码具备所需条件：

- 图、核数固定后，COPY 收缩依赖、全局拓扑序、弱分量及 Pipe 负载分核均不依赖 lag。
- `pos` 是**该核 jobs 列表的局部位置**，不是全图分量编号；分量次序同样固定。
- 前缀使用 `max(1, cycles)` 累加。验证器要求 cycles 和 ID 为非负 Python 整数且 ID 唯一，
  所以前缀是精确整数，分量内部严格递增，没有浮点四舍五入参与排序键。
- 键为 `(prefix + pos * lag, op_id)`，第二项是原操作 ID，不是 singleton 子图 ID。
- `node_to_subgraph` 的插入顺序和子图 ID 取固定全局拓扑位置；两字段提交中，只有
  `core_schedules` 会随 lag 变化。固定映射是一一映射，相同操作序列恰对应相同提交顺序。

代码中每核 length 可以不同，所以已有 lag 是向量 `(lag_0, ..., lag_(C-1))`。
将它直接说成全图只有一个公共标量是不准确的。若后续新增公共标量或共同分母参数，
它改变参数化方式，需显式记录，不能悄悄改写既有 as-run 算法身份；这仍属于同一
仿射构造机制的参数变化，不应记成独立的新机制。

## 一个核的精确区间

固定该核每个操作 u 的整数前缀 p_u、局部作业位置 j_u 和唯一整数 ID u。
对正整数 l，按 `(p_u + j_u*l, u)` 升序排列。
给定锚点 l0 处的完整序列 `s=(s1,...,sn)`，对每个相邻对 `(u,v)` 定义

```text
a = j_u - j_v
b = p_v - p_u - (1 if u > v else 0)
```

保持 u 排在 v 前面的充要条件是 `a*l <= b`。当 u<v 时允许第一坐标相等；
当 u>v 时第一坐标必须严格较小，因为坐标为整数，严格性恰好化为右侧减 1。
对每对约束取：

| 条件 | 对 l 的限制 |
| --- | --- |
| a>0 | l <= floor(b/a) |
| a<0 | l >= ceil(b/a) |
| a=0 且 b>=0 | 无新增限制 |
| a=0 且 b<0 | 不存在该序列 |

全部限制与 `[1,+infinity)` 相交，即精确整数区间 `[L,U]`，U 可以无穷。
从真实锚点序列生成的区间必含 l0；若不含，说明参数身份或实现存在错误。
空核、单操作核没有相邻约束，区间为全部正整数。

证明：若序列不变，所有相邻比较都必须成立。反之，所有相邻比较成立，字典序的
传递性保证整个序列严格有序；ID 唯一使完整键没有平局，故它就是唯一排序结果。
每项是一维半直线，交集只能是一个整数区间。因此一个完整顺序不会在分离区间复现。
无需枚举全部操作对来验证一个已知顺序的等价区间。

整数实现不可用 `int(b/a)`，它会朝零截断并引入浮点精度风险。Python 精确写法是
`floor(b/a) = b // a`、`ceil(b/a) = -((-b) // a)`，对正负非零 a 都成立。

以下是**手算排序边界**，不是官方图、自动化测试或性能成绩：

| u 的 (ID,p,j) / v 的 (ID,p,j) | 要求 u 在 v 前 | 边界说明 |
| --- | --- | --- |
| (9,5,0) / (2,0,1) | l>=6 | l=5 时 ID 2 胜出；忽略平局会错误包含 5 |
| (2,5,0) / (9,0,1) | l>=5 | l=5 时 ID 2 胜出；一律用严格比较会错误排除 5 |
| (9,5,0) / (2,1,2) | l>=3 | -2*l<=-5；向零取整会错误给出 2 |

## 多核、完整输出与成本边界

- 每核独立调整正整数 lag 时，相同完整提交的参数域是各核区间的笛卡尔积；
  这不意味着各核对 P3 Makespan 的影响可以独立优化，Cache 和带宽仍跨核耦合。
- 若明确改成所有核共用一个 l，则取各核区间的交集。不能把独立向量的所有等价类
  简化为一维扫描，否则会漏掉候选组合。
- 若仅将固定分母 8 扩展为公共正整数 d，`lag_c(d)=max(1,floor(T_c/d))`，
  应求上述 lag 区间的逆像，而不是拿 d 代入排序不等式。对该核区间 `[L,U]`，
  有限 U 给出 `d >= floor(T_c/(U+1))+1`，L>=2 给出 `d <= floor(T_c/L)`；
  L=1 或 U 无穷时相应侧无约束。再交 `[1,+infinity)` 及所有核限制。
  此处只给出参数映射公式，没有实现或验证新的可调 d 接口。
- 固定图、配置、代码与完整有序计划可讨论复用评分证据；生成来源/参数、构造耗时和
  必要独立官方复核仍各自记录。该证明只覆盖两字段计划，不覆盖包含参数、时间戳、
  运行费用的 receipt，也不提供跨问题、配置或代码版本的缓存复用授权。

## 收益和下一步的限度

给定一个核的锚点，排序 O(n log n)，相邻约束扫描 O(n)。若未来一维参数扫描从 l=1
开始，每次跳到当前区间的 `U+1`，到无穷上界结束，可以每个完整顺序只构造一个代表。
这避免逐个尝试产生相同计划的大段整数，却不保证不同计划数量很小：同核不同 j 的
每一对相对次序最多翻转一次，故粗略至多 O(n^2) 个顺序；逐区间重新排序仍可能昂贵。
独立多核参数的组合更可能膨胀，不能凭“去重了”就称其符合非暴力研发要求。

本结论没有给出哪个区间更优、如何处理跨核 Cache 相互作用、全局最优界或泛化收益。
更重要的未实现方向仍是只读共享关系驱动的分核与相位联合构造，不能让参数枚举替代
结构设计。若以后确需研究仿射参数，先在独立纯函数中核边界及有序计划一致性，再单独
提出含完整求解成本的评价 manifest；本次不启用扫描或追加任何 E0/E2 调用。
