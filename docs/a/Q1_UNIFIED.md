# P1 统一结构构造与在线质量选择

同一入口 `python -B src/q1/unified.py GRAPH --cores K --output PLAN --diagnostics JSON`。
方法族 `q1-unified-structural-guard`，固定变体 `structural-four-plan-guard-v1`。
当前是待正式全量验收的实现，不是已达标结果。五核全100图均值必须严格超过3.85；同时交付同一源码100×1–5核完整证据与求解端到端墙钟。

## 为什么是统一算法

运行只读取本次图、核数和冻结官方配置。图文件名、用例编号、历史成绩、历史计划、成绩台和网络均不参加选择。
固定规则最多提供4个不同两键计划，全部候选由图结构重新生成。预先冻结后使用同一版本跑全量，不在跑完以后按每格赢家拼算法。

1. **B：bounded** 始终生成，保留完整独立组件与已有树前沿，过大Task仅在独立组件边界切块。
2. **H：heavy/sink** 为组件太少、多出口或工作集中于一个重组件时暴露可并行的独占后缀。内部可能直接回退B。
3. **O：overload** 组件足够但某组件的某Pipe工作超过该Pipe的K核公平份额时，把可拆后缀组成Task DAG并按就绪表放置。内部可能直接回退H。
4. **X：输入窗口或分叉阶段**。组件数≥K且外部输入并集>524288 B时，生成共享输入/活跃核/深度窗口候选；它也可能有益于大批私人输入，故不以“必须公共输入”作为排除条件。组件数<K且存在计算fork时，改为Fang的fork-rank阶段森林前沿候选（grain=4）。这两个触发域互斥。

K=1只返回B。候选以最终JSON原字节去重，保留mapping插入顺序、Task ID及数值类型，不假定ID置换或语义哈希等价。重复计划不评分，但为识别重复而已经发生的构造仍计时。此版本复用旧构造接口，H/O内部有重复回退构造，尚未宣称其开销已消除。

这不是枚举任意切图、Task排列或参数网格：每个候选对应一种明确的结构限制（完整组件装箱、重/超载组件、输入压力、内部fork-join），每种机制只生成一次固定方案，不根据评分反复修改方案。上述触发与静态成本都是启发式，不是收益、容量或下界证明。

## 选择、预算与正确性边界

不同候选超过1个时，以固定E1 `5bfe53a29c1ba05167239f51ea937e602f7f85b4` 在线评分，按Makespan、scheduled-copy字节字典序选优，完全同分保持原候选顺序。对同一图scheduled与added搬运相差固定原图搬运，次目标排序相同。E1九文件保持原字节，清单见 `src/q1/unified_sources.json`。

单worker、16 MiB序列化缓存、每次评分60秒超时、worker启动10秒、最多4次评分、0重试。16 MiB不是RSS上限；独立实验supervisor另管进程组RSS与完整solver墙钟。无效候选、错误或超时立即终止后续评分，保留已成功评分的最优计划；首个评分失败则保留B并明确记失败。候选构造失败记入diagnostics并跳过，B本身失败则求解失败。实际评分调用与评分尝试分开：worker未启动成功不能算已完成E1。CLI逐项flush JSONL事件；外层中止后按已返回记录和已开始请求报告调用下界/上界或未知，不把未写最终diagnostics当作0调用。

一个不同计划时跳过在线排名，仍需外部E0验收。E1包含局部编译、spill、共享DDR、FIFO和Task gate全局重放，但现有精确性证据只覆盖有限测试域，不能把“exact”名字当全域证明。新结构先做有预算的E1/最终E0对照；正式成绩只来自未修改E0。E1失真可能导致错选，因此在最终E0核验前不声称质量保护已经在全域成立。

Task构造的覆盖、数据依赖与增广DAG检查继续由每条机制完成；不传Q2/Q3的额外排序接口。最终方案严格只有 `node_to_subgraph` 和 `core_schedules`；诊断写另一文件。

## 复杂度与计时

设计算邻接展开后大小为V、E，K≤5。组件、阶段森林与就绪表工作主要为O(V+E)加堆/装箱排序O(V log V)；原始tensor生产者×消费者展开与COPY收缩成本单列，不能对原始输入笼统称线性。输入窗口候选最多比较K个元数据配置，选择后构造1个方案。旧机制的常数次嵌套构造也实际执行，整体不会因候选数固定就变成零成本。

E1复杂度另外取决于每计划扩展图、spill与事件数。求解总时间由外层runner从进程启动到落盘和子进程收尾计，包括读图、全部成功/重复/失败构造、模块/worker启动、评分、选择和序列化。diagnostics内函数时间只用于定位开销，不能替代这个完整wall。外部最终E0另列；正式批次冻结源、预算、机器和并发数。
