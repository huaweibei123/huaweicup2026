# 单尾固定 FIFO 次序的可组合响应模型

目的：把当前一次全图最长路分析变成可解释的阶段响应，以区分本核工作与从前核传入的尾作业等待。它研究的是**零 COPY、零额外跨核 lag 的计算/FIFO 松弛模型**，不修改已冻结的首波阶梯构造和1cold/2E0预算。初版仅有小合成验证；2026-09-25T03:29Z按另冻预算完成一次真实067静态核验，全部核/尾段时间与全DAG一致，仍0官方E0；详见 [结果与等待余量](../../../results/a/q3-yuanzhifang/tail-response-static-followup-20260925/REPORT.md)。

## 严格适用域

令每个计算操作周期为正整数，管线为M或V。固定的每核计算次序恰覆盖全部操作一次，所有核内原依赖均沿该次序向前；再加入同核同pipe相邻操作的FIFO边。唯一跨核相互作用来自一个尾作业序列 `t_0,...,t_(L-1)`：每对相邻操作的原依赖边确实存在，尾序列按非空连续区间依次归核0至k−1，所有跨核原边都是尾序列内向后续核的边。非尾操作不得有跨核依赖。

在这个范围中，可删去除相邻尾段交接外的跨核跳跃边：对任意 `t_i→t_j`，原图已有完整链 `t_i→t_(i+1)→...→t_j`，且各顶点周期非负、边没有额外延迟；链约束蕴含跳跃边约束。删边不改变该松弛模型的可行时间或最长路。这不是对实际COPY展开图的前驱删除规则；实际张量传输、COPY管线、各自完成时刻和500周期release必须另行保留，不能套用本约简。

## 每核四个系数

将上一个尾段最后操作的完成时间记为R。本核唯一外部约束是尾段首操作不能早于R；其余边全部留在核内。对每个操作v，完成时间可表示为 `F_v(R)=max(A_v,R+B_v)`。没有从尾段入口到v的路径时，`B_v=−∞`。

设操作时长为d_v，按已验证的本核拓扑次序计算：

```text
A_v = d_v + max(0, 所有本核前驱的 A_u)
B_v = d_v + max(本核前驱的有限 B_u,
                若 v 为本核尾段首操作则另加入 0)
```

第二行没有候选时仍为−∞。证明由拓扑归纳给出：把各前驱的两项max代入最早开始递推，分别收集常数项和含R项即可；不是参数拟合或两次采样。所有原核内边与同pipe FIFO边都进入该递推。

定义 `A=max_v A_v`、`B=max_v B_v`；尾段末操作的两个系数为C、D。于是本核总完成时间 `E(R)=max(A,R+B)`，传给下一核的尾完成时间 `R'=max(C,R+D)`。第一核取R=0，顺序组合并取所有E的最大值，精确还原此固定计算/FIFO图的最长路。构建全部系数为 `O(|V|+|E|)` 时间和空间，之后一次组合仅 `O(k)`；这不是完整官方求解器的复杂度或提速实测。

## 后续切点优化必须保留什么状态

若切点前缀的状态为 `(R,M)`，M是已经处理各核的最晚结束时间，则追加一核更新为：

```text
R' = max(C, R + D)
M' = max(M, A, R + B)
```

在**同一阶段、同一切点、同一首波政策与相同后续构造**下，两分量均不大的状态可支配另一状态，原因是上述映射对R和M分别单调。不能只保留M最小的前缀：前缀 `(R,M)=(1,10)` 与 `(4,8)`，接上一核 `A=B=7,C=D=1` 后，总结束时间分别为10和11；只留当前M较小的第二状态反而丢掉未来较优者。这是响应模型的状态反例，不是官方图实测。

因而将来若做切点DP，必须保留足够的入尾时间/总体结束时间状态，或证明更强的特殊结构能压缩前沿。本文尚未证明该Pareto状态数有多项式界，也未实现或宣称最优切点算法；限制候选数不自动构成题目所要求的高效结构算法。

后续已找到另一种处理：不直接压缩整个Pareto前沿，而是固定完工阈值后只留最小入尾时间，再用整数二分求固定响应表最优值。完整归纳证明、系数预计算边界与新合成实现见 [阈值切点DP](TAIL_CUT_DP.md)。原反例与前沿规模未证结论仍成立；新方法不声称官方最优切图。

## 验证与边界

合成测试须与原计算DAG加逐pipe FIFO的完整最长路独立对照，覆盖跨段skip边、M/V交错、从前核传来的等待和各类拒绝条件。测试不生成官方计划，不调用derive、Step或E0。若任何原边不满足单尾守卫，模块必须拒绝，不能删去难处理依赖后签发“精确”结论。该响应模型可供跨问共享概念，但P1/P2是否适用须重新核对各自结构与硬件语义。

本模块已由 Sol medium 执行一次 `uv run --no-sync python -m unittest discover -s tests/q3_yuanzhifang -p test_tail_response_model.py`：4项测试通过，其中54组小整数管线/周期组合与独立全DAG最长路一致。根会话随后逐行复核源码、测试与本文，未把合成结果当成真实067或官方E0。新增真实图核验另按 `TAIL_RESPONSE_AUDIT.md` 冻结一次静态预算。
