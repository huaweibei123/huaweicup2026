# 同构链按连续阶段分核

动机：044 的 active_stages 用 2 核得到 P3=44185，但每核仍需读完整共享权重。把同一作业的连续位置分配到不同核，可让每份共享权重集中在较少核，代价是跨阶段激活搬运与固定通信延迟。依据原图结构直接构造，不按图 ID 选择，不在线试跑候选。

沿用严格同构串行链及共同输入签名守卫，要求作业数不少于请求核数、链长不超过512（限制DP成本）。守卫失败回退 active_stages。每个核获得一段连续位置；所有核按相同作业次序执行，每个作业先完成该段再处理下一个，便于早释放首个作业。输出仍为官方两字段、每原计算操作一个子图。

## 可证明的抽象问题

将每段视为单台串行机器，处理每个作业的时间为该段所有原操作时长之和 p_s；忽略COPY、容量、缓存、跨核延迟以及同核不同pipe重叠。J个相同作业经过m台机器且各台采用相同顺序时，最后完成时刻为 sum(p_s)+(J−1)max(p_s)。

证明：完成时刻的递推是 C(j,s)=max(C(j−1,s),C(j,s−1))+p_s。其网格最长路径每个阶段至少访问一次，另有J−1次纵向访问；额外每次权重不超过max(p_s)，上界是上述式子。把所有纵向步骤集中在最大p_s的阶段可取得该长度，故等号成立。总工作sum(p_s)与切点无关，最小化瓶颈即可最小化此抽象问题。

令 D(s,i) 为前i个位置切s段的最小最大段和，则 D(s,i)=min_{h=s−1..i−1} max(D(s−1,h), prefix[i]−prefix[h])，D(0,0)=0，其余不可行状态为无穷。最优分割最后一段的起点必在枚举范围；该前缀若非最优可替换而不增加瓶颈，因此递推覆盖且达到全部连续切分的最优值。时间O(kL²)、空间O(kL)，k≤5、L≤512。此处枚举是有最优子结构的动态规划，不是调用评估器盲搜。

**该定理仅针对以上抽象，不是官方E0的界限或最优证明。** 官方pipe可重叠，也可能因内存预取/FIFO造成阻塞；跨核COPY、500周期及共享DDR竞争会推翻收益。实际共同权重按段统计，跨核tensor网的字节数单列，不能把它们替代官方额外DDR。未知的容量行为由未修改E0验证，全部失败及spill原样保留。
