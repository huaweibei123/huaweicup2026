# 用阈值判定消除单尾切点 DP 的 Pareto 状态增长

本节接续 `TAIL_RESPONSE_MODEL.md`，求解**固定四系数表**中 k 个非空连续尾段的最小松弛完工时间。它不声称官方 E0 最优，不把零 COPY 计算下界当可实现成绩，也不把不同首波政策混在同一个状态中。实现为 `src/q3_yuanzhifang/tail_cut_dp.py`；真实图系数表生成和端到端求解尚未实现。

## 问题与可压缩条件

尾链位置为0至L−1。阶段c选区间[l,r)，表中每个允许区间提供固定的非负整数 A、B、C、D；缺失区间表示不可选。给定入尾时间R，该阶段本核结束时间和传出时间分别是 `E=max(A,R+B)` 与 `R'=max(C,R+D)`。初始R=0，所有E的最大值为目标。真实模型还须由响应模块的严格守卫保证：唯一串行跨核尾链、固定 M/V FIFO、零额外跨核 lag、无 COPY。通用DP本身只验证抽象响应表的整数/索引合法性，不替调用者证明该表来自真实图。

同一个 `(c,l)` 的后缀必须只依赖c、l及R。比如固定h后取首波n_c=h+c，并独立由区间与固定其余波次产生系数，可以满足该条件；若前缀选择还会改变后续分核、容量、首波宽度或Cache状态，就不能合并为当前状态。那些未进入模型的真实服务状态不因DP成功而消失。

## 判定引理及证明

先固定整数阈值T，要求所有已选阶段E≤T。令 `R[c,l]` 为满足这个条件、使用c个非空段覆盖[0,l)的**最小尾完成时间**；不存在时记∞。初始 `R[0,0]=0`。对允许的下一区间，若 `max(A,R[c,l]+B)≤T`，即可更新

```text
R[c+1,r] = min(R[c+1,r], max(C,R[c,l]+D)).
```

证明按阶段归纳。保留下来的状态本身有真实前缀和回溯指针，故不会产生假可行解。另一方面，任何被丢弃前缀的R都不小于该状态所保留的R；相同区间的E和R'分别对R单调，所以用较小R替换不会破坏阈值约束，也不会使后续入尾更晚。迭代应用即表明：存在任意满足T的完整切分，当且仅当 `R[k,L]` 有限。前缀的M虽然可能不同，但它们都已≤T，故不需继续保留数值；这是区别于直接只保留最小M的关键。

具体反例也可使用满足局部计算DAG系数必要关系的表：两个前缀在同一位置产生 `(R,M)=(2,11)` 与 `(5,9)`，最后一阶段 A=B=7、C=D=1。两者最终M为11和12。只保留当前M较小的前缀会错过更优解，而T=11时保留最小R判定正确。新测试给出两个前缀的逐段系数及回溯切点。

## 最优性、复杂度与没有证明的部分

可行性对T单调。设表中最大系数为F，则任意连通切分的第c阶段入尾R≤cF、E≤(c+1)F；因此kF是安全上界。先在上界判断是否存在连通路径，再在[0,kF]整数二分，最小可行T就是**该固定响应表**的精确最优值。返回路径直接组合的M必须等于T，否则实现拒绝。

令m为表内区间数。按单位成本整数运算计，一次判定用 `O(m+kL)` 时间，回溯/状态 `O(kL)` 空间；建表后总优化用 `O((m+kL)(1+log(1+kF)))` 时间，存表与状态 `O(m+kL)` 空间。稠密区间表m≤kL(L+1)/2。F=0时仍有线性读取和判定成本。高精度整数的位运算成本可额外按数值位长计，未声称与数值规模完全无关的强多项式算法。

这避开了多阈值合并时可能很大的(R,M) Pareto前沿；**没有证明那个前沿本身为多项式**。系数预计算成本另加，不能仅报DP毫秒数作完整solver效率。也没有优化额外DDR次目标；合法搬运展开、实际容量/Cache服务及同计划P2/P3仍需外部官方评测。固定模型中更优的切点不保证真实E0更优，后续试验仍须另冻最小预算。

## 已做验证

Sol medium完成初版4项合成测试，包含固定种子8673的70个小响应表与全部合法切点枚举对照，以及阈值状态、无路/零值/非法输入检查，0真实图/derive/Step/E0。根会话逐行复核后将状态反例加强为满足局部DAG必要系数关系的实例，并修正F=0时的复杂度写法；仅对改动后的这个测试文件复核，不重复运行旧响应模型测试。全切点穷举只用于这些L≤6的测试oracle，不是研究求解器的方法。
