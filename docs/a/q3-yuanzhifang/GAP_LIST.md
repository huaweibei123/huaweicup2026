# 保留未来预约，同时填入计算管线空隙

既有join_list按各核每pipe的末尾时钟追加。如果较高优先链依赖晚到的跨核输入，追加会预约远处计算，并把其前方闲置时间丢失；后续已经就绪的独立工作也只能等该预约结束。release_order只换M/V交错，不能消除同pipe的这种约束。

本候选保留最大串行链、剩余路径优先、最后前驱/join联合定价。把末尾时钟改为每核M/V的不可变空闲区间树；每个候选链从前驱释放时刻起，逐原操作寻找最早足够长的该pipe空隙并预约，最后只提交选中核心的版本。无需复制整段日历，也不运行官方评价器。join仍至多k²种算术分配，一次提交两条链；其他链每次至多k种。最后按模型开始时刻输出每核singleton优先序。

日历是增广持久AVL树，键为前一个计算预约的结束，值为到下一个预约开始的空闲区间；保留零长区间和无穷远尾部。子树记录最大空闲长度。先检查release所在区间的剩余长度，否则找键≥release且长度足够的最左区间；AVL与区间增广使查询及分裂预约均为O(log V)，仅复制根至叶路径。一次链候选按其原操作顺序完成，所有旧预约原封保留。

在固定的其他预约、核心、释放时间和串行原操作链下，逐操作最早插入得到该链最早可能结束：第一个操作不能早于最早可用区间；归纳地，较早完成前缀不会缩小下一操作允许的开始集合，前缀预约均位于其完成之前。模型保证每pipe互斥、原计算依赖及估计跨核延迟；正时长使按开始排序保持每条依赖及相应FIFO。这个局部结论不证明整图贪心最优，也不保证优于原join_list在另一条决策轨迹上的最终结果。

粗略总界O(k²(V+E)log V)，k≤5；持久版本在候选计算后回收，提交日历仅O(V)个节点，临时候选额外路径复制O(k V log V)的保守上界。实际Python对象和端到端时延必须测量；不把公式当性能。原图/COPY守卫与join一致，另要求非负整数cycles的M/V原操作。官方共享DDR、Cache轨迹、容量补边和最终执行仍由未修改E0决定，可能退化或spill。

当前仅研究代码和合成日历正确性；未读取官方图运行build，没有新plan/solver/E0。第七轮release_order实际P3仅15221→15123、cold0.476134→0.665118s，说明保留计算FIFO的优先重排在该例收益很小，值得检验消除同pipe空隙约束是否有效。

合成验证包含：对180次固定种子的随机release/时长预约逐次用独立整数时间枚举核验最早空隙、AVL平衡/增广不变量；保留旧版本且拒绝重叠；两核长短菱形加独立短操作，证明较晚处理的独立操作确实插入跨核短分支的等待区间，原汇合完成仍10002模型周期。这些均不调用官方E0，也不当作真实用例成绩。
