# 对新释放的 join 一并定价

来源：已全文读 [Pro本轮问答](https://github.com/huaweibei123/huaweicup2026/blob/4c7f3425b805494afaee026db93fef0538bb9c19/AI%20chats/20260924-Pro-P3-%E5%BD%92%E7%BA%A6%E6%A3%AE%E6%9E%97%E5%88%87%E5%88%86/%E5%AE%8C%E6%95%B4%E9%97%AE%E7%AD%94-20260924T153228Z.md) 的归约短视反例、封闭团队DP及其异步借核反例。本实现保留一般DAG列表的自由核心复用，只扩大最后一条前驱链的局部决策到即将释放的join；没有复制封闭子树DP或宣称优于它。

沿用 dag_list 的真实依赖一致守卫、最大串行链凝聚、bottom-level 就绪优先级及逐pipe时钟。若当前可分配链j只有一个后继z，且z有至少两个前驱、除j外的前驱均已分配，则对(j所在核,z所在核)的至多k²种直接算术组合传播结束时刻，选择z最早完成的组合，并立即将j、z一起提交到全局构造次序。否则使用原单链分派。并列依次看j结束、跨边数和核ID；没有E0或候选时间线试跑。

局部保证：固定此前已经确定的全部归属和pipe序，假定直到j、z两条链结束期间没有其他新作业插入，并采用与dag_list相同的跨边固定估计。任意将j、z追加的选择仅由这两个核号决定；逐pipe最早开始递推给该选择的最小模型完成时间，枚举所有k²对后选择最小值，故达到这个受限两链追加问题的最优。它不是全局最优；抢先提交z可能推迟其他更重要的独立链，模型仍忽略共享DDR、实际Cache和容量。

复杂度为链凝聚O(V+E)、排序O(J log J)、追加传播总计O(k²V+kE)，k≤5；每条链最终只提交一次。j在原商图就绪，z的所有前驱随后均已提交，二者按j,z追加保持全局拓扑序；每核计算FIFO依然投影自该序，不能形成计算环。完整COPY/内存合法性仍要未修改E0验证。

合成反例用于机制测试：同pipe diamond 的fork长1、两支长1000/100、join长1、跨边估计502；原逐链选择得到1106，一并定价选择同核1102。长支改10000后，短支的去返通信可被隐藏，新构造仍允许跨核并得10002。没有把这些模型数称为官方成绩，也没有用统一最小片段阈值禁止跨核。
