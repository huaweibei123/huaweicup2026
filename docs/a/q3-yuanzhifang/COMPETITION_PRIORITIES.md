# 从内部竞赛转向完整竞赛交付

2026-09-25，用户要求评估是否继续以“超过队长”为主目标。本评估建议：把对队长版本的比较保留为新增价值检验，将主目标调整为提高全队最终提交的质量、可信度、解释力和可复现性。这里是任务优先级建议，不是替他人接管源码、签署验收或扩大实验预算。

判断依据：本线累计33次cold提交构造、56次外部E0，已经产生有效方法和反例，其中044/k4容量方案为37581周期，较旧40927改善8.18%，额外DDR下降、spill为0；这些贡献值得整合。另一方面，067完整作业归核已被12446880的必要界排除超过当前12237901，单尾固定末波布局的零COPY FIFO下界也已达12218400，即这个布局最多只剩19501周期、约0.15935%的改善空间。它不证明别的布局无潜力，但不足以支撑无期限竞争单格成绩。针对固定类给出下界与停止理由，比反复尝试同类更有价值。

| 优先级 | 可交付工作 | 验收方式 |

问题3最适合本会话承担的是独立证据审阅、Cache非单调机制/失败案例，以及本线方法与界的论文段落。中央统一源码、成绩台和正式论文的单写权仍由既有owner负责；待协调明确写范围再接入。此分工能与队长的森林/张量复用算法研究互补，不要求另造一个全功能竞争solver。
