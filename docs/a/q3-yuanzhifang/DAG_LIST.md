# 分叉汇合DAG：串行链凝聚和释放时间感知分核

动机来自500格必要下界分析：005/069/071/086等图的原图大弱分量含大量分叉与汇合，整分量分核压住并行性。此名单只用于公开开发实测选择，不进入算法分派。程序仅从原图结构与固定配置工作。

保守守卫：原计算Pipe为输入合法字段；原计算邻接须与官方直接op边/tensor eligible生产消费边一致，不把COPY收缩的额外边当通信；需同时有分叉和汇合。将出度1且后继入度1的相邻节点合为最大串行链，每条链保留单核。按最长剩余计算路径处理已可构造的链，在k核上用逐Pipe工作时钟和已分配前驱的完成/跨核通信估计计算最早结束位置，选择一个核心。不对官方评分试参、不在线调用E0。未满足守卫使用既有active_stages/结构基线回退。

模型跨边估计=配置500+源/目标各一次全miss COPY服务；对实际Cache命中、总DDR共享带宽、容量、COPY排队没有精确模拟，绝不当作官方时延或全局下界。正确性论证仅限计算顺序：链按全局拓扑可用次序追加，因此每核计算FIFO边都从较早全局位置指向较晚位置，不能制造计算增强DAG环。插入COPY、Step2 spill和内存容量的完整合法性仍由E0判断。

复杂度：基础图分析与排序沿既有Index；串行链凝聚O(V+E)，每条链至多k次逐操作时钟计算，加优先队列O(J log J)，整体额外O(kV+E+J log J)，不隐藏逐候选评价。记每核不同Pipe时钟而非单一串行时间，防止将本可重叠的M/V错当独占一个CPU。此构造仍可能过度跨核、滞后释放或引发spill，负例必须保留。
