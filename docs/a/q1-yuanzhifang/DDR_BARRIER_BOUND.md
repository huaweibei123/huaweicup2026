来源为第二轮Pro答复e6bef3c9的第三节。此文给出可核验的充分条件，并把其单个ADD尾下界改成真实归约树的最短叶根路径。它是下界，不是求解器、评分近似或不可继续改进的证明。原件在AI chats/P1-fork-join-yuanzhifang，归档7a3e314a；Pro自己未读到官方文件，本地必须补做源码和实际结构审查。

## 结构与源码条件

`ddr_barrier_bound.certificate`首先通过既有guarded_stages：每轮12条四节点同耗时PIPE_V链，随后11节点二叉归约，前轮根释放后轮所有链。额外核查每轮有12个互异原始COPY_IN输入且各轮恰重复同一集合；输入等大；每个链内部的三个链接有对应私有同尺寸张量，所有链接张量身份互异。计算依赖保留与COPY收缩依赖必须一致。

冻结E0 `_build_scene_a_tasks` 的输入边界条件是有局部消费者而没有局部生产者；输出边界条件包含仍有别的Task消费者。两个条件均不以core相同为豁免，逐边插入DDR COPY。`activate_task`后才建立操作就绪队列；`retire`须Task全部操作完成才标done，包含COPY_OUT；`task_release_time`要求前驱Task都done，且同核序的100与异核依赖1000。一个核一个PIPE_V槽，每个重操作duration=p。DDR活跃COPY公平共享总归一化容量1，而非逐请求独占FIFO；服务量w=max(1,ceil(bytes/bandwidth))。小COPY、spill、容量阻塞只能增加工作/限制，不从下界扣除。公式是这些数学语义下的必要界，未声称一般浮点程序对任意数量级输入的形式化验证。

## 证明

令每条链L=4p、宽度m=12，第j轮任一链末端至本轮根的计算路径至少d_j。Task商图无环蕴含路径凸性：同一Task里两节点间的依赖路径不能离开该Task后又返回。

对j>1，P是包含前轮根的Task，t_j是本轮根操作完成时刻。P所含本轮每条链只能是前缀；设u条完整链、c条非空真前缀，前缀长度p_i属于{p,2p,3p}。记X=uL+sum(p_i)，p_max=max(p_i)或0。P结束不早于t_(j-1)+X。所有P之外的本轮操作必须等P全部结束后才能启动。

若u<m，其余m-u条链的第一个外部操作，各需要自己的大张量COPY_IN。这些COPY所属Task不早于P结束加g=min(同核等待,异核等待)启动；此处检查异核>=同核，故g=同核等待。全部服务量至少(m-u)w，最后完成者到根还剩至少L-p_max+d_j。因此

`t_j-t_(j-1) >= mw+L+d_j+g + u(L-w) + sum(p_i)-p_max`。

当u=0,c>0，P中没有完整叶链，故不能包含本轮归约节点；其最后本轮V操作必产生一个外部使用的大张量，COPY_OUT必须在P结束前完成，再额外有w服务的串行等待。若 `p <= w <= 2p`，上述两种情况均给出

`t_j-t_(j-1) >= b_j + p(u+c)`，其中`b_j=mw+L+d_j+g`。

若u=m，本轮重计算全部在P同一PIPE_V串行，时间至少mL。代码显式检查`mL >= b_j+mp`，故同一式仍成立。这些数值条件是充分条件，不满足就拒绝出证书。

首轮的m个互异原始输入必须加载；最后完成者到根仍有L+d_1，故`t_1 >= mw+L+d_1`。令 `LB=mw+L+d_1+sum_(j>1)b_j`。逐根间隔相加给出任意合法分区的`Cmax >= LB`。

设M为12个原始输入的不同“输入—消费Task”对数。单个输入在各轮的消费Task不能离开后再返回同一Task，否则违反路径凸性。相邻两轮同Task的次数共12R-M；每次都使后轮首操作包含在前轮根Task中，因而`12R-M <= sum_(j>1)(u_j+c_j)`。于是`Cmax >= LB+p(12R-M)`。

设B为四节点链内部跨Task的张量链接数。私有中间张量互异、生产者唯一，故每个切口至少OUT+IN，M个原输入—Task对也各有一次IN；单位DDR总容量给出`Cmax >= w(M+2B)`。两项取最大，不能相加：

`Cmax >= max(LB+p(12R-M), w(M+2B))`。

Pro取每轮d_j=13得到210452。本实现计算实际树的d_j；若051每轮最短路径为39，则可提高到211076。后一句在真实图静态检查完成前只是条件算术，不能提前当成已核证书。M/B专属计划的接口不替代其合法性验证；即使逐计划项更强，也不能把该计划特有M/B强加给其他分区。
