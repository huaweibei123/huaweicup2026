# 任意合法P1方案的屏障—门控资源下界

本节是本地提出的证明，尚需独立审阅。实现 `barrier_bound.py`，只用保留的计算边，不收缩COPY桥、不构造或评分方案。适用固定E0每核每Pipe一个slot、非COPY时长max(1,cycles)、跨核Task边等待δ的语义；保留直接计算边与原tensor的计算生产者→消费者边。所有下界针对任意合法Task分区/分核/核序，不限于本轮stage构造。

## 可比较顶点与时间分段

在一个计算弱分量中，若顶点b和每个其他顶点都可达可比较，则称b为全分量屏障。所有屏障在任意拓扑序中顺序一致。相邻屏障p、q之间的所有非屏障顶点都满足p→v→q；因此它们的实际执行区间全在p完成与q开始之间。不同分段的这些实际时间区间不重叠，可以把**分别证明有效**的段长下界与每个屏障自己的计算时长相加。不得把任意fork-rank阶段当成满足这一性质的全屏障段。

线性识别：沿分量拓扑序扫描，维护已处理诱导子图的sink集合；加入v时删去其直接前驱、加入v。若sink集合只有v，全部此前顶点都通往v。反向扫描对后缀source集合做对偶处理，只有v时v通往全部后续顶点。两条件同时成立当且仅当v为全屏障。这不需要成对可达矩阵；除既有拓扑排序外，扫描O(V+E)。

## 跨核路径的必要延迟

若保留计算路径u→…→v的端点处于不同核，该路径至少跨一次Task/核边。前驱Task结束不早于u完成，消费者Task开始不早于此前Task结束+δ，后续依赖时间均非负；故v开始≥u完成+δ。对同核端点仅使用零延迟弱界，不假定整路径同核，也不把多条边的等待相加。此引理依赖路径确实被官方保留，不能用于已删COPY桥。

考察有两个端屏障的一个分段，令D=q开始−p完成，某Pipe在该段总必需工作为W，核数k。

- p与q同核时，该核可用窗口至多D；其余核各至多max(D−2δ,0)。
- p与q异核时，两端所属核各至多max(D−δ,0)，其余k−2核各至多max(D−2δ,0)。

每个操作必须完整落在其窗口，且同核同Pipe不重叠。第二种容量不大于第一种：D≥2δ时相等；D<2δ时直接比较即可。因此未知端点核也始终有：

`W ≤ D + (k−1) max(D−2δ, 0)`。

没有前屏障或没有后屏障时，只有一次必要跨核延迟，右侧改为`D + (k−1)max(D−δ,0)`。两端都没有则为kD。空段W=0只给0，不能凭空加等待。

若端点数h为0/1/2，令L=hδ。上述容量函数的最小整数逆为：W≤L时D≥W，否则D≥ceil((W+(k−1)L)/k)。h=0或k=1自然退化成普通工作量界。各Pipe分别计算后取max，并与该段内部保留计算边的关键路径取max；不是把不同Pipe工作相加。随后对同分量各不重叠段相加，并加入每个屏障的时长。各弱分量可并行，故分量之间只取max，另与全图每Pipe工作量/k界取max。

## 没有证明什么

不包含DDR/边界COPY、spill、同核100周期、真实FIFO及非抢占的进一步装箱限制。下界可能很松，不是可达调度、全局最优性证明或真实硬件保证。跨核等待仅用于必要窗口，不能从算术余量推断所有等待都可移除。单核操作时长仍取官方max(1,cycles)。

单测将屏障识别与独立传递闭包比较，并在四节点小DAG上离线枚举分区/核分配/核序的单Pipe放松进行反例搜索。该有限验证不是一般证明的替代，也不是正式求解程序的搜索机制；0官方评分。随后与既有成功E0原件做一致性检查，不把旧成绩冒充新实验。
