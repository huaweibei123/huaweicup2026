# 独立证明审阅记录

审阅对象：作者 `f16746ff2ab112ae8e802711e90d74829c419eb9`，冻结官方 P1。结论限定在每核每 Pipe 单 slot、非 COPY 时长 `max(1, cycles)`、跨核 Task 依赖等待 δ、原 direct/tensor 计算依赖被保留的语义下。没有调用编译器或评分器重新生成成绩，也没有使用仍在生成的 Pro 回答代替推导。

## 1. 任意 Task 分区是否破坏路径延迟

保留路径 u→…→v 上，每条边在同 Task 中保留计算先后，跨 Task 时成为 Task 依赖。若 u、v 异核，沿路径至少存在一次异核 Task 边 X→Y。该边前的保留路径保证 X 结束不早于 u 完成；Y 开始不早于 X 结束加 δ；边后路径保证 v 不早于 Y 开始。因此 `start(v) >= finish(u)+δ`。中间同核边的 100 周期等待可被放松为 0，多个前驱的 max 只会加强这一单路径必要条件，无需错误地把所有前驱等待相加。

Task 可以跨越某个屏障；上述论证只需跨核路径的真实 Task 边，不要求 Task 边界与屏障重合。若一个 Task 同时包含相邻屏障 p/q，而段中 v 分到别核，则 p→v→q 会在 Task 商图诱导返回同 Task 的环，不能成为合法反例。即使不使用这个额外事实，按实际操作起止时间得出的窗口上界仍成立。

## 2. 屏障、窗口和求和

全分量可比较顶点与同一分量每个其他顶点都有单向可达关系；任意两个此类顶点在 DAG 中有唯一先后。相邻 p/q 之间的顶点必然满足 p→v→q。因此其完整执行区间位于 `[finish(p),start(q)]`。对一个段中落在 c 核的任意 v，若 c 不同于 p 核，则开始至少推迟 δ；若 c 不同于 q 核，则完成至少提前 δ。

p/q 同核：该核窗口至多 D，其余核各至多 `max(D-2δ,0)`。p/q 异核：两端所在核各至多 `max(D-δ,0)`，其余 k−2 核至多 `max(D-2δ,0)`。若 D≥2δ，两种容量相同；若 δ≤D<2δ，异核容量 `2(D-δ)<=D`；若 D<δ，异核容量为 0。因而同核表达式是统一上界，端核未知不构成漏洞。

同一 Pipe 的操作在单核不重叠，故其工作量不超过这些窗口长度总和。不同 Pipe 可以重叠，所以分别求界取 max，不相加。不同弱分量也只取 max；全图 Pipe 总量/k 可另给独立必要界。相邻段与屏障操作的实际时间区间沿依赖顺序不重叠，因此一个弱分量内可以相加，而非任意构造阶段都可以相加。

只有后屏障时用 `[0,start(q)]`；只有前屏障时用 `[finish(p),global makespan]`。一次必要跨核延迟给 h=1 容量。没有屏障时只有普通 kD 容量。空段 W=0 给 0，不凭空加 δ。内部关键路径只计本段保留计算边，可与资源界取 max，不把两种界相加。

## 3. COPY、多 Pipe 及代码对应

作者 `_build_op_adjacency` 先提取原 direct op 边及 tensor 的生产者→消费者边，再把 COPY 节点从保留计算子图排除；没有把 COPY 桥收缩成新的计算边。这规避了已知 Task 内 COPY 删除会消除旧路径的问题。Task 间官方可能额外保留 COPY 收缩后的约束，它们不应被反向假定为所有分区内部也保留；本下界忽略它们只会变松。

代码按原 `pipe` 分资源，按 `max(1, cycles)` 取计算时长；在冻结官方 `PIPE_SLOTS` 为 1 的前提下成立。未证明多 slot、不同官方 Pipe 映射或负/非法输入变体。合法性仍由官方定义；本函数也不是非法图的完整验证器。

线性屏障识别的前缀唯一 sink / 后缀唯一 source 条件分别意味着全部此前节点可达 v / v 可达全部后续节点；有限 DAG 的每个节点都可沿边到达某个 sink，反向同理。在已有拓扑序上两条件同时成立即全可比较屏障。本审计另用独立传递闭包检查全部 64 个四节点向前边 DAG，不依赖作者扫描来构造预期答案。

## 4. 有限证伪范围与未覆盖项

另枚举 64 DAG × 16 两 Pipe 标记 × 16 两核归属 × 所有兼容操作总序，共 80,640 个放松调度。保留每核每 Pipe 串行槽和异核计算边 δ，删除 Task 占用、同核 Task 等待、DDR、COPY、内存限制。任意合法 P1 计算时间线投影满足这些放松约束；按其资源顺序求最早执行只会更快。因此该集合能提供强于直接观察若干 Task 方案的有限反例搜索，但四节点、固定权重 1/3/2/4、δ=2 的穷举仍不能证明一般规模。

本审计未给出形式化证明机证书，也未覆盖所有图规模、所有权重或未来官方语义修改。未发现当前命题的明显漏洞；160 条既有 E0 一致性提供必要交叉验证。结果不能反推 DDR/门控余量可全部消除，不能认为 `official local_makespan` 是动态实际时长下界，不能以此停止方案质量研发。
