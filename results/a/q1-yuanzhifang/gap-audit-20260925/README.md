**统一入口建议及证据等级。** 事实是 overload 的后缀分裂带来 24 项收益、4 项退化，并留下上述两类结构缺口；shared-input 与 fork/G 已在各自公开开发格上提供进一步改善。理论上，单汇点不排除内部 antichain 并行，某组件过载也不保证拆分收益。尚待新算法验证的猜想是：保留整链边界、利用较早释放的根核预取，再结合容量友好的输入窗口，可覆盖更多当前瓶颈。不能把这个猜想升级成统一解法保证。

队长正在负责“至多四个结构候选 + 固定 E1 选优”的统一入口，本审计不修改其写区。建议在其既定预算内明确四类职责：bounded 对照、overload（包含其既有 heavy fallback）、shared-input、内部 fork（可将 G 作为显式结构守卫的子路由）。若同时保留 C 与 G 为独立评分候选，必须重新核对总候选上限，不能静默多加一个。G 作为 fork 子路由会牺牲同守卫下 C 的备选，当前只有 051 的开发证据，不能宣称一般支配。

选择器应直接使用其冻结的、已验证适用范围内的评分路线；代理值只能作有风险的排序或构造信号，不能凭 R+DDR 排除 G。只有与已知可行上界匹配的有效下界才可用于有证明的剪枝。字节一致计划可在同一运行中去重，但历史表、case ID 和事后最优不能成为在线选择依据。递归 fallback、全部候选构造、E1、失败处理、落盘与退出都要计入求解端到端墙钟，最终 E0 另列。完整 100 图 × 1～5 核的统一表现必须由未来冻结入口实际验证；本审计没有扩大实验预算或申请运行。
