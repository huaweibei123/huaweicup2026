macOS arm64、Python 3.12.13：
```
.venv/bin/python -B -m unittest tests.q1.test_resource_windows tests.q1.test_lower_bounds -v

OK
```

模块已有单独10项测试的首轮0.017s记录在Pro独立初审。接入首轮19项中有一个旧期望12与新结果13不符：共享输入后的两个独立M10都至少在cycle11结束，两次必要输出写在单DDR资源上至少再花2周期。双阈值窗口正确给13，原测试只核旧CP12；补了必要输出释放11的语义断言并更新期望，重跑后19项通过。其余原边界反例保持通过。
