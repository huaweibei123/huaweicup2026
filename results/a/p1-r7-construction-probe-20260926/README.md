# P1 R7 044/K5 structure-only construction probe

**Question.** Can the frozen shared-input-band rule generate one valid two-key candidate from the official 044 graph and the saved unified-v4 full500 K5 baseline? This is a mechanism probe, not a quality result.

**Sources.** Graph: `data/raw/a/official-cases.zip:data/case_044.json`, SHA-256 `9abd4468a4be365e384de47431ac914ee44fd6e7b6221dffc584561f388cd57e`. Fixed config: L1 524288 B, UB 131072 B, bandwidth 60 B/cycle.

**Method.** `src/q1/shared_band_proto.py` accepts a graph, a supplied baseline, capacity and bandwidth. It recognizes aligned independent unique-spine components with standard external COPY_IN, selects one maximum positive contiguous shared-input band, greedily packs it by the full managed-tensor footprint, and constructs only one candidate. It checks exact eligible-op coverage through the official plan parser, the augmented data and core-order Task DAG through the official order validator, and independently accounts for Task boundary COPY bytes. Unsupported inputs return the supplied baseline unchanged. It does not call Task compilation or any evaluator.

**Output.** `plan.json` contains only `node_to_subgraph` and `core_schedules`; raw SHA-256 `8eecfa3411b660b7cbffc8951ee7129df2ebb49745128243bbd6e1a3f9b90716`. `diagnostics.json` records sources, 10 Tasks, balanced peripheral groups 3/3/3/2, band rank interval [48,75), slices [48,65) and [65,75), and owner core 4. The resulting structure matches the R7 static pre-registration for these fields.

**Verification.** `PYTHONPATH=. python3 tests/q1/test_shared_band_proto.py` passed three focused tests: official structural validation plus accounting on 044, fail-closed capacity gate, and fail-closed shared-tensor identity gate. E0/E1/E2 calls: 0. Task compile calls: 0. Saved-plan solver batch: 0. Workers: 1 process for this direct probe.

**Limit.** Total managed-tensor footprint is a sufficient static capacity certificate under this input domain, not proof of actual Step2/Step3 behavior, FIFO timing, or Makespan. No official quality claim follows from this probe. The baseline was used only for validity, K, and fallback; the R7 candidate itself is input-structure-driven. Candidate identity and structural evidence are ready for separate scientific review before any official scoring.
