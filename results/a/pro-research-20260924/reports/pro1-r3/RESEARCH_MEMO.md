# R3研究备忘：把数学结构变成官方可检验的构造

## 0. 判断与证据层次

本轮把R2中优先级最高的“理想集参数最小割”降为备选，把主线转为：

> 安全串行包 + 固定计算FIFO的小型max-plus响应，先决定核心归属，再对原操作细化子图与参考顺序。P1采用另一套Task门控意识，不能照搬B。

## 2. 第一层降维：安全串行包

在正确收缩COPY后的计算DAG中，只在边u→v同时满足下面条件时粘合：

\[
\deg^+(u)=1,\qquad\deg^-(v)=1.\tag{R3-M1}
\]

所选边构成互不相交的无分叉有向链。每条链作为一个“核心归属包”。同一链的内部节点只有链内计算前驱/后继，外部计算边只能从链首进入、链尾离开，因此收缩后若有商图环，可沿链内部路径提升为原图环，矛盾。故这种链收缩保持计算商图无环。

它不是全局执行合法性的证明：共享输入、边界COPY、固定Pipe FIFO和内存复用边仍要由E0展开。也不是“把链永久变成一个不可分割Task”的证明。后面会把一个归属包拆成多个可提交子图，保留原操作和原ID。

原型先比较简化计算邻接与官方COPY收缩邻接；若出现尚未支持的内部COPY桥接，明确抛NotImplementedError，不悄悄漏边。所有正式试验均通过这项一致性检查。

## 3. 第二层降维：3×3计算响应，而不是一个总cycles标量

每个包固定一种计算拓扑序及其M/V投影，暂时把全部包外数据的到达合成一个共同释放时刻。输入为旧M时钟、旧V时钟、共同释放；输出为新M时钟、新V时钟、包内所有计算完成时间：

\[
\begin{bmatrix}M'\\V'\\C\end{bmatrix}
=K_B\otimes\begin{bmatrix}M\\V\\r\end{bmatrix},
\qquad (K\otimes x)_i=\max_j(K_{ij}+x_j).
\tag{R3-M2}
\]

每个操作的完成时刻是同Pipe前项、数据前驱和共同释放的最大值，加上其计算周期。用三个输入的符号表达逐操作传播，所有表达始终是三个输入加常数后取max，所以得到一个3×3响应矩阵。没有使用浮点数；负无穷哨兵不参与普通加法。

对`M1→V100→M1`，该子模型给出：

\[
K=\begin{bmatrix}
102&101&102\\
101&100&101\\
102&101&102
\end{bmatrix}.
\tag{R3-M3}
\]

这是固定计算FIFO/common-release模型的精确表示，不是官方评估器：没有动态DDR公平共享、内存额度历史、SPILL、Cache或精确外部输入逐个到达。它也不是原问题下界。第三个输出是完成时间、第三个输入是释放时间；不能仅因形状相同，就不加条件地把独立包矩阵直接连乘。

相同矩阵可以共享存储/计算代码，但保留每个包的真实张量接口、原ID及位置。case002的1798个非COPY操作变成397个归属包，397个包只有3种计算响应；**这不意味着原问题只剩三个实体或三个计数变量。** 本轮没有实施R2中更强的对称分支计数DP，不能冒称已经完成。

构造器在宏DAG上按剩余计算路径生成共同拓扑参考序。每次尝试N个核心，用矩阵更新M/V时钟，同时用张量生产核心和已读取位集合估计到达。当前读取集合是未建容量限制的代理，不能当真实驻留。全部模拟配置硬绑定冻结配置并由solve入口检查，不把500cycle用于P1的物理真值；P1里链包构造只是B启发的候选种子。

若原图n操作、e依赖、总输入包-张量pin为p，包数b，在单生产者范围内，索引/粗化/拓扑和矩阵建立约为O(n log n+e)，放置约为O(N(e_macro+p+b))，存储O(n+e+p+b)。输出不能小于O(n)。当前Python集合与排序常数仍有改进空间，没有依据宣称所有35k操作图都已满足最坏时限。

## 4. 固定归属后细化：把通信选择与流水选择分开

对Q2/Q3的当前冻结构图，边界COPY在每核合并后按生产/消费核心集合建立。因此，原图及所有操作的核心归属不变时，SPILL前的切分新增字节分量不依赖如何再分桶和排序：

\[
a_1(o)=a_2(o)\ \forall o
\Longrightarrow D_{\rm partition}(P_1,a_1,\pi_1)
=D_{\rm partition}(P_2,a_2,\pi_2).
\tag{R3-M4}
\]

证明只需逐张量查看官方构图：原始输入按消费者核心建立读取，中间张量按源-目标核心对建立COPY对，最终输出按生产核心建立写出；这些集合不变。该命题限当前实现与成功构图，**不覆盖SPILL量、Cache实际服务路径和Makespan，也不适用于Q1跨子图总经DDR的规则。**

这给出一个有价值的决策分解：先通过包保持数据归属，再在固定归属面上搜索少量顺序。相关68组本轮结果已核对操作核心映射、partition字节不变，但推导不靠这68个例子当普遍证明。

### 4.1 重入切分

读取链的Pipe字串；一个Pipe离开后再次出现，在再次进入前切开。如M,V,M,V拆为[M,V]、[M,V]。与其让不同核反复传递中间张量，更合理的候选是保持同核，在不同链间交错这些阶段。

`refine_response`保持粗链分核，再按该规则细化；`nr_response`则从细包重新分核。它们是刻意分开的消融。

case002：链包71904；保持归属细化71108；细化后重新分核110545。后者增加了跨核中间数据复制，说明不能把“细粒度更多自由度”直接理解为启发式会用得更好。case044保持归属细化也会变慢；只改变顺序不等于必然收益。

### 4.2 有限参考窗口的阶段展开

把粗包内部按连续同Pipe段切开，沿粗包的全局拓扑参考序，每W个包作为一个参考窗口。窗口内用“阶段索引、原包位置”作为Kahn就绪优先级，输出细包的共同拓扑序，再投影为每核子图顺序。W取factor×N，本轮固定试了factor=2/8/32。

重要边界：这不是插入实际屏障，也不是允许任意等待；官方可以让后续COPY提前进入流水，因此**参考窗口宽度不是实际在飞包数或内存峰值的上界**。它只压缩需要尝试的可提交排序族。

伪代码：

```text
base = chain_matrix_assignment(G,N)
owner = immutable operation-to-core mapping from base
phase_packets = split each base chain at Pipe changes
for each selected fixed W:
    compute base-packet topological positions and window IDs
    Kahn-order phase packets by (window, phase_index, base_position)
    output each core's projected phase order with original op IDs
    E0 expands and evaluates the complete candidate
    keep the best confirmed legal incumbent
```

一个候选的额外构造为O(n+e+b' log b')量级；只尝试几个固定窗口值，不枚举全部合法线性扩展。完整执行图仍由E0判断。

## 6. P1：覆盖关系合并，必须保留Task出口意识

Q1中细包通常放大100/1000cycle等待。对当前Task DAG加上每核相邻Task顺序边，得到增广DAG。对相邻同核A→B，合并保持增广DAG无环，当且仅当删除直接边后不存在A到B的其他路径：

\[
\operatorname{contract}(A,B)\text{仍DAG}
\Longleftrightarrow
\nexists A\leadsto B\text{经其他节点的路径}.
\tag{R3-M6}
\]

证明：收缩后新环必须经过合并点；恢复端点后只能是A出发回到B的替代路径，其他情况都已构成原DAG环。反向同理。

当前实现每次合并重算拓扑，不假设只影响两核；保守复杂度取O(b^2(b+e_task))，Python版只在小候选上验证。可用动态可达索引改进，但不要在存在全局路径时跳过检查。

反例：core0的A=V10产生远端C=V5000所需输入，同核随后独立B=M5000。分别执行时6014；把A和B作合法覆盖合并后11005。五项搬运相同，但C必须等待整个合并Task完成。出口保护恢复6014。

正式case002：链种子122820，受保护覆盖合并93126；旧三构造池最好248496。case051链338092，受保护合并385092（更差）。Q1这条线作为有限候选保留，不宣称单调改善。保护A的远端出口还不够：B若引入新的远端输入，融合可能延迟A开始；后续可做输入释放支配检查，仍需E0最终确认。

## 9. 少数优先研究卡

1. **高同质重入包的固定归属展开。** 试验显示最有价值的不是全面重分核，而是先保留高成本内部数据，再在少量参考窗口中交错。下一步把重入负载比例、接口同质性、可同时就绪包宽度作为启用特征。这个触发器目前是看过结果后提出的假设，必须在另一组case/合成扰动上冻结验证，不可声称泛化已证。
2. **块规模选择而非一个统一粗化。** 同时保留链、已有小张量接口块与必要的细粒度候选；记录packet→core和最终subgraph两个层次。主实验已证明三者互有胜负。可用合法下界作安全剪枝；不能把代理点估计当下界。
3. **P1 Task边界收益。** 覆盖合并提供精确合法性工具；出口/输入门控给局部风险提示。固定窗口里优先尝试不会推迟远端关键释放的合并，失败立即保留原方案，不把少搬运或少Task等同变快。

R2理想集参数割、窄边界DP、全局端口消元仍有研究价值，但本轮没有新增官方收益证据支持将它们置于当前主线之前。完整max-plus全局事件消元尤其不能借本轮整数profile测试冒称binary64模拟零差分。

## 10. 文献定位与原创性边界

DAG聚类、关键路径列表构造不是本轮新发明。Tao Yang、Apostolos Gerasoulis的DSC研究以无界、完全连通处理器为背景；不能把其近似界用于这里固定2–5核、共享DDR和固定FIFO。主文献元数据：IEEE TPDS 5(9),951–967,1994, DOI10.1109/71.308533；本轮实际再次读取UCSB作者机构报告页及摘要，未重新阅读全文证明：https://cs.ucsb.edu/research/tech-reports/1994-12 。

max-plus表示沿用R2已读Baccelli等《Synchronization and Linearity》(1992)的固定依赖/固定时延思想。这里的明确推导与新产物是：3输入计算响应的构造、冻结实现下固定核心归属的partition字节不变性、资源重入导致粗化性能损失的可达微图，以及定向细化在正式例的官方结果。没有宣称发现全新通用调度理论或全局最优算法。
