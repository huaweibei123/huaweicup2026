# 原051五核的启动约束下界

在冻结原图、冷Cache、60 B/cycle DDR与跨核500等待的官方服务语义下，必要界为 `12×547 + 2135 + 23×6279 + 1 = 153117`。本轮统一2d5459fa及已归档单点方案的M为157299，距该界4182周期（当前M的2.6586%）；这不是可达性或全局最优证明。

DERIVATION.md与proof.json是构造者证据，INDEPENDENT_REVIEW.md是另一代理只读复核。代理均已暴露题目背景，不称盲审。原理不要求singleton；关键是冷Cache首次填充、共享DDR服务守恒、原计算因果和reload的MTE2 FIFO。

后23阶段6279下界的纯计算证明在同级pro-r02-independent-20260925；本轮补查从该松弛模型迁到官方的必要因果。共享池float与1e-9容差尚未做逐位形式误差证明，本报告是源码语义审计而不是机器检查定理。未新增solver、E0/E1/E2、Task构造或正式用例成绩。
