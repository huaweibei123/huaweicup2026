# 原 051 / 五核 P3 冷启动必要下界：独立源码复核

结论：在冻结原 051、五核、冷 Cache 和当前官方 P3 源码语义下，未发现任意合法切图、分核、FIFO 能绕过新增物理约束的反例。支持必要界 **M >= 153117 cycles**；不要求 singleton，不声称 tight、可达或已由官方运行复现。

本次只读源码、原始 JSON（子审查从原 ZIP 静态解析）和既有证明材料。0 E0/E1/E2、0 solver、0 官方 Task 构造，无仓库改动。按 root 最新要求立即收束，不追加实验或扩大证明范围。

## 1. 已闭合的新增物理条件

以下路径相对工作树 `data/raw/a/official/code/`。

- **任意合法分组不省略原计算或输入。** `multicore_cut_evaluate_problem_3.py:69–94,141–174` 为每核合成一个 Task，逐个保留映射的原计算，图输入在每个实际消费核上重建 DDR→COPY_IN→片上 tensor。`51–67` 中分组优先顺序仍须拓扑合法。证明不依赖 singleton 或某种特定每核词。
- **12 个初始键不同且不可提前小尺寸填充。** 原 051 SHA-256 为 `884e8b12ac1f7a9b569958909680e8c2f6055966a59c9f929ffd5cee48aae43b`。12 个 L1 输入 ID 为 1000000001,3,…,23，各 32768 B，唯一原 COPY_IN producer，各有 24 个阶段 head 消费；原 tensor 无 `logical_tid`/`version`。P3 `398–414` 以片上 tensor 的 logical_tid 或 tid 为 Cache 键；Step2 `343–352` 的 incarnation 保持原逻辑键、size、pos。因此不能借其他 2 B 张量预填这些键。
- **每键首次完成一定是 miss。** P3 `328` 的 Cache 为空；`508–510` 仅在 COPY_IN 完成后插入，`539–549` 在发射时判断命中。若某键全局首次完成的 COPY_IN 是 hit，则发射前已有该键 COPY_IN 完成，与“首次”矛盾。以全局首次完成定义证明，不需要指定原 COPY_IN 或某个核必须最早。
- **已有 DDR backing 和 spill 不取消读入。** Step2 `304–379` 可以省 COPY_OUT，但仍生成同尺寸 COPY_IN 和新 incarnation。`407–440` 重接消费者，不删原生产者边。Step3 `217–220` 只把无 producer 的 tensor 当初始驻留；这里输入与 incarnation 均有 COPY_IN producer。
- **reload 也不能绕过跨核 500 屏障。** Step2 `40–66` 将 producer 计入 use；reload 插在后续 use 前，`443–453` 保持原 seq 顺序。原输入 COPY_IN 与其 reload 同在 MTE2，原输入在固定投影中先出现。Step3 `281–287,579–581,675–701` 原样交付该顺序，P3 `443–474,499–511` 仅在前项完成后推进管线游标。所以即使 backing 重用导致 reload 没有显式原 COPY_IN→reload 数据边，它仍不能越过原读入完成及其 external release。P3 `436–441` 的 source COPY_OUT 完成加 500 判定发生在 Cache 命中之前。
- **并发池不使 12×547 缩为 547 或按总字节只取一次 ceil。** Step3 `74–81` 和 P3 `547–549,575–581` 先对每个 miss 计算 `ceil(32768/60)=547`，再把该时长加入唯一共享 DDR 工作池。P3 `352–372` 按活跃数均分 elapsed，归一总服务率不超过 1；`374–396` 重新预测完成时刻，不新增带宽。Cache 命中走另一个池，但 12 次各键首次完成均非 hit。其他 COPY 竞争只能占用额外 DDR 服务。
- **最终 2 B 输出不可省。** P3 `176–187` 根据原 COPY_OUT 重建最终写回；原最终 root 1428 的 2 B 输出 tensor 1000001439 接原 COPY_OUT 1429。Step2 保持其生产因果。COPY_OUT 不查询只读 Cache，时长至少 `max(1,ceil(2/60))=1`。P3 `684–688` 的 Makespan 包括该输出完成。

## 2. 必要界组合

令 τ_i 为输入键 i 在所有核、所有 incarnation 上首次 COPY_IN 完成时间。上述冷 miss 服务守恒给出

`τ = max_i τ_i >= 12 * 547 = 6564`。

取最后首次完成的输入。它对应首阶段 head 不可能在 τ 之前消费到该输入。该 head 至首阶段根仍有四个不可拆的 524 周期原操作和至少三个 13 周期 ADD，故

`R_1 >= 6564 + 4*524 + 3*13 = 8699`。

先前独立纯计算复核已证明，五核原阶段在任意原操作 owner 与合法 FIFO 下，后续根间隔至少 6279。将此结论用于官方时，需要原生产依赖和跨核至少 500 保持；上节的重建边、reload MTE2 FIFO 与 external release 证据闭合了本次特别关注的适用条件。各后续阶段全部计算依赖前根、全部又是当前根祖先，所以 23 个间隔可以相加；没有把跨阶段 COPY 预取强制串行相加。

`M >= 8699 + 23*6279 + 1 = 153117`。

8699 已含初始 DDR 服务，不能再额外加一次 547。该下界不蕴含存在达到它的合法官方计划。
