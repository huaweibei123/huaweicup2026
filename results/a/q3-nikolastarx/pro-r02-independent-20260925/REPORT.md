## 1. 下界覆盖全部 B，而非仅固定完整 lane

对后续阶段令前一 root 完成于 0，owner 为 a；本阶段 root 完成于 T，owner 为 b。取任何 lane j 的第 r 个原大操作 v，owner 为 c，p=524，g=13，δ=500。

从前一 root 沿该 lane 到 v 的原路径含前面 r−1 个大操作。若 c≠a，路径两端 owner 不同，至少存在一条跨核原依赖。因此 `start(v) >= (r−1)*p + δ*[c≠a]`。同理，从 v 到当前 root 的原路径含后面 4−r 个大操作，以及 d_j 个 ADD（前 8 lane 深度 4，后 4 lane 深度 3）。若 c≠b，至少还有一条跨核边，故 `end(v) <= T−(4−r)*p−d_j*g−δ*[c≠b]`。

两个论证分别在 v 之前和之后的路径上，不会把同一条通信重复计算。任意更多迁移只增加非负等待；任意 ADD owner 或合法 FIFO 也不会删去这些原路径。因此不需要完整 lane 同核、collector 在重核、固定 ADD 归属或固定 FIFO。

去掉非负链前后缀、使用 d_j≥3 后，核 c 的全部 524 周期操作完整包含在共同窗口 `[δ*[c≠a], T−39−δ*[c≠b]]` 中。同核单 V 槽互斥使该核最多容纳窗口长度除以 524 的下取整。即使忽略全部 ADD 对同一资源的占用，这仍是必要条件：

`48 <= Σ_c max(0, floor((T−39−δ*[c≠a]−δ*[c≠b])/524))`。

- T<6279，a=b 时容量至多 `11+4*9=47`。
- T<6279，a≠b 时容量至多 `2*10+3*9=47`。
- 首阶段没有起点广播项；T<5779 时容量至多 `10+4*9=46`。

整数 DAG 校验器独立计算了 5778/5779、6278/6279 两侧的容量。证明本身同样适用于实数起止时刻：严格短于阈值时相应下取整不变。

**必要前提**：五个核；524 周期原操作不可分且完整占用其 owner 的唯一 V 槽；原依赖是前驱完成到后继开始的至少 500 延迟；没有复制计算、删除依赖、改变 ADD 树或提前执行首阶段。不能把该公式无条件用于其他核数、其他时长/树形、Cache 可豁免跨核延迟的模型或非同一官方语义。

首阶段式 FJ.7 的 root-core 项未写 `max(0,...)` 仅是形式省略：任何可行阶段已有至少 `4*524+3*13=2135` 的链路径。若将式子定义为任意实数 T 的容量函数，应统一补上非负截断；这不改变定理。

## 2. 阶段下界可以相加

每个阶段的全部 59 个原计算节点都是本阶段 root 的祖先，且下一阶段每条 lane 的首操作都真依赖前一 root。故前一阶段全部计算已完成后，下一阶段计算才能开始。无论 owner 和 FIFO 如何选，都不能计算流水跨过 root。

因此最后 root 的完成时刻至少为 `5779+(S−1)*6279`。本结论不禁止 COPY、预取或其他被本模型忽略的物理服务重叠；不能据此给官方服务时间简单逐项相加。
