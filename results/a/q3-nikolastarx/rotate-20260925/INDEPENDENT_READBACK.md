# 旋转归约三格独立只读复核

本审计读取冻结源码 `b1dd5d7e7420f48baa37d3dee6801a04aecb15b2` 对应的已存在 3 次 E0 原件；**新增评分 0 次**，未执行求解器或构造器，未写中央成绩台。审计对象为 051、024、016 的 P3 / 5 核，范围仅本目录。

## 审计结论

三格 feed、batch、receipt、最终 plan、seed plan、实际被评估 plan 与完整 result 相互一致。原始计算算子共 25,370 个，均恰好出现一次，算子类型、管线、524/13 周期时长与原图不变。按原始 tensor 边独立追溯每阶段 12 条四算子向量链及 11 个原始二叉 ADD，未发现重结合、切断向量链或重复/遗漏。

实际 root 所在核逐阶段为 `0,2,0,2,…`，与 `collector_policy=rotate_heavy`、`collector_cycle=[0,2]` 一致。固定与旋转 k5 所有 lane 归属完全相同，12 个不可变输入的归属跨阶段固定，lane 数为 `[3,2,3,2,2]`。纯本核子树的 ADD 留本核；混合 ADD 都在该阶段 collector。逐条原树叶到根路径最多一次跨核。上述检查来自原图边、实际 plan 和官方 timeline，不仅是相信 metadata。

## 搬运与 Cache 字节核对

|图|跨核连接数|原图 COPY 字节|调度 COPY 字节|额外字节|spill|Cache hit / miss 字节|字节命中率|
|---|---:|---:|---:|---:|---:|---:|---:|
|051|236|393218|394162|944|0|138 / 393550|0.035053%|
|024|1006|393218|397242|4024|0|600 / 394628|0.151811%|
|016|3046|393218|405402|12184|0|1824 / 397484|0.456790%|

由原 tensor producer/consumer 独立去重到 `(tensor, source_core, target_core)`，固定与旋转 k5 的跨核连接数均为 `10N-4`；全为 2 字节标量，匹配官方 transfers（236/1006/3046）。双向 COPY 操作的额外调度量为 `4*(10N-4)=40N-16` 字节。所有字节命中/未命中由 cache_events 重新求和，命中字节为 `6*(N-1)`，不是次数比。原图 12 个 32768 字节输入与 2 字节输出合计 393218。

`ddr_bytes` 沿协议表示 **scheduled_copy_bytes（调度搬运）**，不能当物理 DDR 读写量。spill=0 仅是三份官方轨迹事实，未证明所有结构输入均零 spill。没有同计划 P2 对照，CacheGain 未测。
