# 已有正式结果与全局下界的差距

本表复用两批共 30 份已完成、已入成绩台的 E0 结果。脚本逐份检查 feed 引用的 plan/result/run/manifest 字节哈希、图与下界身份、冻结官方源码/配置及结果数值；没有启动 solver/E0/E1/E2。`audit.json` 保留全部 30 格，不只保留下面的改进项。

下界证明与适用域见 `docs/a/q2-nikolastarx/OPTIMALITY_BOUNDS.md`，原证书为 `results/a/q2-nikolastarx/goal-20260924/global-bounds.json`。令 L 为必要下界、U 为已有官方可行方案 Makespan，则 L ≤ OPT ≤ U。U/L 给出相对全局最优值的近似因子上限，(U−L)/U 给出从现有方案出发可能再降低 Makespan 的比例上限。它不是已知可达到的改进量，也不界定 DDR 或求解耗时的最优值。
