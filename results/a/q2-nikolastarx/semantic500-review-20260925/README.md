原图重建验证：083/044/092 分别有 31/11/142 个分量，每个分量都是 124 个计算算子（50 CONV、50 RELU、24 ADD）。50 个共享 L1 张量合计 930,400 B，超过每核 L1 的 524,288 B。四核日志中每个 cohort 都已降为单分量，却全部超出 raw envelope；继续减小 cohort 数已经没有空间。当前 vector repair 因非全 PIPE_V 结构而不触发，repair_construct_calls=0。
