500 格额外 DDR 总计由 3,043,860,416 B 增至 4,159,738,560 B（+36.66%）。55 格 Makespan 与 DDR 同时下降，199 格 Makespan 下降但 DDR 增加，14 格 Makespan 下降而 DDR 相同，232 格两者相同。不能将本轮称为双指标同时改善。

新增字节净增量中，切分新增占 77.66%，spill 新增占 22.34%。014、072 两图在五个核数合计贡献净增量的 77.09%；这说明字节退化集中，不能据此断言其他图不需要优化或硬编码例外。

5 核当前平均 8.268 MiB 中，切分新增 5.444 MiB，spill 新增 2.825 MiB；21/100 图仍有 spill，79 图无 spill 不等于没有跨核/切分额外搬运。

## 解释与后续

当前选择器按 `(makespan, added_copy_bytes)` 严格字典序比较；第二项只在 Makespan 相等时决定胜负。这只保证相对候选集内已评分 baseline 的字典序不退化；本轮与固定前版配对实测 500 格均无 Makespan 退化，但 DDR 可以增加。很多不同速度和字节取舍的候选会同时属于二者的 Pareto 集，不能只凭字节较少替换更快方案。

后续优先验证容量感知的张量复用、消费者就近分组、生命周期缩短与分核/时序协调，争取同等或更低 Makespan 时减少切分/溢出搬运。尤其关注微小主指标增益伴随大幅字节增长的机制；不按 case ID 写特判，不擅自把官方主目标改成任意加权和。将两个指标同时放进固定算法全量报告，保留有证据的质量取舍。

R05 003/K2 机制试验的约 18% 降幅指调度总 COPY 字节，相对旧 seed；它不是本轮额外 DDR 全量提升。该候选官方 Makespan 变差，未纳入当前算法。
