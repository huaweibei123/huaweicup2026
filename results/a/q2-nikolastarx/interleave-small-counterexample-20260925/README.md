# 合成反例：内存贪心不保证最小峰

固定单核 M 链 1,2,3,4 与 V 链 5,6,7,8，8个单位时长op；全部70种交错合法。容量L1=13、UB=17。seed与greedy闭触碰峰均为L1=25/UB=11；最优交错 `[1,5,6,7,2,3,4,8]` 为23/11，最大归一峰从25/13变为23/13。

这里只证明内存贪心非全域最优，未证明它比seed更差，也没有无spill或官方Makespan结论。小枚举只作数学oracle，不进入正式求解器。固定随机种子20260925的有限搜索在第7个实例找到后停止，共490个oracle交错、0.044秒；root对保存夹具用直接逐tensor闭区间求和独立复核70种交错。原始fixture和搜索计数原件不变，另存核验记录。
