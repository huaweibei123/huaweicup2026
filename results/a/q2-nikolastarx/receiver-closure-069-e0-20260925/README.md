## 本次实测解释

只读比较旧图与两份已取得的 E0 输出，得到 `link-replacement-readonly.json`：

- op460（DIV，30 周期）从核 1 移到核 2。两份 trace 中，它由 10821–10851 提前到 10301–10331，即完成时刻提前 520 周期。
- 两条原输入跨核连接（tensor 1000000494，768 B；1000000483，32 B）消失，但输出 tensor 1000000495（768 B）新增核 2→核 1 的跨核连接。
- 因此它不是把原关键依赖链的跨核边界整体消除：计算提前后，输出仍要跨回去。该结构事实与仅 3 周期的最终改善一致；精确分解各项因果贡献仍需额外对照，不能把 520 当作已兑现的 Makespan 收益。
