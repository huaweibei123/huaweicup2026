## 正文具体适配

1. 第1章将计算图、硬件资源、子图方案三节归入“计算图与硬件执行约束”，与背景和问题分析构成清晰分组。
2. 第3章从已有段落边界明确分出决策变量、依赖与执行顺序约束、目标函数与可行域；共用框架、方法适用性、无环性与下界分别归组。
3. 第4章区分基础候选和细化择优；支路构造、执行全序与无环性证明保持连续。没有将其强行重写成缺少正文支撑的独立建模节。
4. 第5章把原5.2.1的空闲区间初始分配移至新5.3.1，把局部超图割及工作量保护归入模型求解；新5.2只承载超图表示、复制代价和增量公式。辅助流网络图随算法归属移动。引出边界复制量的原段落也随模型移动，保留“后续”指向。
5. 第6章将原6.2.3的森林结构判定与执行序列构造移至新6.3.1；归约树存储峰值与非交错排序证明留在6.2；复杂度从四级提升到三级。
6. 第7章按求解质量、计算效率、比较与局限归组。第8章收短标题；摘要、参考文献及附录原文不改。

所有非标题行逐文件完整保留，移动的是完整内容块。没有删除定理条件、公式、伪代码、数据、图注和来源说明。图、表、算法标签与引用由 LaTeX 重算；新的编号与页码不得用于旧 PDF 批注。保留“固定候选方案下界”和“非交错子树”的限定，未把复制量改称实际额外 DDR 搬运量。

## 复现与整合

用 `CHECKPOINT` 指向含 `main.tex`、`anonymous-paper-v10.pdf` 和 `source/chapters/` 的冻结 v10，先核 [input-manifest.json](input-manifest.json)。`$CHECKPOINT` 只表示调用者提供的路径，不硬编码个人目录。

```sh
python3 scripts/restructure_paper_toc.py --checkpoint "$CHECKPOINT" --output paper/review/toc-structure-20260927
```

将生成的 `main.tex` 放到独立构建目录，并从同一 v10 复制 `gmcm2026.cls`、`gmcm-numerical.bst`、`figures/`、`fonts/`。字体和图件不得取另一个版本。连续运行 XeLaTeX 直到交叉引用稳定，再转 PDF：

```sh
xelatex -no-pdf -interaction=nonstopmode -halt-on-error main.tex
xdvipdfmx -q -o paper-v10-toc.pdf main.xdv
```

验证器使用已有 `pypdf`，`--build` 指向编译目录（最终编译日志名为 `compile-5.txt`）：

```sh
python3 scripts/validate_paper_toc.py --checkpoint "$CHECKPOINT" --review paper/review/toc-structure-20260927 --build output/paper-toc-structure
```
