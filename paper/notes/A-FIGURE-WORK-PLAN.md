# A题绘图分工与验收任务书

版本：v5｜2026-09-26｜范围：现有初稿的 18 组图

本版用于甲、乙直接分工执行。每张图保留五项：**类型与内容、绘图流程、输入材料、交付指标、验收标准**。绘图流程说明“按什么步骤画”，交付指标回答“交什么、交多少”，验收标准回答“怎样判断完成”。文中的要求是后续制图任务，不表示图件或数据已经验收。

## 一、独立分工与统一交付要求

### 1. 责任分配

| 负责人 | 负责方向 | 主责图号 |
|---|---|---|
| 甲 | 流程、结构、容量与真实执行机制 | 4-1、4-2、4-3、5-1、5-2、5-4、6-1、6-2、6-5、6-6，共 10 组 |
| 乙 | 加速比、缓存收益、质量与耗时、下界统计 | 4-4、4-5、5-3、5-5、5-6、6-3、6-4、6-7，共 8 组 |

**每个人独立完成自己名下的图，包括读取已有数据、整理输入、绘制、检查、编写图注和最终导出。** 不分拆给另一人做子图，不安排两人互审，也不以对方完成某张图作为开工前提。**图 5-4 的时间线、统计面板及整图拼版全部由甲负责。**

每人直接使用已发布的数据、初稿和证据索引。需要同一份已有数据时各自读取，不等待另一人整理；材料不足就登记具体缺口，并继续其他可完成的图。统一规范直接按本文执行。

### 2. 每组图统一交付包

所有图均交付以下内容，后文只列各图特有的增补项，避免重复：

| 交付项 | 最低要求 |
|---|---|
| 成图 | 1 份 SVG 矢量图、1 份 PNG 预览；一组多面板图同时保留各面板来源 |
| 可编辑源 | 流程/结构图提供 `.drawio`；数据图提供 `.py` 及实际生成命令 |
| 绘图输入 | 实际使用的 CSV/JSON；结构示例提供节点、边和映射清单，不强造统计数据 |
| 图注 | 1 段，说明图意、单位、样本/案例、比较条件及必要局限 |
| 来源与检查记录 | 1 份简短说明，记录版本、输入路径/哈希、有效与缺失数量、验收结果和未完成项 |

不重复拷贝大型原始 Trace 或官方图数据：保留固定来源、哈希和用于作图的必要派生表即可。后续论文如需 PDF 插图，再从同一源文件导出；本任务书本身只交 Markdown。

### 3. 全部图通用的完成条件

- **数值可复核**：图中每个点、条块、阈值和事件标记有来源；整数计数/字节与原表一致，均值按相同公式计算后与正文显示精度一致。
- **口径一致**：Makespan 用 cycles，求解耗时用 s，搬运量明确 B 或 MiB；平均加速比按逐用例比值求算术平均。
- **版面可用**：在论文实际插入宽度检查中文、图例、坐标、箭头，无缺字、遮挡、裁切；同类图保持字体、颜色含义和线型一致。
- **状态真实**：缺数据列明缺口，不填 0、不造散点或时间线。只有已完成的检查才写“通过”；主责人完成验收记录后交整稿负责人确认。

## 二、甲负责的 10 组图

### 图 4-1｜P1 两层决策与官方评价流程

**类型与内容**：Draw.io 分层流程图。上层画结构识别、切图、分核、Task 顺序和候选选择；下层画边界 COPY 重建、官方核内调度与事件模拟。两层通过最终方案文件连接。

**绘图流程**：

1. 阅读固定 P1 入口，列出结构识别、候选构造、在线选择和官方评价节点。
2. 按“求解器决策 / 官方评价”分成上下两层，以两个规定字段组成的方案文件连接。
3. 添加流程箭头、在线 E1 与最终 E0 标记，以及 Makespan、额外 DDR 出口。
4. 对照固定主结果所绑定的算法版本检查主线，调整节点间距后导出。

**输入材料**：P1 初稿 4.1、4.4.1～4.4.4；统一 v4 源码及官方输出契约。

**交付指标**：1 张双层流程图；必须标出两个提交字段 `node_to_subgraph`、`core_schedules`，以及 Makespan、额外 DDR 两项评价出口；附流程节点与源码模块的简短对应表。

**验收标准**：

- 切图、分核、每核 Task 顺序三项决策齐全；没有赋予提交者直接控制官方 Pipe 顺序或等待时间的自由。
- 在线 E1 评分与独立最终 E0 复评分开表示。
- 后续局部研究模块未混入当前完整 v4 主线，流程和主结果属于同一版本。

### 图 4-2｜分叉-汇合结构的阶段划分与分核

**类型与内容**：Draw.io 三联结构图，依次展示原始 DAG、阶段/前沿/归约尾划分、投影到各核的 Task 次序。

**绘图流程**：

1. 选择含分叉、并行链和汇合的小型示例，保存节点与依赖清单。
2. 绘制原始 DAG，再复制相同节点布局，标出阶段、前沿和归约尾。
3. 按核心建立泳道，将对应 Task 按依赖顺序排入，统一节点 ID 和核颜色。
4. 逐节点、逐边核对三幅图，补图例和“条块宽度无时间含义”说明。

**输入材料**：P1 初稿 4.4.2、分叉前沿构造定义；自行整理的小型示例节点/边表。

**交付指标**：1 组三面板图；1 份节点、依赖、子图和核心映射清单；三幅图使用相同节点 ID。

**验收标准**：

- 全部示例节点在划分中恰好覆盖一次，依赖关系未遗漏或反向。
- 各核 Task 顺序与示例依赖相容，颜色及外框分别表达什么有图例。
- 图注明确“结构示例、条块宽度无时间含义”，不声称实测加速或零 spill。

### 图 4-3｜输入错峰前后的多核执行时间线

**类型与内容**：Matplotlib 配对甘特图。比较 case051 / 3 核的 control 与 paced，显示源核、远端核的搬运、计算和归约尾。

**绘图流程**：

1. 核对 control/paced 的图、核数、配置及结果身份，提取两端事件起止表。
2. 按相同核/Pipe 顺序建立上下两个面板，以真实开始周期和持续时间画甘特条。
3. 共用绝对时间轴，标记输入完成、Task 完成、远端返回、归约尾，并框出首轮。
4. 将最晚结束周期和额外 DDR 与 E0 结果核对，补充配对变化及单例范围说明。

**输入材料**：P1 初稿 4.4.6；stage-j 固定配对的计划、E0 结果和原始 Trace。

**交付指标**：2 个上下配对时间线面板；标出大输入完成、源 Task 完成、远端返回、归约尾开始，并单独标示首轮；提供所用事件表。

**验收标准**：

- 两端使用同一绝对时间尺度、相同核/Pipe 行顺序，操作按真实身份匹配。
- 完整事件表的最晚结束周期与对应官方结果一致；局部裁剪明确显示范围。
- 首轮与后续阶段区分，局部提前不直接写成所有指标改善；周期和额外字节变化均有配对依据。

### 图 5-1｜P2 张量通信优化技术路线

**类型与内容**：Draw.io 分支流程图。结构初解、gap/hypergap 候选、固定分核重排、去重和完整评分汇入最终方案；侧栏放容量和下界分析。

**绘图流程**：

1. 从 c665 固定入口提取结构初解、gap、hypergap 的调用关系和触发条件。
2. 画候选分支，再汇入固定分核重排、去重、完整评分和最终选择。
3. 将容量诊断、下界及未接入研究模块放侧栏，标明其与主线的关系。
4. 核对候选保留规则、评分次数及初稿主结果表中的方法名称，完成排版导出。

**输入材料**：P2 初稿 5.4、证据索引 S3/S4、固定主算法源码。

**交付指标**：1 张流程图；明确“结构初解”“gap”“hypergap”三类候选关系及完整评分出口；附主线/辅助研究模块清单。

**验收标准**：

- 分支、候选保留和评分次数说明与冻结入口一致。
- 静态张量通信目标与最终 Makespan 评价分开，不能将局部最小割表述为全局调度最优。
- 尚未接入的容量保护或就绪匹配等研究模块不画入主线。

### 图 5-2｜张量生命周期与容量约束

**类型与内容**：Matplotlib 生命周期区间图＋内存占用阶梯图。展示同一步输入和输出共同驻留，L1、UB 分别设置容量线。

**绘图流程**：

1. 整理物理张量 ID、大小、存储空间、产生和最后使用位置，明确区间端点语义。
2. 按物理身份去重，逐位置累加存活字节，分别计算 L1 和 UB 占用。
3. 上方画张量生命周期区间，下方画两类存储占用阶梯及容量线，标出共同驻留位置。
4. 手算峰值前、峰值处、释放后三个位置，核对曲线并标明示例或真实数据来源。

**输入材料**：P2 初稿 5.5.1；可手算示例，或绑定固定计划的真实完整物理序列。

**交付指标**：1 张张量区间面板＋L1/UB 各 1 张占用面板；1 份生命周期表及三个位置的手算核对记录。

**验收标准**：

- 物理张量按身份去重，区间端点符合所用闭区间语义；三个手算位置与曲线数值一致。
- 横轴明确是执行序号或真实周期，不能混用；L1 与 UB 分开核对。
- 静态估计不标为实际并行峰值；没有官方 spill 记录时不画虚构 spill 事件。

### 图 5-4｜通信、容量与调度耦合的典型正反例

**类型与内容**：Matplotlib 组合图。用典型配对时间线、搬运量分解和全量质量/DDR 取舍解释“搬运减少仍可能变慢”。正文优先选择 case003 / 2 核的 R05 反例。

3. 从 S16 的完整版本对计算逐格周期和额外 DDR 变化，绘制散点；零分母项单独处理。

**输入材料**：P2 证据 S15 的 R05 两方案及 Trace；S16 的完整 500 格 DDR 对照。

**验收标准**：

- 时间线端点、总周期、搬运数字与各自原件一致；基础、额外、scheduled COPY、spill 的定义不混用。

- COPY 活跃时长占比不称为带宽利用率；E0 与下界的差不称为实测 DDR 等待。

## 三、乙负责的 8 组图

### 图 4-4｜P1 多核平均加速比及逐例分布

**类型与内容**：Matplotlib 平均折线＋箱线/散点。主图展示 1～5 核平均加速比，旁图展示各核数逐例差异。属于优先完成的题面核心结果图。

**绘图流程**：

1. 读取完整 v4 结果和固定单核基线，检查坐标、状态和分母身份。
2. 对 2～5 核逐例计算 B/M，再按核数求算术平均；规定主曲线单核点设为 1。
3. 绘制五个核数点的折线，并用实际逐例值绘制旁侧箱线或散点。
4. 与表 4-1 核对显示精度，检查离群点、图例和方法名后导出数据及成图。

**输入材料**：P1 完整 v4 100×5 结果、固定单核分母、初稿表 4-1 和统计快照。

**交付指标**：1 张含 5 个核数点的主曲线＋1 张 2～5 核逐例分布；交付逐格比值和分核汇总两张表。主曲线 k=1 按题面设为 1。

**验收标准**：

- 输入覆盖 100 个用例×5 核，坐标不重不漏、身份和有效状态一致；各核数均值与正文同精度一致。
- 先算每例 B/M 再平均，不用总周期之比；优化后单核观测不替代规定基点。

### 图 5-5｜P2 质量-耗时与尾部延迟

**类型与内容**：Matplotlib 质量/耗时散点＋经验累积分布。展示完整求解时间和尾部，复用图 4-5 的视觉样式。

**绘图流程**：

2. 将不同平台及并发条件分组，计算有效样本数、median/P95/max。
3. 绘制质量-耗时散点和分核 ECDF；只有具备实测数据时才增加冷启动面板。
4. 将分位数与原始记录核对，补足资源、独立复评和缺测说明，再按统一样式导出。

**验收标准**：

### 图 5-6｜全局下界距离分布

**类型与内容**：Matplotlib 经验累积分布图。横轴 `U/L_global - 1`，纵轴累计比例，按核数区分并标注 5% 阈值。

**绘图流程**：

1. 匹配逐例官方 U 与全局下界 L，核对下界适用域和证书，排除固定 FIFO 界混入。
2. 对适用且 L>0 的项计算 gap；发现 L>U 先查证，未认证项单列。
3. 按核数排序有效 gap，生成 ECDF，绘制五个核数组别并标出 5% 阈值。
4. 核对有效样本、阈值计数及曲线末端，注明分母与下界局限后导出。

**输入材料**：P2 全局下界说明、逐例界记录、对应主算法官方 Makespan。

**交付指标**：1 张含五个核数组别的 ECDF；1 份逐例 U、L、gap 和证书状态表；1 张各核数有效数量、未认证数量及 gap≤5% 计数表。

**验收标准**：

- 仅对适用且 L>0 的记录计算；发现 L>U 先排查版本和条件，不裁成 0。
- ECDF 非递减，有效集末端为 100%，分母清楚；不能只凭五个阈值计数伪造完整曲线。
- 固定 FIFO 界不混入全局界；较大 gap 不写成必然可实现的优化空间。

## 四、统一绘制与交付流程

### 1. 三步推进

1. **各自准备样板与数据**：甲以图 4-1 建立自己的流程图样板，乙以图 4-4 建立自己的统计图样板；各自按本文规范设置字体、字号、颜色并核对源数据版本，无需等待对方确认。
2. **再完成核心结果**：乙优先完成 4-4、5-3、6-3、6-4；甲同步完成三问流程及结构/容量图。数据未齐的图登记具体缺口。
3. **最后补机制与验收**：甲完成真实 Trace 案例和图 5-4 拼版，乙完成效率和下界统计；各图逐项检查后导出终版。

### 2. 每图导出的四个步骤

1. 保存源文件和实际绘图输入，记录图号、文件版本及输入数据版本。
2. 从源文件生成 SVG 与 PNG，多面板图统一字号、图例和面板编号。
3. 在论文实际插入宽度查看，检查坐标、文字、裁切和数据标记；发现问题后从源文件修正并重导。
4. 补齐图注及验收记录，明确本次完成内容、已通过的检查和仍缺的材料。

图 5-4 先分别生成时间线与统计面板，再等比拼版；数值、筛选规则或坐标范围变化时，从对应数据与脚本重新生成，不直接修改导出图。

### 3. 终版交付判定

每人独立按自己图件的验收条目检查、记录结果并提交整稿负责人，不要求另一位绘图者复核。有未满足项则保留“待补数据/待修改”，不能仅凭图已导出宣布完成。涉及新实验的缺口交算法负责人确认，不由绘图分工自动增加实验预算。
