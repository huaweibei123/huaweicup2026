## 统一视觉规则

**制图前必读：[论文图件制作与验收规范](FIGURE_PRODUCTION_PROTOCOL.md)。** 此文件集中保存用户全部制图要求及最新更正；机制图默认两阶段，中文在生图时直接排版，第三阶段仅按需。图号、图名、图注与分图标题由 Markdown／LaTeX 管理；机制图优先原生透明背景。

- 最新语言约定见[中英文边界与术语契约](TERMINOLOGY.md)：解释用中文，题面原词、代码标识、通用短术语及数学符号保留英文。机制图按需采用“结构稿→生图”两阶段或增加代码复刻的三阶段，不强制全图重绘；数值图始终由真实数据代码生成。
- 同一真实图的节点 ID、位置与张量大小，在三问机制图中保持不变；新增硬件能力用局部高亮解释。
- 子图身份用外框色和 sgid；Core 用泳道；Pipe 用固定色，三种含义不混用。M：蓝，V：紫，MTE2：青，MTE3：橙；等待为浅灰斜线，跨边界传输为橙色虚线并标字节。
- 同硬件、同图、同核数的方案对比共用时间轴、字号、图例；每一条执行色块来自 trace。三问硬件变化单独解释，不把不同场景的成绩差归因于纯算法改进。
- 主图保持完整时间范围；局部放大另设窗口并注明区间。优先图形直接标注，避免让读者频繁找图例。
- 真实 JSON 子图必须标明裁剪边界与外部依赖；概念示例写明“示意”，不得配上未经实测的 Makespan。
- 本文借鉴逐步建立直觉、固定对象连续变换和反例解释的叙事方法，不复制第三方画面。正文用连续分图，交互演示是同源补充材料。
