## 编译

安装 TeX Live 2026 或提供对应宏包的 XeLaTeX 环境，进入 source 目录执行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error -jobname=anonymous-paper-v9-layout-04 main.tex
```

首次编译需运行完整 latexmk 流程，使目录、页码与交叉引用稳定。不要从 Markdown 构建器重新生成 main.tex 后覆盖本次设置。字体按原包许可使用，见 source/fonts/README.md；本包实际使用字体随源码提供，不依赖个人电脑绝对路径。
