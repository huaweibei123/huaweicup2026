图 X　问题二的三种完整方案及其选择过程。（a）算法读入原始图、核数和固定配置后，先生成并保留基础方案 P0，再尝试生成空闲区间方案 P1。即使 P1 与 P0 相同，算法仍以调整前的 P1 为输入，尝试基于超图作局部调整。只有调整前后的原始 COPY 字节数均为有效的非负整数，且调整后的数值严格小于调整前，才继续执行重排并尝试生成完整方案 P2。如果局部调整或重排不支持当前结构，或 COPY 字节数未严格下降，则不生成 P2，继续比较已构造的完整方案。如果 P1 构造失败、调整或重排发生非预期错误，或者字节数证据无效，则直接返回 P0。（b）算法按 P0、P1、P2 的构造顺序删除重复的完整方案。若只剩 P0，则直接返回；否则逐份调用在线评分函数，总调用次数不超过三次。先比较总完成时间（Makespan），相同再比较额外 COPY 字节数；两项都相同时保留先构造的方案。评分出错或评分结果无效时返回 P0。

“原始 COPY 字节数”是在重排前比较的构造阶段数据，仅用于决定是否尝试生成 P2，不能据此推断最终总完成时间会缩短。“额外 COPY 字节数”是完整方案评分返回的第二比较量，两者统计对象不同。评分函数只接受状态为 `ok` 且两个指标均为非负整数的结果。图中的“三次”指在线评分函数的调用上限，不等于外部正式复评次数；论文成绩仍须用未修改的官方评价器复评。P2 对应固定源码中基于超图局部调整后的完整重排方案。
