## 1. 核心科学事实与逻辑修正汇总

本版针对 v1 初稿进行了系统性核查与深化修订，修正了部分表述偏长、过于抽象或与代码实现存在偏差的问题，彻底落实用户指令要求的五项必要纠正：

### 1.1 问题一（`p1-complete-flow`）
1. **`base1`（独立支路切分范围）**：由原笼统的“独立计算支路”更正为**“切分过大的独立计算部分”**，忠实体现算法仅对负载或体积超过门槛的支路实施切分，而非无条件处理所有独立计算。
2. **`base4`（核心数决策依据）**：修正原“按两项选核心数”的模糊表述，准确拆分为**“按共享输入选核心数，或按分叉分配子树”**，忠实反映两种不同的启发式分支。
3. **`mode2`（模式命名）**：将模式代号准确订正为 **`root-heavy-fused`**（非 `root-heavy`）。
4. **`base_note`、`intact_note`、`branch_note`（长图注与保底机制）**：
   - 三个长注释节点统一执行 `move_to_caption` 策略，图内文本置空（`proposed_figure_text: ""`），完整解释移交图注与正文第 4.3 节；
   - 准确说明回退逻辑为**“保留已有合法最优方案”**，明确全流程共享至多 10 次在线 E1 评测预算用尽时的安全退出机制；
   - 彻底删除“方案哈希去重表维护”、“无条件回退单核”等虚构描述，忠实于源码中基于已有父方案/基准方案的兜底逻辑。
5. **`helper_text`（援助核心分配能力界限）**：明确说明援助核心局部重分配采用轻载贪心启发式，**“不保证单步消除所有环”**，依赖外围拓扑合法性检验与多阶段推进。

### 1.2 问题二（`p2-local-cut` 与 `p2-three-plans`）
1. **`p2-three-plans: keep`（P1 方案继承与演进）**：明确原 P1 方案即便与 P0 拓扑同构，**仍予以保留并作为后续局部超图调整的输入基准**，仅在最终进入完整候选列表时实施去重，纠正了原“若同构则丢弃原 P1”的错误断言。
2. **`p2-three-plans: dedup`（方案比对机制）**：将去重机制明确定义为**“Python 方案对象值比对”**，彻底消除“全量哈希表”、“文本序列化去重”等技术臆测。
3. **`p2-three-plans: skip`（跳过分支与候选状态）**：当局部调整无改善或重排失败时，明确表述为**“保留已有候选”**，不武断断言“候选集恰为 2 个”（实际可能仅有 1 个或 2 个）。
4. **`p2-three-plans: tie`（平局决胜用语清理）**：消除“平局决胜”黑话，规范表述为**“指标相同时保留先构造的方案”**。
5. **`p2-local-cut: guard_cap`（完全忠实 `binary_hypercut.py:198–259` 源码实现）**：
   - 明确流水线上限 `caps` 为调用方传入（初始分配必须满足上限）；
   - 迭代超额检查时，取**“首个超限的核心与流水线”**；
   - 在导致超额的迁入链中，选出**“在该流水线上耗时最长的一条链”**；
   - 若存在相同耗时，严格**“按单元编号升序破平”**，并将其锁定回初始分配核心。
6. **`p2-local-cut: guard_accept`（严格区分两层判定门槛）**：
   - 明确内层局部割返回条件为**“满足各流水线上限且局部复制成本非严格增加（$\operatorname{Cost} \le \operatorname{Cost}_0$）”**；
   - 明确外层重排触发条件为**“全图预 Step 2 原始复制字节数产生严格下降（$\text{after} < \text{before}$）”**。
7. **`p2-local-cut: guard_bound`（解耦局部流求解与全局评测预算）**：
   - 单元格执行 `move_to_caption`（`proposed_figure_text: ""`），技术细节移入正文；
   - 明确至多求解 $r+1$ 次最大流（$r \le 16$ 为自由移动链数量），且初始分配在每次迭代中始终可行；
   - 强调该上界属于局部规划循环，与全局至多 3 次在线离散仿真评测预算**完全解耦**。

### 1.3 问题三（`p3-forest-decision`）
1. **`scope`（归约森林结构适用限定）**：严格忠实 `forest_memory_order.py` 判定范围：
   - 至少包含两个树状连通组件，且至少包含一处多子算子汇聚结构；
   - 每个算子均为已知尺寸的单一输出；
   - 非根算子输出仅被唯一父算子消费，根算子输出作为外部依赖。
2. **`order`（子树排序决策准则）**：准确表达为**“按 $h_i - r_i$ 降序（即非升序）排定次序”**，并在指标相同时**“按算子编号升序破平”**。
3. **`distinct`（编码比对机制）**：明确说明为**“与当前最优方案 `winner[0]` 直接比对编码字节”**，避免重复评测，纠正原“维护历史全量方案去重表”的表述。
4. **`guarantee`（理论性质界限与移出图框）**：
   - 单元格执行 `move_to_caption`（`proposed_figure_text: ""`）；
   - 明确该最小化性质仅是在非交错树模型推导下对单棵树局部内部结果存储峰值的理论保证；
   - 明确指出该保证不改变既定分核归属，不代表真实芯片物理 L1 或片上 Unified Buffer 的占用峰值，亦不推断官方评测 Makespan 缩短或缓存命中率必然提升。
