# 摘要

面向多核神经网络处理器的计算任务执行需求，本文研究数据流计算图的子图切分、核心分配与调度定序联合优化问题。在由算子与数据依赖构成的有向无环图中，方案需协同确定算子到子图的划分、子图到计算核心的指派以及各核心上的任务执行全序。针对赛题递进的硬件执行语义，本文构建了轻量结构构造与有限模拟闭环择优的求解体系。

针对问题一中子图物理隔离、跨任务数据必须通过片外主存中转的通信约束，算法分析前沿拓扑与并联支路，提出分支援助重分配机制；利用桥树分解将过载核心的独立计算分支剥离并迁移至轻载核心，在数学上证明了基于拓扑高度波次的重构能够消除循环等待、保证调度时序的拓扑可行性。针对问题二中同核子图合并、允许私有缓存跨子图复用数据的特性，算法构建超图模型刻画张量在多核心间的边界复制代价，并在局部最小割求解中引入计算流水线工作量上限保护，防止算力向单一核心过度倾斜。针对问题三中引入片外共享只读缓存的架构演进，算法针对多分支树状归约结构，在逐棵子树连续处理的限定模型下证明了深度优先后序遍历可使内部结果的峰值内存占用达到极小，引导数据在片上缓存中紧凑驻留。

全套固定算法在官方全部100张计算图与1至5核的测试场景中完成系统评测，每题均获得500个完整合法的调度结果。在5核场景下，三类问题的官方模拟平均加速比分别达到4.0553、4.5498与4.7576。在问题三保持切分方案不变的成对测试中，启用只读缓存相比关闭缓存取得1.0829的平均加速比，平均字节命中率达31.36%。求解程序执行高效平稳，在包含方案构造与受限模拟评估的全流程下，三类问题全量500个测试网格的端到端平均求解耗时分别为2.825秒、4.029秒与4.401秒，整体处于赛题建议的高效区间内。所测实际运行时间为共享主机环境下的工程耗时，底层执行时钟周期亦属微架构离散事件仿真指标。

**关键词：** 计算图切分；多核调度；微架构仿真；数据搬运；缓存复用
