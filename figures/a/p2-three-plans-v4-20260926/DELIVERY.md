# 图5.5-1下一版排版候选：两块面板

原图位于 v7 PDF 第35页，源稿 SHA-256 `51cd3c6fefd4885c7978bf46d6ad279297c170f3c8b590ae649aa4963df51ff0`。本目录从已入稿的 v3 可编辑图源另起，不修改冻结稿。

- `(a)` 展示基础完整方案 P0、空闲区间完整方案 P1 与经原始 COPY 字节严格下降门槛后才可能生成的完整方案 P2。红色路径表示按固定代码立即返回 P0；灰色路径表示不生成 P2，但继续处理此前已构造的方案。
- `(b)` 展示完整方案去重、最多三次注入评分接口请求、按总完成时间与额外 COPY 字节数作严格字典序比较，以及评分错误时返回 P0。图注候选在 [caption.md](caption.md)，其中保留了图内移走的异常分支和科学限定。
- 每块面板均有 `.drawio` 可编辑节点与连线、SVG 和 PDF 矢量导出、PNG 与按约160 mm宽生成的纸面预览。两块须在论文中上下排版；若并排压至总宽160 mm，当前纸面字号检查不再适用。

重建：`python3 build.py`，随后对两个 `.drawio` 分别运行 `drawio -x -f svg -e`、`drawio -x -f pdf --crop`、`drawio -x -f png -s 2 -b 16`。PNG 使用 `sips -Z 1890 -s dpiWidth 300 -s dpiHeight 300` 制作预览；完整命令中的输入输出路径即本目录同名文件。`SHA256SUMS.txt` 列出全部源文件与产物的字节哈希。
