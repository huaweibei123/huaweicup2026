分叉—汇合结构的阶段划分与计算任务分配。左上为原始有向无环图，右上为阶段及节点分组，下方为三个核心上的任务分配与顺序。本图为结构示例，条块宽度与水平间距不表示执行时间。

图中每个节点表示一个操作。有向边 u→v 表示操作 v 读取操作 u 产生的数据，因此 v 中相关的读取操作须等待该数据可用。图中的有向路径表示由这些直接依赖逐步传递形成的先后要求。

按原稿式（4-11）的划分，本例的阶段0包含 s、a，阶段1包含其余10个节点。节点 a 分出三条链：b1→c1→d1、b2→d2、b3→c3→d3；各链在归约节点 r 处汇合，随后到达 t。

灰色节点 s、a 构成一组；三个青绿色虚线框分别圈定一条链；琥珀色虚线框圈定 r、t。这五组节点构成五个子图，各子图对应的计算任务依次标为 Task 0 至 Task 4。左侧括号标示阶段范围，蓝色横框标示任务所属的计算核心。相同颜色的三条链对应三个不同任务。

Core 是图中对计算核心的标记。Core 0 依次执行 Task 0 和 Task 1；Core 1 依次执行 Task 2 和 Task 4；Core 2 执行 Task 3。蓝色实线箭头表示被分配到同一核心的任务顺序，琥珀色虚线箭头表示跨核心的数据依赖。在本图对应的情况 A 中，跨核心所需数据经 DDR 传递。

本图描述节点分组和任务依赖，没有模拟执行事件或性能测量。阶段的递推定义及一般构造条件以正文对应算法为准。
