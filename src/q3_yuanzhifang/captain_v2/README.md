# 固定队长P3运行模块的隔离副本

来源是队长 NikolaStarx 的 `huaweibei123/huaweicup2026` 固定提交 `2d5459fa042507cce0f0343e544ed43784c8488b`，原入口 `src.q3.adaptive_solve`。12个实际递归导入模块从GitHub固定内容API读取，解码后逐文件核对Git blob SHA-1及字节数；原SHA-256、复制后SHA-256和全部变更见UPSTREAM.json。没有执行下载模块、原作者附件或任何solver/E0。

此目录保留原算法代码及其作者归属，不将队长的stage迁移、attention/FFN、归约树或评价选优机制归为Fang原创。唯一源码适配是construct.py的仓库根目录由parents[2]改为parents[3]，因为副本多嵌套一级；其他模块逐字节相同。原src/q3与队长写区未修改，不依赖可能移动的分支或个人绝对路径。

复制是为后续统一入口按冻结结构规则复用已验证的方法，**不是新算法已通过全量评价的证明**。队长500格的solver墙钟含在线E0，不可作为新入口的实测墙钟；复用旧评价须逐格核同完整计划字节及图/配置/核/语义并注明来源。此目录与本线的新pipeline构造将由独立统一入口组合，组合规则和正式预算另冻结；现有独立机制批次不因此改名或拼接主成绩。
